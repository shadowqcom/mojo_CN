Mojo 并不强制使用值语义或引用语义。它对两者都提供支持，并允许每种类型自行定义其创建、复制和移动方式（如果确实需要的话）。因此，如果你在构建自己的类型，你可以让它支持值语义、引用语义，或者两者兼有。话虽如此，Mojo 的参数行为默认采用值语义来设计，并且为引用语义提供了严格控制以避免内存错误。

对引用语义的控制由[值所有权模型](/docs/manual/values/ownership)提供，但在我们介绍其语法和规则之前，重要的是先理解值语义的原理。一般而言，这意味着每个变量都独占地访问一个值，该变量作用域之外的任何代码都不能修改它的值。

## 值语义简介

在最基本的场景中，共享一个值语义类型意味着你创建该值的一个副本。这也被称为"按值传递（pass by value）"。例如，考虑以下代码：

```mojo
def main():
    var x = 1
    var y = x
    y += 1

    print("x:", x)
    print("y:", y)
```

```output
x: 1
y: 2
```

我们将 `x` 的值赋给 `y`，这通过复制 `x` 来为 `y` 创建值。当我们递增 `y` 时，`x` 的值并不会改变。每个变量都独占某个值的所有权。

而如果某个类型采用引用语义，那么 `y` 就会指向与 `x` 相同的值，递增其中任意一个都会影响两者的值。`x` 和 `y` 都不会"拥有"该值，任何变量都可以引用它并修改它。

Mojo 中的数值类型具有值语义，因为它们是平凡类型（trivial types），复制代价很低。

## Mojo 函数中的值语义

在 Mojo 中，值语义也默认适用于函数参数。但具体适用方式取决于[参数约定](/docs/manual/values/ownership#argument-conventions)，这部分内容在[所有权](/docs/manual/values/ownership/)一页中讨论。

例如，在以下函数中，`y` 参数默认是不可变的，因此如果函数想在局部作用域中修改该值，就需要制作一份本地副本：

```mojo
def add_two(y: Int):
    # y += 2  # This would cause a compiler error because `y` is immutable
    # We can instead make an explicit copy:
    var z = y
    z += 2
    print("z:", z)

def main():
    var x = 1
    add_two(x)
    print("x:", x)
```

```output
z: 3
x: 1
```

这一切都与值语义保持一致，因为每个变量都对其值保持独占的所有权。

函数接收 `y` 值的方式是一种"只看不碰"式的值语义。在处理内存占用较大的参数时，这也是一种更节省内存的做法，因为 Mojo 不会进行任何复制，除非我们自己显式地制作副本。

因此，函数参数的默认行为完全是值语义的：参数是不可变引用，调用者中任何存活的变量都不会受到函数的影响。

但我们也必须允许引用语义（可变引用），因为这是构建高性能且节省内存的程序的方式（一切都复制代价太大）。挑战在于以一种不破坏值语义的可预测性和安全性的方式引入引用语义。

在 Mojo 中，我们的做法是：与其强制每个变量对一个值拥有"独占访问权"，我们确保每个值都有一个"独占所有者"，并在其所有者的生命周期结束时销毁每个值。

在关于[值所有权](/docs/manual/values/ownership/)的下一页中，你将学习如何修改默认的参数约定，并安全地使用引用语义，使每个值在任一时刻都只有一个所有者。
