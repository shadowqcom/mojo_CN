Mojo 不强制执行值语义或引用语义。它同时支持两者，并允许每种类型定义它是如何创建、复制和移动的（如果有的话）。因此，如果你正在构建自己的类型，你可以实现它以支持值语义、引用语义或两者兼有。话虽如此，Mojo 设计的参数行为默认为值语义，并提供了对引用语义的严格控制，以避免内存错误。

对引用语义的控制由[值所有权模型](/docs/manual/values/ownership)提供，但在我们讨论其语法和规则之前，重要的是要理解值语义的原则。一般来说，这意味着每个变量都唯一地访问一个值，任何变量范围之外的代码都不能修改其值。

## 值语义简介

在最基本的情况下，共享值语义类型意味着你创建值的副本。这也称为"按值传递"。例如，考虑以下代码：

```mojo
def main():
    var x = 1
    var y = x
    y += 1

    print("x:", x)
    print("y:", y)
```

```output
x: 1
y: 2
```

我们将 `x` 的值赋给 `y`，这通过复制 `x` 来为 `y` 创建值。当我们增加 `y` 时，`x` 的值不会改变。每个变量都拥有一个值的唯一所有权。

相反，如果一个类型使用引用语义，那么 `y` 将指向与 `x` 相同的值，增加其中一个会影响两个的值。`x` 和 `y` 都不会"拥有"该值，任何变量都被允许引用并修改它。

Mojo 中的数值是值语义的，因为它们是简单类型，复制成本很低。

## Mojo 函数中的值语义

值语义也默认应用于 Mojo 中的函数参数。然而，它们应用的方式取决于[参数约定](/docs/manual/values/ownership#argument-conventions)，这在[所有权](/docs/manual/values/ownership/)页面上进行了讨论。

例如，在以下函数中，`y` 参数默认是不可变的，因此如果函数想在局部范围内修改值，它需要创建一个本地副本：

```mojo
def add_two(y: Int):
    # y += 2  # 这会导致编译错误，因为 `y` 是不可变的
    # 我们可以显式创建一个副本：
    var z = y
    z += 2
    print("z:", z)

def main():
    var x = 1
    add_two(x)
    print("x:", x)
```

```output
z: 3
x: 1
```

这与值语义一致，因为每个变量都维护其值的唯一所有权。

函数接收 `y` 值的方式是值语义的"只读不写"方法。当处理内存密集型参数时，这也是一种更节省内存的方法，因为 Mojo 不会进行任何复制，除非我们明确自己创建副本。

因此，函数参数的默认行为完全是值语义的：参数是不可变引用，调用中的任何活动变量都不会受函数的影响。

但我们也必须允许引用语义（可变引用），因为这是我们构建高性能和内存高效程序的方式（复制所有东西变得非常昂贵）。挑战在于以一种不干扰值语义的可预测性和安全性的方式引入引用语义。

我们在 Mojo 中的做法是，不是强制每个变量都有"独占访问"值的权利，而是确保每个值都有一个"独占所有者"，并在其所有者的生命周期结束时销毁每个值。

在关于[值所有权](/docs/manual/values/ownership/)的下一页上，你将学习如何修改默认参数约定，并安全地使用引用语义，以便每个值同时只有一个所有者。
