在调用 Python 方法时，Mojo 需要在原生 Python 对象和原生 Mojo 对象之间进行来回转换。大多数转换会自动进行，但有许多情况 Mojo 尚未处理。在这些情况下，你可能需要进行显式转换，或调用额外的方法。

## Python 中的 Mojo 类型

Mojo 原始类型会隐式转换为 Python 对象。目前我们支持整数、浮点数、布尔值和字符串。

为了演示，以下示例动态创建了一个名为 `py_utils` 的内存中 Python 模块，其中包含一个 `type_printer()` 函数，该函数简单地打印给定值的类型。然后你可以看到不同的 Mojo 值如何转换为相应的 Python 类型。

```mojo
from std.python import Python

def main() raises:
    py_module = """
def type_printer(value):
    print(type(value))
"""
    py_utils = Python.evaluate(py_module, file=True, name="py_utils")

    py_utils.type_printer(4)
    py_utils.type_printer(3.14)
    py_utils.type_printer(True)
    py_utils.type_printer("Mojo")
```

```output
<class 'int'>
<class 'float'>
<class 'bool'>
<class 'str'>
```

## Mojo 中的 Python 类型

你也可以从 Mojo 创建和使用 Python 对象。

### Mojo 包装对象

当你在 Mojo 代码中使用 Python 对象时，Mojo 会在 Python 对象外添加 [`PythonObject`](/docs/std/python/python_object/PythonObject/) 包装器。此对象暴露了许多常见的双下划线方法（dunder methods），如 `__getitem__()` 和 `__getattr__()`，将它们传递给底层的 Python 对象。大多数情况下，你可以像在 Python 中一样对待包装后的对象。你可以使用点号表示法访问属性和调用方法，使用 `[]` 运算符访问序列中的项。

你可以通过使用 Mojo 整数、浮点数、布尔值或字符串初始化 `PythonObject` 来显式创建包装的 Python 对象。此外，你可以使用 [`Python.dict()`](/docs/std/python/python/Python/#dict)、[`Python.list()`](/docs/std/python/python/Python/#list) 和 [`Python.tuple()`](/docs/std/python/python/Python/#tuple) 静态方法在 Mojo 中直接创建多种类型的 Python 集合。

例如，要创建 Python 字典，使用 [`Python.dict()`](/docs/std/python/python/Python/#dict) 方法：

```mojo
from std.python import Python

def main() raises:
    py_dict = Python.dict()
    py_dict["item_name"] = "whizbang"
    py_dict["price"] = 11.75
    py_dict["inventory"] = 100
    print(py_dict)
```

```output
{'item_name': 'whizbang', 'price': 11.75, 'inventory': 100}
```

使用 [`Python.list()`](/docs/std/python/python/Python/#list) 方法，你可以创建 Python 列表并可选地初始化它：

```mojo
from std.python import Python

def main() raises:
    py_list = Python.list("cat", 2, 3.14159, 4)
    n = py_list[2]
    print("n =", n)
    py_list.append(5)
    py_list[0] = "aardvark"
    print(py_list)
```

```output
n = 3.14159
['aardvark', 2, 3.14159, 4, 5]
```

[`Python.tuple()`](/docs/std/python/python/Python/#tuple) 方法创建一个 Python 元组：

```mojo
from std.python import Python

def main() raises:
    py_tuple = Python.tuple("cat", 2, 3.1415, "cat")
    n = py_tuple[2]
    print("n =", n)
    print("Number of cats:", py_tuple.count("cat"))
```

```output
n = 3.1415
Number of cats: 2
```

如果你想构造一个没有对应 Mojo 字面量的 Python 类型，你也可以使用 [`Python.evaluate()`](/docs/std/python/python/Python/#evaluate) 方法。例如，创建一个 Python `set`：

```mojo
from std.python import Python

def main() raises:
    var py_set = Python.evaluate('{2, 3, 2, 7, 11, 3}')
    num_items = len(py_set)
    print(num_items, "items in the set.")
    contained = 7 in py_set
    print("Is 7 in the set:", contained)
```

```output
4 items in the set.
Is 7 in the set: True
```

`PythonObject` 实现了 [`Writable`](/docs/std/format/Writable/) 特征。这允许你使用内置的 [`print()`](/docs/std/io/io/print/) 函数打印 Python 值，如前面几个示例所示。

然而，大多数其他 Mojo API 不直接接受 `PythonObject` 值。在这些情况下，你需要将 Python 值显式转换为原生 Mojo 值。例如：

```mojo
from std.python import Python
from std.python import PythonObject


def main() raises:
    var py_string = PythonObject("Hello, Mojo!")
    var py_bool = PythonObject(True)
    var py_int = PythonObject(123)
    var py_float = PythonObject(3.14)

    var mojo_string = String(py=py_string)
    var mojo_bool = Bool(py=py_bool)
    var mojo_int = Int(py=py_int)
    var mojo_float = Float64(py=py_float)
```

### 在 Mojo 中比较 Python 类型

你可以在 Mojo 比较表达式中使用 Python 对象，Mojo 的 `is` 运算符也可以用于比较两个 Python 对象的标识。Python 值如 `False` 和 `None` 在 Mojo 布尔表达式中也会被评估为假值。

如果你需要知道底层 Python 对象的类型，你可以使用 [`Python.type()`](/docs/std/python/python/Python/#type) 方法，它等价于 Python 内置的 `type()` 函数。你可以通过将 Python 对象与类型进行标识比较来测试它是否为特定类型，如下所示：

```mojo
from std.python import Python

def main() raises:
    var value1 = PythonObject(3.7)
    value2 = Python.evaluate("10/3")

    # 比较值
    print("Is value1 greater than 3:", value1 > 3)
    print("Is value1 greater than value2:", value1 > value2)

    # 比较标识
    value3 = value2
    print("value1 is value2:", value1 is value2)
    print("value2 is value3:", value2 is value3)

    # 比较类型
    py_float_type = Python.evaluate("float")
    print("Python float type:", py_float_type)
    print("value1 type:", Python.type(value1))
    print("Is value1 a Python float:", Python.type(value1) is py_float_type)
```

```output
Is value1 greater than 3: True
Is value1 greater than value2: True
value1 is value2: False
value2 is value3: True
Python float type: <class 'float'>
value1 type: <class 'float'>
Is value1 a Python float: True
```
