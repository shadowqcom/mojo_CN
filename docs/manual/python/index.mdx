Mojo 不仅使用了 Python 风格的语法，我们的计划是提供与 Python 生态系统的完全兼容。我们支持两种类型的兼容性（或互操作性）：

- [从 Mojo 调用 Python](/docs/manual/python/python-from-mojo/)：

  你可以导入现有的 Python 模块并在 Mojo 程序中使用它们。这是 100% 兼容的，因为我们使用未经修改的 CPython 运行时，以完全兼容现有的 Python 库。你可以直接从 Mojo 构造 Python 对象并调用 Python 函数，将 CPython 解释器作为动态库使用（在图 1 中显示为 `libpython.dylib`）。

- [从 Python 调用 Mojo](/docs/manual/python/mojo-from-python/)：

  你可以用高性能的 Mojo 代码扩展你的 Python 代码（或逐步将 Python 代码迁移到 Mojo）。由于 Mojo 是编译型语言，我们不能直接从 Python "求值" Mojo 代码。相反，你必须声明哪些 Mojo 函数和类型可以从 Python 调用（声明"绑定"），然后你就可以在 Python 代码中导入它们（在图 1 中显示为 `mojo_module`），就像任何其他模块一样——不需要额外的编译步骤。

通过拥抱双向的语言互操作，你可以选择最适合你用例的 Mojo 与 Python 协作方式。

:::note Python 要求

Mojo 本身不要求 Python。要使用本节中所述的 Mojo ↔ Python 互操作特性，你需要 Python 3.10–3.14。

:::
