许多语言都具备*元编程*（metaprogramming）的设施：编写能够生成或修改代码的代码。Python 具备动态元编程的设施：包括装饰器、元类等在内的许多特性。这些特性使 Python 非常灵活且高效，但由于它们是动态的，因此会带来运行时开销。其他语言则具备静态或编译时元编程特性，比如 C 预处理器宏和 C++ 模板。这些特性可能存在限制，并且难以使用。

Mojo 的编译时元编程系统使用与运行时程序相同的语言，因此你不必学习一门新语言——只需学习几个新特性。你需要学习的主要特性有：

- 编译时语句和表达式
- 参数（Parameters）
- Trait

## 编译时语句和表达式

`comptime` 关键字用于标识需要在编译时求值的语句或表达式。例如，`comptime` 关键字用于声明编译时常量值，以及引入编译时的条件分支和循环。有关编译时赋值和控制流的信息，请参阅[编译时求值](/docs/manual/metaprogramming/comptime-evaluation/)。

## 参数

函数和结构体可以使用编译时参数进行*参数化*，使你能够定义一个容纳不同数据类型的容器，或者一个按矩阵维度进行参数化的矩阵乘法算法。编译时参数类似于 C++ 模板参数或 Rust 泛型参数。在编译时，Mojo 会对参数化代码进行*特化*（specialize），生成*具体*版本——也就是用常量值替换参数。

例如，一个按矩阵维度进行参数化的矩阵乘法函数可以在编译时被特化，从而根据这些维度选择最高效的算法。有关参数化的信息，请参阅[参数](/docs/manual/parameters/)。

## Trait

类型参数化的函数和结构体可以跨多种类型工作。例如，一个列表可能容纳 `Int`、`Float32` 或 `String` 值。类型参数化的代码需要知道这些类型支持哪些操作。

*trait* 定义了类型所提供的一组行为。参数化的排序函数不必预先选定具体的类型，而可以仅要求 `Comparable`。有关更多信息，请参阅 [trait](/docs/manual/traits/) 和[参数化声明](/docs/manual/generics/)。
