指针是对存储在内存中的一个或多个值的间接引用。指针是一个持有内存地址的值，并提供 API 来向该内存存储值和从中检索值。指针所指向的值也被称为 _pointee_（被指物）。

Mojo 标准库包含多种指针类型，它们提供不同的功能集。所有这些指针类型都是 _参数化的_——它们可以指向任何类型的值，而值类型以参数的形式指定。例如，以下代码创建一个指向 `Int` 值的 `OwnedPointer`：

```mojo
from std.memory import OwnedPointer

var ptr: OwnedPointer[Int]
ptr = OwnedPointer(100)
```

`ptr` 变量的值类型为 `OwnedPointer[Int]`。该指针 _指向_ 一个 `Int` 类型的值，如图 1 所示。

访问内存——检索或更新一个值——被称为对指针 _解引用（dereferencing）_。你可以在变量名后跟一对空的方括号来解引用指针：

```mojo
# Update an initialized value
ptr[] += 10
# Access an initialized value
print(ptr[])
```

## 指针术语

在深入了解指针类型之前，这里列出一些你会遇到的术语。其中一些你可能已经熟悉了。

- **安全指针（Safe pointers）**：旨在防止内存错误。除非你使用被特别标明为不安全的 API，否则你可以使用这些指针而不必担心双重释放（double-free）或释放后使用（use-after-free）等内存问题。

- **可空指针（Nullable pointers）**：一些语言使用一个哨兵值（sentinel value）来表示一个不指向任何东西的指针（"空指针"）。Mojo 标准库中的指针类型都不可空。要建模一个可空指针，请使用
  [`Optional`](/docs/std/collections/optional/Optional/) 类型。例如，`Optional[Pointer]` 或 `Optional[OwnedPointer]`。

- **拥有指针（Owning pointers）**：拥有其被指物的所有权，这意味着当指针本身被销毁时，它所指向的值可能会被释放。拥有指针（或 _智能指针_）负责分配和释放内存以容纳其被指物。非拥有指针可能指向由其他地方拥有的值，或者可能指向动态分配的内存。

- **未初始化内存（Uninitialized memory）**：指尚未用值初始化的内存位置，因此可能包含随机数据。新分配的内存是未初始化的。安全指针 API 不允许你访问未初始化的内存。不安全的 API 可以访问一块未初始化的内存位置，然后逐一初始化它们。能够访问未初始化内存本质上就是不安全的。

- **可复制性（Copyability）**：许多指针类型可以被隐式复制（例如，通过把一个值赋给变量）：

  ```mojo
  var copied_ptr = ptr
  ```

  指针本身只是一小段要复制的数据（通常是 64 位），复制指针并不会复制被指物——原始指针和副本都指向同一块内存位置和同一个值。

## 指针类型

Mojo 标准库包含多种具有不同特性的指针类型：

- [`Pointer`](/docs/std/memory/pointer/Pointer/) 是 Mojo 的主要指针类型。
  它指向一个或多个连续的内存位置，并可以引用未初始化的内存。

- [`OwnedPointer`](/docs/std/memory/owned_pointer/OwnedPointer/) 是一种
  智能指针，指向单个值，并维护对该值的独占所有权。

- [`ArcPointer`](/docs/std/memory/arc_pointer/ArcPointer/) 是一种
  引用计数智能指针，指向一个被拥有的值，该值的所有权可能与其他 `ArcPointer` 实例共享。

表 1 总结了不同类型的指针：

|                                                  | `Pointer`                  | `OwnedPointer`          | `ArcPointer`            |
|--------------------------------------------------|----------------------------|-------------------------|-------------------------|
| 安全（Safe）                                     | 条件性 <sup>1</sup>        | 是                      | 是                      |
| 内存分配                                         | 通过 `alloc()` 手动进行    | 隐式 <sup>2</sup>       | 隐式 <sup>2</sup>       |
| 拥有被指物                                       | 否 <sup>3</sup>            | 是                      | 是                      |
| 可隐式复制                                       | 是                         | 否                      | 是                      |
| 可空（Nullable）                                 | 否                         | 否                      | 否                      |
| 可指向未初始化内存                                | 是                         | 否                      | 否                      |
| 可指向多个值（类数组访问）                       | 是                         | 否                      | 否                      |

<figcaption><b>表 1.</b> 指针类型</figcaption>
</figure>

<sup>1</sup> `Pointer` 同时具有安全方法和不安全方法。不安全方法以 `unsafe_` 前缀命名（或要求一个 `unsafe_` 关键字参数）。

<sup>2</sup> `OwnedPointer` 和 `ArcPointer` 在你用值初始化指针时隐式分配内存。

<sup>3</sup> `Pointer` 提供了用于初始化和销毁已存储类型实例的不安全方法。用户负责管理已存储值的生命周期。

下面各节提供每种指针类型的更多细节。

## `Pointer`

[`Pointer`](/docs/std/memory/pointer/Pointer/) 类型是 Mojo 的主要
指针类型。它可以访问一块连续的内存位置，这些位置可能是未初始化的。堆分配的内存通过 `Pointer` 访问；其他指针类型包装一个 `Pointer` 来访问堆内存。

当 `Pointer` 用于指向一个已存在的值时，它是 _安全的_：

```mojo
var ptr = Pointer(to=some_value)
print(ptr[])
```

这样使用时，`Pointer` 类型携带它所指向值的 origin。它可以用来在结构体字段中存储引用。

`Pointer` 类型还提供了许多不安全方法，你可以使用它们来访问动态分配的内存、初始化和销毁已存储的值等等。这些特性对于底层系统编程任务很有用，但你需要谨慎使用它们。一些 _不安全_ 指针用例包括：

- 构建高性能的类数组集合，例如 `List`。一个 `Pointer` 可以访问多个值，并让你对如何分配、使用和释放内存拥有很大控制权。能够访问未初始化的内存意味着你可以预分配一块内存，并在值被添加到集合时增量地初始化它们。

- 与外部库（包括 C++ 和 Python）交互。你可以使用 `Pointer` 向外部库传递或从外部库接收装满数据的缓冲区。

更多信息，请参阅
[使用指针](/docs/manual/pointers/using-pointers)。

## `OwnedPointer`

[`OwnedPointer`](/docs/std/memory/owned_pointer/OwnedPointer/) 类型是一种
智能指针，专为底层数据单一所有权的场景而设计。`OwnedPointer` 指向单个项目，该在你初始化 `OwnedPointer` 时传入。`OwnedPointer` 分配内存并将值移动或复制到预留的内存中。

```mojo no-test
from std.memory import OwnedPointer

var o_ptr = OwnedPointer(some_big_struct^)
```

拥有指针几乎可以持有任何类型的项目，但在构造 `OwnedPointer` 时，存储的项目必须是 `Movable` 或 `Copyable` 的。

由于 `OwnedPointer` 旨在强制单一所有权，指针本身可以被移动，但不能被复制。

`OwnedPointer` 确实提供了一个初始化器，通过从现有的 `OwnedPointer` 复制 _已存储的值_ 来创建一个新的 `OwnedPointer`。这会产生两个拥有指针，每个都有自己的独立分配和自己的已存储值副本。

## `ArcPointer`

[`ArcPointer`](/docs/std/memory/arc_pointer/ArcPointer/) 是一种
引用计数智能指针，非常适合共享资源场景，其中给定值的最后一个所有者可能并不明确。与 `OwnedPointer` 一样，它指向单个值，并在你用值初始化 `ArcPointer` 时分配内存：

```mojo
from std.memory import ArcPointer

var attributesDict: Dict[String, String] = {}
var attributes = ArcPointer(attributesDict^)
```

与 `OwnedPointer` 不同，`ArcPointer` 可以被自由复制。一个给定 `ArcPointer` 的所有实例共享一个引用计数，每当 `ArcPointer` 被复制时引用计数递增，每当一个实例被销毁时引用计数递减。当引用计数降为零时，存储的值被销毁，分配的内存被释放。

你可以使用 `ArcPointer` 来实现安全的引用语义类型。例如，在下面的代码片段中，`SharedDict` 使用一个 `ArcPointer` 来存储字典。复制 `SharedDict` 的实例只会复制 `ArcPointer`，不会复制字典，字典在所有副本之间共享。

```mojo
from std.memory import ArcPointer


struct SharedDict(ImplicitlyCopyable):
    var attributes: ArcPointer[Dict[String, String]]

    def __init__(out self):
        var attributesDict: Dict[String, String] = {}
        self.attributes = ArcPointer(attributesDict^)

    def __init__(out self, *, copy: Self):
        self.attributes = copy.attributes

    def __setitem__(mut self, key: String, value: String):
        self.attributes[][key] = value

    def __getitem__(self, key: String) -> String:
        return self.attributes[].get(key, default="")


def main():
    var thing1 = SharedDict()
    var thing2 = thing1
    thing1["Flip"] = "Flop"
    print(thing2["Flip"])
```

:::note

`ArcPointer` 让引用计数本身是线程安全的，但对存储值的读写并非如此——调用者负责同步。

:::
