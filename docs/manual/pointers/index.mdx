指针是对存储在内存中的一个或多个值的间接引用。指针是一个持有内存地址的值，并提供 API 来在该内存中存储和检索值。指针所指向的值也被称为_被指物_（pointee）。

Mojo 标准库包含多种指针类型，它们提供不同的功能集。所有这些指针类型都是_泛型_的——它们可以指向任何类型的值，值类型以参数的形式指定。例如，以下代码创建了一个指向 `Int` 值的 `OwnedPointer`：

```mojo
from std.memory import OwnedPointer

var ptr: OwnedPointer[Int]
ptr = OwnedPointer(100)
```

变量 `ptr` 的类型为 `OwnedPointer[Int]`。该指针_指向_一个 `Int` 类型的值，如图 1 所示。

访问内存——检索或更新值——被称为_解引用_指针。你可以在变量名后跟一对空的方括号来解引用指针：

```mojo
# 更新已初始化的值
ptr[] += 10
# 访问已初始化的值
print(ptr[])
```

## 指针术语

在深入了解指针类型之前，以下是一些你会遇到的术语。其中一些你可能已经熟悉了。

- **安全指针**：旨在防止内存错误。除非你使用特别标记为不安全的 API，否则你可以放心使用这些指针，不必担心双重释放或释放后使用等内存问题。

- **可空指针**：可以指向无效的内存位置（通常为 0，即"空指针"）。标准库中的指针类型都不可空。要模拟可空指针，请使用 `Optional[UnsafePointer]`。

- **智能指针**：拥有其被指物的所有权，这意味着当指针本身被销毁时，它所指向的值可能会被释放。非拥有指针可能指向由其他地方拥有的值，或者可能需要手动管理值的生命周期。

- **内存分配**：某些指针类型可以分配内存来存储其被指物，而其他指针只能指向预先存在的值。内存分配可以是隐式的（即在用值初始化指针时自动执行），也可以是显式的。

- **未初始化内存**：指尚未用值初始化的内存位置，因此可能包含随机数据。新分配的内存是未初始化的。安全指针类型不允许用户访问未初始化的内存。不安全指针可以分配一块未初始化的内存位置，然后逐一初始化它们。能够访问未初始化的内存本质上就是不安全的。

- **可复制类型**：可以隐式复制（例如，通过将值赋给变量）。也称为_隐式可复制类型_。

  ```mojo
  copied_ptr = ptr
  ```

  _显式可复制_类型要求用户使用带关键字参数的构造函数来请求复制：

  ```mojo
  copied_owned_ptr = OwnedPointer(other=owned_ptr)
  ```

## 指针类型

Mojo 标准库包含多种具有不同特性的指针类型：

- [`Pointer`](/docs/std/memory/pointer/Pointer/) 是一种安全指针，指向它不拥有的单个值。

- [`OwnedPointer`](/docs/std/memory/owned_pointer/OwnedPointer/) 是一种智能指针，指向单个值，并维护对该值的独占所有权。

- [`ArcPointer`](/docs/std/memory/arc_pointer/ArcPointer/) 是一种引用计数智能指针，指向一个拥有的值，该值的所有权可能与其他 `ArcPointer` 实例共享。

- [`UnsafePointer`](/docs/std/memory/unsafe_pointer/UnsafePointer/) 指向一个或多个连续的内存位置，并且可以引用未初始化的内存。

以下各节提供了每种指针类型的更多细节。

## `Pointer`

[`Pointer`](/docs/std/memory/pointer/Pointer/) 类型是一种安全指针，指向它不拥有的已初始化值。`Pointer` 的一些示例用例包括：

- 存储对相关类型的引用。例如，列表的迭代器对象可能持有一个指向原始列表的 `Pointer`。

- 通过 `external_call()` 将单个值的内存位置传递给外部代码。

- 需要一个 API 返回对值的长生命周期引用的情况。（目前标准库集合类型如 `List` 的迭代器返回指针。）

你可以通过使用 `to` 关键字参数调用构造函数来构造一个指向现有值的 `Pointer`：

```mojo
from std.memory import Pointer

ptr = Pointer(to=some_value)
```

你也可以通过复制现有的 `Pointer` 来创建一个 `Pointer`。

`Pointer` 携带存储值的[`来源`](/docs/manual/values/lifetimes/)，因此 Mojo 可以跟踪被引用值的生命周期。

## `OwnedPointer`

[`OwnedPointer`](/docs/std/memory/owned_pointer/OwnedPointer/) 类型是一种智能指针，专为底层数据单一所有权的场景而设计。`OwnedPointer` 指向单个项目，该项目在你初始化 `OwnedPointer` 时传入。`OwnedPointer` 分配内存并将值移动或复制到预留的内存中。

```mojo
from std.memory import OwnedPointer

o_ptr = OwnedPointer(some_big_struct)
```

拥有指针几乎可以持有任何类型的项目，但在构造 `OwnedPointer` 时，存储的项目必须是 `Movable` 或 `Copyable` 的。

由于 `OwnedPointer` 旨在强制单一所有权，指针本身可以移动，但不能复制。

注意：目前，你无法创建 `Optional[OwnedPointer[T]]`，因为 `Optional` 类型仅适用于既可移动又可复制的类型。这限制了某些本应是 `OwnedPointer` 自然适用场景的用例，包括自引用数据结构如链表和树。（在 `OwnedPointer` 支持此用例之前，可以在需要可 `Optional` 的智能指针时使用 `ArcPointer`。）

## `ArcPointer`

[`ArcPointer`](/docs/std/memory/arc_pointer/ArcPointer/) 是一种引用计数智能指针，非常适合共享资源的场景，其中给定值的最后一个所有者可能不明确。与 `OwnedPointer` 类似，它指向单个值，并在你用值初始化 `ArcPointer` 时分配内存：

```mojo
from std.memory import ArcPointer

attributesDict: Dict[String, String] = {}
attributes = ArcPointer(attributesDict)
```

与 `OwnedPointer` 不同，`ArcPointer` 可以自由复制。给定 `ArcPointer` 的所有实例共享一个引用计数，每当 `ArcPointer` 被复制时引用计数递增，每当实例被销毁时引用计数递减。当引用计数降为零时，存储的值被销毁，分配的内存被释放。

你可以使用 `ArcPointer` 来实现安全的引用语义类型。例如，在以下代码片段中，`SharedDict` 使用 `ArcPointer` 来存储字典。复制 `SharedDict` 的实例只会复制 `ArcPointer`，而不会复制字典，字典在所有副本之间共享。

```mojo
from std.memory import ArcPointer

struct SharedDict(Copyable):
    var attributes: ArcPointer[Dict[String, String]]

    def __init__(out self):
        attributesDict: Dict[String, String] = {}
        self.attributes = ArcPointer(attributesDict)

    def __init__(out self, *, copy: Self):
        self.attributes = copy.attributes

    def __setitem__(mut self, key: String, value: String):
        self.attributes[][key] = value

    def __getitem__(self, key: String) -> String:
        return self.attributes[].get(key, default="")

def main():
    thing1 = SharedDict()
    thing2 = thing1
    thing1["Flip"] = "Flop"
    print(thing2["Flip"])
```

注意：引用计数使用 [`Atomic`](/docs/std/atomic/atomic/Atomic/) 值存储，以确保引用计数的更新是线程安全的。然而，Mojo 目前不强制跨线程边界的独占访问，因此仍有可能形成竞态条件。

## UnsafePointer

[`UnsafePointer`](/docs/std/memory/unsafe_pointer/UnsafePointer/) 是一种低级指针，可以访问一块连续的内存位置，这些内存可能是未初始化的。它类似于 C 和 C++ 编程语言中的原始指针。`UnsafePointer` 提供了不安全的方法来初始化和销毁存储的值，以及在值初始化后访问它们。

顾名思义，`UnsafePointer` 不提供任何内存安全保证，因此你应该将其保留给其他指针类型无法胜任的情况。以下是一些你可能需要使用 `UnsafePointer` 的用例：

- 构建高性能的类数组结构，如 `List` 或 `Tensor`。单个 `UnsafePointer` 可以访问多个值，并让你对内存的分配、使用和释放拥有很大的控制权。能够访问未初始化的内存意味着你可以预分配一块内存，并在值添加到集合时逐步初始化它们。

- 与外部库（包括 C++ 和 Python）交互。你可以使用 `UnsafePointer` 向外部库传递或从外部库接收充满数据的缓冲区。

更多信息请参阅[不安全指针](/docs/manual/pointers/unsafe-pointers)。
