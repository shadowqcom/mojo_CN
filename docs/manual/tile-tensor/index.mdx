title: TileTensor 简介

Mojo 的 [`layout` 包](/docs/layout/)提供了许多用于处理密集多维数组的 API，简化了编写线性代数算法的工作。

本节讨论 `TileTensor` 抽象及其相关类型：

- [`TileTensor`](/docs/layout/tile_tensor/TileTensor/) 是一种灵活的张量类型，它将 `tile_layout.Layout` 和数据指针组合在一起。
- [`tile_layout.Layout`](/docs/layout/tile_layout/Layout/) 结构体描述了数据在内存中的排列方式。*布局*是一个函数，将一组逻辑坐标（如二维数组中的 (*x*, *y*)）映射到一个线性索引值（如内存缓冲区中的偏移量）。布局可以描述简单的行主序或列主序矩阵，也可以描述更复杂的组织方式，如细分为瓦片的矩阵。
- [`Coord`](/docs/layout/coord/Coord/) 是一个类似元组的容器，用于存储整数坐标，同时支持编译时和运行时值。它用于定义逻辑坐标和布局形状等。

`layout` 包还包含较早的 `LayoutTensor` 类型及其关联的基于 `IntTuple` 的布局类型 `layout.Layout`。`TileTensor` 本质上是 `LayoutTensor` 的新版本，解决了该类型的若干不足。新旧类型的大部分概念是相同的。然而，`TileTensor` 尚未实现 `LayoutTensor` 支持的所有功能。以下是关于何时使用各类型的指导：

- 当你需要具有运行时维度的布局、嵌套布局，或使用较新的基于 `Coord` 的布局系统时，请使用 `TileTensor`。基于 `Coord` 的布局系统最小化了布局结构体的内存占用，有助于减少 GPU 上的寄存器压力。

- 当你需要已有的操作（如 `copy_dma()`、`collective_load()`），或需要与使用基于 `IntTuple` 的布局的现有代码兼容时，请使用 `LayoutTensor`。

你可以将 `TileTensor` 转换为 `LayoutTensor`因此在必要时可以同时使用两种类型。同样，你可以轻松地将基于 `Coord` 的布局转换为基于 `IntTuple` 的布局。

有关 `LayoutTensor` 的更多信息，请参阅[基于 `IntTuple` 的布局](/docs/manual/layout/layouts/)和 [`LayoutTensor`](/docs/manual/layout/tensors/)页面。
