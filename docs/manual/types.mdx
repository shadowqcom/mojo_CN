Mojo 中的所有值都有关联的数据类型。大多数类型是*名义类型*（nominal type），由 [`struct`](/docs/manual/structs/) 定义。这些类型是名义的（或"命名的"），因为类型相等性由类型的*名称*决定，而不是由其*结构*决定。

有一些类型不是作为结构体定义的：

- 函数根据其签名进行类型化。
- `NoneType` 是一种只有一个实例的类型，即 `None` 对象，用于表示"无值"。

Mojo 附带一个标准库，提供了许多有用的类型和实用函数。这些标准类型并不是特权类型。每个标准库类型都像用户定义类型一样定义——即使是像 [`Int`](/docs/std/builtin/simd/#int) 和 [`String`](/docs/std/collections/string/string/String/) 这样的基本类型也是如此。但这些标准库类型是大多数 Mojo 程序都会用到的构建块。

最常见的类型是*内置类型*（built-in type），它们始终可用，无需导入。这些类型包括数值、字符串、布尔值等类型。

标准库还包括许多其他类型，你可以按需导入，包括集合类型、用于与文件系统交互和获取系统信息的实用工具等。

## 数值类型

Mojo 提供了内置数值类型，表示有符号整数、无符号整数和浮点值。这些类型支持多种精度，用于对低层数据和高层数值计算进行建模。

以下章节介绍 Mojo 中的整数和浮点类型。

:::note
所有数值类型都支持常规的数值运算符和按位运算符。[`math`](/docs/std/math/) 模块提供了额外的数学函数。
:::

### 整数和无符号整数

Mojo 的通用整数类型是有符号的 `Int`。如果需要特定位宽或无符号整数，请使用固定大小整数类型：

- 如果需要固定大小的整数，Mojo 提供了显式位宽的整数类型，如 `Int8`、`Int16`、`UInt32` 和 `UInt64`。

- 当不需要特定位宽时，使用通用的 `Int` 类型。

这些通用和固定精度的整数类型都是 [`SIMD`](/docs/std/builtin/simd/SIMD/) 类型的别名。

`Int` 表示使用系统原生字长的有符号整数，通常在 64 位 CPU 上为 64 位，在 32 位 CPU 上为 32 位。

你可能想知道何时使用 `Int`、何时使用其他整数类型。一般来说，当你需要整数类型且不需要特定位宽时，`Int` 是一个很好的安全默认选择。将 `Int` 作为 API 的默认整数类型可以使 API 更一致、更可预测。

#### 有符号与无符号

具有相同位宽的有符号和无符号整数可以表示相同数量的不同值，但范围不同。例如：

- `Int8` 表示 256 个值，范围从 `-128` 到 `127`
- `UInt8` 表示 256 个值，范围从 `0` 到 `255`

#### 溢出行为

有符号和无符号整数在处理溢出的方式上有所不同。

- 当有符号整数溢出时，值会使用二进制补码算术环绕到负数范围。例如，向 `var si: Int8 = 127` 加 `1` 的结果是 `-128`。
- 当无符号整数溢出时，值会环绕到其范围的起始处。例如，向 `var ui: UInt8 = 255` 加 `1` 的结果是 `0`。

当不需要负值、不打算设计公共 API，或者想要最大化可用的正数范围时，你可能更倾向于使用无符号整数。

### 浮点数

Mojo 提供了几种浮点类型，用于以不同精度表示实数。由于浮点值使用固定数量的位，因此某些数字无法精确表示。

浮点类型 `Float64`、`Float32` 和 `Float16` 遵循 IEEE 754-2008 标准来表示浮点值。每种类型都包含一个符号位、一组表示指数的位，以及一组表示尾数（也称为小数部分或有效数字）的位。表 3 展示了这些类型在内存中是如何表示的。

<figure id="table-3">
<figcaption><b>表 3.</b> 浮点类型的详细信息</figcaption>

| 类型名称 | 符号  | 指数 | 尾数 |
|-----------|-------|----------|----------|
| `Float64` | 1 位 | 11 位  | 52 位  |
| `Float32` | 1 位 | 8 位   | 23 位  |
| `Float16` | 1 位 | 5 位   | 10 位  |

</figure>

全零或全一的指数值表示特殊情况。这些模式使浮点数能够编码正负无穷大、有符号零和非数字（NaN）。这些值是作为由 [`FloatLiteral`](/docs/std/builtin/float_literal/FloatLiteral/) 提供的静态常量可用的：

```mojo
from std.math import copysign
from std.utils.numerics import isfinite, isinf, isnan

var inf = FloatLiteral.infinity
print(isinf(inf))  # `True`
print(inf > 0)     # `True`

var neginf = FloatLiteral.negative_infinity
print(isinf(neginf))  # `True`
print(neginf < 0)     # `True`

var nan = FloatLiteral.nan
print(isnan(nan))  # `True`

var negzero = FloatLiteral.negative_zero
print(negzero == 0.0)              # `True`
print(copysign(1.0, negzero) < 0)  # `True`
```

关于浮点数如何表示的更多详细信息，请参见 [IEEE 754](https://en.wikipedia.org/wiki/IEEE_754)。

#### 浮点近似与比较

由于浮点值是近似的，它们通常无法精确表示它们想要建模的数学值。

- **舍入误差。** 舍入可能会产生意外的结果。例如，`1/3` 无法用浮点格式精确表示。随着执行的浮点运算越来越多，舍入误差可能会累积。

- **相邻数字之间的间隔。** 在浮点类型的整个范围内，相邻可表示值之间的距离是变化的。在接近零的地方，值分布得非常密集。对于很大的正数或负数，间距可能超过 1，从而使某些连续整数无法被表示。

由于值是近似的，使用相等运算符（`==`）来比较浮点数几乎没有意义。例如：

```mojo
var big_num = 1.0e16
var bigger_num = big_num + 1.0
print(big_num == bigger_num)
```

```output
True
```

比较运算符（如 `<` 和 `>=`）在浮点值上可以按预期工作。要测试两个值是否在某个容差范围内相等，请使用 [`math.isclose()`](/docs/std/math/math/isclose/) 函数来比较两个浮点数在指定的容差范围内是否相等。

#### Mojo 支持的浮点类型

在下表中，**eXmX** 格式（例如 `Float8_e5m2` 和 `Float8_e4m3fn`）指的是分配给浮点数的指数和尾数的位数。

所有 IEEE 754 浮点格式都使用一个隐式的前导 1。这意味着 `Float32` 是 e8m23 但实际上是 e8m24，`Float16` 是 e5m10 但实际上是 e5m11，`BFloat16` 是 e8m7 但实际上是 e8m8，而 `Float8_e4m3fn` 是 e4m3 但实际上是 e4m4。

除了 eXmX 之外：

- **fn** 表示仅限有限数。这些数是有效的浮点值，不是无穷大。支持 NaN。
- **uz** 表示无符号零。仅支持 +0，不支持 -0。

虽然 Mojo 支持所有这些类型，但这些类型并非在所有硬件上都受支持。

:::note
`BFloat16` 中的 *B* 代表 Brain，来源于 Google Brain 人工智能研究小组。Google 专门为其张量处理单元（TPU）开发了它，以加速机器学习工作负载。因此，这里的 B 是项目标识符，而不是技术格式指示符。
:::

#### AI 优化的浮点格式

有几种浮点类型是专门为 AI 和机器学习工作负载设计的，以精度换取内存效率和计算吞吐量。

**BFloat16（Brain Floating Point）** 使用与 `Float32` 相同的 8 位指数位，保留了其动态范围，但与 Float32 的 23 位尾数相比，仅使用 7 个显式位（8 个有效位）来表示尾数。这使其非常适合于梯度幅度变化很大但对高精度要求不高的神经网络训练。

**8 位格式**（`Float8_e5m2`、`Float8_e4m3fn` 及其 `fnuz` 变体）是用于 AI 加速器的超紧凑格式，在这些场景下内存带宽是主要瓶颈。命名指示了位的分配：`e5m2` 表示 5 个指数位和 2 个尾数位。`fnuz` 后缀还表示无符号零（无 -0），用于 AMD 硬件。

**4 位格式**（`Float4_e2m1fn`）仅用 2 个指数位和 1 个尾数位提供极端压缩，用于可以用精度换取最大吞吐量的专用推理场景。

### 数值字面量

除了这些数值类型之外，标准库还提供了整数和浮点字面量类型，即 [`IntLiteral`](/docs/std/builtin/int_literal/IntLiteral/) 和 [`FloatLiteral`](/docs/std/builtin/float_literal/FloatLiteral/)。

这些字面量类型在编译时用于表示代码中出现的字面量数字。通常，你绝不应该自己实例化这些类型。

在编译时，Mojo 将数值字面量视为任意精度值，因此编译器可以执行编译时计算而不会发生溢出或舍入误差。

在运行时，这些值会被转换为有限精度类型。`IntLiteral` 可以转换为任何有限精度的整数类型，如果未指定类型则默认转换为 `Int`。`FloatLiteral` 可以转换为任何有限精度的浮点类型，默认转换为 `Float64`。

```mojo
var float1 = 3.3  # float1 是 Float64 类型
var float2: Float32 = 7.5
var int1 = 5  # int1 是 Int 类型
var int2: Int8 = 4
```

这种将只能在编译时存在的值转换为运行时值的过程称为*实例化*（materialization）。

以下代码示例展示了任意精度计算与在运行时使用 `Float64` 值执行相同计算之间的差异，后者会受到舍入误差的影响。

```mojo
var arbitrary_precision = 3.0 * (4.0 / 3.0 - 1.0)
# use a variable to force the following calculation to occur at runtime
var three = 3.0
var finite_precision = three * (4.0 / three - 1.0)
print(arbitrary_precision, finite_precision)
```

```output
1.0 0.99999999999999978
```

### `SIMD` 和 `DType`

为了支持高性能数值处理，Mojo 使用 [`SIMD`](/docs/std/builtin/simd/SIMD/) 类型作为其数值类型的基础。SIMD（单指令多数据）是一种处理器技术，允许你一次对一整套操作数执行运算。Mojo 的 `SIMD` 类型对 SIMD 操作进行了抽象。一个 `SIMD` 值表示一个 SIMD *向量*——即一个可以放入处理器寄存器的固定大小的值数组。SIMD 向量由两个[*参数*](/docs/manual/parameters/)定义：

- 一个 `DType` 值，定义向量中的数据类型（例如 32 位浮点数）。
- 向量中元素的数量，必须是 2 的幂。

例如，你可以像下面这样定义一个由四个 `Float32` 值组成的向量：

```mojo
var vec = SIMD[DType.float32, 4](3.0, 2.0, 2.0, 1.0)
```

对 SIMD 值执行的数学运算会*逐元素*（elementwise）应用于向量中的每个元素。例如：

```mojo
var vec1 = SIMD[DType.int8, 4](2, 3, 5, 7)
var vec2 = SIMD[DType.int8, 4](1, 2, 3, 4)
var product = vec1 * vec2
print(product)
```

```output
[2, 6, 15, 28]
```

### 标量值

`SIMD` 模块定义了几个 [`comptime` 值](/docs/manual/metaprogramming/comptime-evaluation/#comptime-values)，它们充当*类型别名*——即不同 `SIMD` 向量类型的简写名称。`Scalar` 类型是具有单个元素的 `SIMD` 向量。[表 1](#table-1) 中列出的数值类型（如 `Int`、`Int8` 和 `Float32`）都是标量值的类型别名：

```mojo
comptime Scalar = SIMD[length=1]
comptime Int = Scalar[DType.int]
comptime Int8 = Scalar[DType.int8]
comptime Float32 = Scalar[DType.float32]
```

这意味着无论你是在处理单个 `Float32` 值还是一个 float32 值向量，数学运算都会经过完全相同的代码路径。

#### `DType` 类型

`DType` 结构体描述了 `SIMD` 向量可以容纳的不同数据类型，并定义了许多用于操作这些数据类型的实用函数。`DType` 结构体定义了一组 [`comptime` 成员](/docs/manual/parameters/#comptime-members)，它们充当不同数据类型的标识符，如 `DType.uint` 和 `DType.float32`。你在声明 `SIMD` 向量时会使用这些 `comptime` 成员：

```mojo
var v: SIMD[DType.float64, 16]
```

注意，`DType.float64` 不是一种*类型*，它是一个描述数据类型的值。你不能创建一个类型为 `DType.float64` 的变量。你可以创建一个类型为 `SIMD[DType.float64, 1]`（或者 `Float64`，二者是同一个东西）的变量。

```mojo
from std.utils.numerics import max_finite, min_finite

def describeDType[dtype: DType]():
    print(dtype, "is floating-point:", dtype.is_floating_point())
    print(dtype, "is integral:", dtype.is_integral())
    print("Min/max finite values for", dtype)
    print(min_finite[dtype](), max_finite[dtype]())

describeDType[DType.float32]()
```

```output
float32 is floating-point: True
float32 is integral: False
Min/max finite values for float32
-3.4028234663852886e+38 3.4028234663852886e+38
```

标准库中还有其他几种数据类型也使用了 `DType` 抽象。

### 数值类型转换

在 Mojo 中，数值[运算符](/docs/manual/operators/)**不会**自动将操作数收窄或扩展为通用类型。你需要显式地将操作数转换为目标类型。

你可以通过调用 `SIMD` 值的 [`cast()`](/docs/std/builtin/simd/SIMD/#cast) 方法，或者通过将其作为参数传递给目标类型的初始化器，将一个 `SIMD` 值显式转换为不同的 `SIMD` 类型。例如：

```mojo
var simd1 = SIMD[DType.float32, 4](2.2, 3.3, 4.4, 5.5)
var simd2 = SIMD[DType.int16, 4](-1, 2, -3, 4)
var simd3 = simd1 * simd2.cast[DType.float32]()  # Convert with cast() method
print("simd3:", simd3)
var simd4 = simd2 + SIMD[DType.int16, 4](
    simd1
)  # Convert with SIMD initializer
print("simd4:", simd4)
```

```output
simd3: [-2.2, 6.6, -13.200001, 22.0]
simd4: [1, 5, 1, 9]
```

你可以通过将 `Scalar` 值作为参数传递给目标类型的初始化器来对其进行转换。例如：

```mojo
var my_int: Int16 = 12                     # SIMD[DType.int16, 1]
var my_float: Float32 = 0.75               # SIMD[DType.float32, 1]
var result = Float32(my_int) * my_float    # Result is SIMD[DType.float32, 1]
print("Result:", result)
```

```output
Result: 9.0
```

你可以通过将值传递给 [`Int()`](/docs/std/builtin/simd/SIMD/#__init__) 初始化器方法，将任何数值类型的标量值转换为 `Int`。此外，你可以将任何实现了 [`Intable`](/docs/std/builtin/int/Intable/) trait 或 [`IntableRaising`](/docs/std/builtin/int/IntableRaising/) trait 的结构体实例传递给 `Int()` 初始化器，从而将该实例转换为 `Int`。

## 字符串

字符串是 Mojo 的主要文本类型。它们存储 UTF-8 编码的文本，并为字符串操作提供安全、易用的接口。

Mojo 的 `String` 类型是可变字符串。`String` 支持各种运算符和常用方法：

```mojo
var s: String = "Testing"
s += " Mojo strings"
print(s) # Testing Mojo strings
```

### 构造

许多标准库类型遵循 [`Writable`](/docs/std/format/Writable/) trait，这表示可以使用 `String(...)` 初始化器将值转换为 `String`。

内置的 [`print()`](/docs/std/io/io/print/) 函数接受遵循 `Writable` trait 的值。

使用 `String(value)` 显式地将值转换为 `String`：

```mojo
var s = "Items in list: " + String(5)
print(s) # Items in list: 5
```

或者，使用接受可变参数 `Writable` 类型的字符串初始化器，这样你就不必对每个值都调用 `String()`：

```mojo
var s = String("Items in list: ", 5)
print(s) # Items in list: 5
```

### 表情符号和字素簇

Mojo 源文件是 UTF-8 编码的，允许你直接在字符串字面量中编写表情符号和其他非 ASCII 字符。

```mojo
var wave = "👋"
```

标准库以三种不同的方式计算表情符号，而这三者的答案通常各不相同：

- `byte_length()` 返回 UTF-8 字节数。
- `count_codepoints()` 计算 Unicode 码点数。
- `count_graphemes()` 返回用户感知到的字符（字素簇）数量，遵循 [UAX #29](https://www.unicode.org/reports/tr29/)。

字素计数与"如果你让某人数字符，他们会告诉你的数字"相匹配。一个家庭表情符号、一面旗帜、一只带肤色的挥手的手，各自都只算作一个字素，尽管每个都是由多个连接的码点组成的：

```mojo
def show(label: StaticString, s: StringSlice):
    print(
        label,
        "bytes=", s.byte_length(),
        "codepoints=", s.count_codepoints(),
        "graphemes=", s.count_graphemes(),
    )

def main():
    show("family    ", "👨‍👩‍👧‍👦")
    show("flag      ", "🇺🇸")
    show("wave      ", "👋🏽")
    show("namaste   ", "नमस्ते")
```

输出：

```text
family     bytes=25  codepoints=7  graphemes=1
flag       bytes=8   codepoints=2  graphemes=1
wave       bytes=8   codepoints=2  graphemes=1
namaste    bytes=18  codepoints=6  graphemes=3
```

如果你不想在源代码中嵌入非 ASCII 字节（例如在仅限 ASCII 的代码库中），可以用十六进制转义或 `chr()` 来拼写码点：

```mojo
var wave = "\U0001F44B"   # 8-digit hex escape
var wave2 = chr(0x1F44B)  # chr() function

var copy   = "\u00A9"   # 4-digit hex escape, ©
var euro   = "\u20AC"   # 4-digit hex escape, €
```

Mojo 的 4 位 `\uHHHH` 转义可以拼写最多到 U+FFFF 的码点。8 位的 `\U` 形式可扩展到 U+10FFFF（Unicode 的上限），覆盖诸如 👋（U+1F44B）这样的表情符号以及其他位于基本多语言平面之上的字符。`chr()` 函数也适用于整个范围。

这两种形式都拒绝代理码点（U+D800 到 U+DFFF）。代理码点是为 UTF-16 编码保留的，单独使用时无效。要转义 U+FFFF 以上的字符，请用 `\U` 写出其完整码点。不要使用 UTF-16 代理对。

### 字符串格式化

`format()` 方法使用手动或自动的位置索引将值插入字符串中。替换字段使用大括号：

```mojo
print("{0} {1} {0}".format("Mojo", 1.125))  # Mojo 1.125 Mojo
print("{} {}".format(True, "hello world"))  # True hello world
```

Mojo 的 `TString`（模板字符串）用直接的表达式和更好的性能特性取代了 `format()` 方法的功能。

`TString` 的工作方式类似于 `format()`，但它将表达式的 [`Writable`](/docs/std/format/Writable/) 表示形式插入到替换字段中。这提供了安全且灵活的字符串处理：

```mojo
var count = 3
var items = "apples"
var template = t"Give me {count} {items}." # Template string
print(template) # Output: Give me 3 apples.
```

`TString` 值是惰性的。在你显式构造 `String` 之前，它们不会分配内存：

```mojo
var x = 41
print(t"The answer is {x + 1}")  # The answer is 42 (no allocation)

var name = "Nate"
var template = t"Hello, {name}!" # template creation

print(template)          # Hello, Nate! (no allocation)
var s = String(template) # explicitly construct a string
```

`TString` 可以在替换字段中添加任意表达式：

```mojo
var list = [1, 2, 3]
print(t"{list[0] + list[1]}") # 3
```

### 原始字符串

在 Mojo 中，**原始字符串**（raw string）是带有 `r` 前缀的字符串字面量。如果你运行以下命令，它会在一行上打印，而不是两行，因为原始字符串会阻止反斜杠转义序列被解释：

```mojo
print(r"Hello\nWorld")  # Hello\nWorld, with the backslash and n
```

原始字符串对正则表达式、代码生成、序列化代码以及其他你希望将转义序列作为字面条目用于字符串的应用场景很有用。与普通字符串不同，原始字符串中的转义序列不会被处理。

原始性适用于所有形式的字符串：单行、多行、文档字符串和 `TString`。原始 `TString` 支持插值，但不会展开转义序列：

```mojo
var name = "Nate"
print(rt"Hello,\t{name}.")  # Hello,\tNate., with the backslash and t
```

原始字符串*仍然*需要一种方式来终止，因此如果你必须在内容中使用 `"`，请使用其他形式的引号（如单引号 `(')` 或三引号（`"""`、`'''`））将其包围：

```mojo
r'She said, "Hello, World!"'
```

### 字符串字面量

与数值类型一样，标准库包含一个字符串字面量类型，用于表示程序源代码中的字面量字符串。字符串字面量用单引号或双引号包围。

相邻的字面量会被连接在一起，因此你可以使用一系列跨多行拆分的字面量来定义一个长字符串：

```mojo
comptime s = "A very long string which is "
        "broken into two literals for legibility."
```

要定义多行字符串，请用三个单引号或双引号将字面量包围：

```mojo
comptime s = """
Multi-line string literals let you
enter long blocks of text, including
newlines."""
```

注意，三双引号形式也用于 API 文档字符串。

`StringLiteral` 在运行时使用时会实例化为 `String`：

```mojo
comptime param = "foo"        # type = StringLiteral
var runtime_value = "bar"  # type = String
var runtime_value2 = param # type = String
```

## 布尔值

Mojo 的 `Bool` 类型表示布尔值。它可以取 `True` 或 `False` 两个值之一。你可以使用 `not` 运算符对布尔值取反。

```mojo
var conditionA = False
var conditionB: Bool
conditionB = not conditionA
print(conditionA, conditionB)
```

```output
False True
```

许多类型都有布尔表示。任何实现了 [`Boolable`](/docs/std/builtin/bool/Boolable/) trait 的类型都有布尔表示。作为一般原则，集合在包含任何元素时求值为 True，在为空时求值为 False；字符串在长度非零时求值为 True。

## 元组

Mojo 的 `Tuple` 是一种轻量级、固定大小、异构且具有值语义的集合。元组包含零个或多个用逗号分隔的值，这些值可以具有不同的类型。虽然元组的结构（其大小和元素类型）是固定的，但单个元素可以被修改。元组支持多种形式的索引：

```mojo
# Tuples are immutable and can hold multiple types
var example_tuple = Tuple[Int, String](1, "Example")

# Assign multiple variables at once
var x, y = example_tuple
print(x, y)

# Get individual values with an index
var s = example_tuple[1]
print(s)
```

```output
1 Example
Example
```

你也可以在不显式指定类型的情况下创建元组。

```mojo
var example_tuple = (1, "Example")
var s = example_tuple[1]
print(s)
```

```output
Example
```

## 集合类型

Mojo 标准库还包括一组基本的集合类型，可用于构建更复杂的数据结构：

- [`List`](/docs/std/collections/list/List/)，元素的动态大小数组。
- [`Dict`](/docs/std/collections/dict/Dict/)，键值对的关联数组。
- [`Set`](/docs/std/collections/set/Set/)，唯一元素的无序集合。
- [`Optional`](/docs/std/collections/optional/Optional/) 表示一个可能存在也可能不存在的值。

集合类型是*参数化类型*：虽然给定的集合只能持有特定类型的值（如 `Int` 或 `Float64`），但你是在编译时使用[参数](/docs/manual/parameters/)指定类型的。例如，你可以像下面这样创建一个 `Int` 值的 `List`：

```mojo
var l: List[Int] = [1, 2, 3, 4]
# l.append(3.14) # error: FloatLiteral cannot be converted to Int
```

你并不总是需要显式指定类型。如果 Mojo 可以*推断*出类型，你就可以省略它。例如，当你从一组整数字面量构造列表时，Mojo 会创建一个 `List[Int]`。

```mojo
# Inferred type == List[Int]
var l1 = [1, 2, 3, 4]
```

当你需要更灵活的集合时，[`Variant`](/docs/std/utils/variant/Variant/) 类型可以持有不同类型的值。例如，`Variant[Int32, Float64]` 在任意时刻可以持有 `Int32` *或* `Float64` 值。（本节不会涉及 `Variant` 的使用，请参阅 [API 文档](/docs/std/utils/variant/Variant/) 获取更多信息。）

以下章节简要介绍主要的集合类型。

### List

[`List`](/docs/std/collections/list/List/) 是一种动态大小的元素数组。List 的元素需要遵循 [`Copyable`](/docs/std/builtin/value/Copyable/) trait。大多数常见的标准库原语（如 `Int`、`String` 和 `SIMD`）都遵循此 trait。你可以像下面这样通过将元素类型作为参数传递来创建 `List`：

```mojo
var l = List[String]()
```

`List` 类型支持 Python `list` API 的一个子集，包括向列表追加元素、从列表中弹出元素以及使用下标表示法访问列表项的能力。

```mojo
var list = [2, 3, 5]
list.append(7)
list.append(11)
print("Popping last item from list: ", list.pop())
for idx in range(len(list)):
      print(list[idx], end=", ")
```

```output
Popping last item from list:  11
2, 3, 5, 7,
```

注意，前面的代码示例在创建列表时省略了类型参数。由于列表是用一组 `Int` 值创建的，Mojo 可以从参数中*推断*出类型。

- Mojo 支持列表、集合和字典字面量用于集合初始化：

  ```mojo
  # List literal, element type infers to Int.
  var nums = [2, 3, 5]
  ```

  如果想要特定的元素类型，也可以使用显式类型：

  ```mojo
  var list : List[UInt8] = [2, 3, 5]
  ```

  你还可以使用列表"推导式"进行紧凑的条件初始化：

  ```mojo
  var list2 = [x*Int(y) for x in nums for y in list if x != 3]
  ```

- 你不能 `print()` 一个列表，也不能直接将其转换为字符串。

  ```mojo
  # Does not work
  print(list)
  ```

  如上所示，只要元素是 [`Writable`](/docs/std/format/Writable/) 类型，你就可以打印列表中的各个元素。

- 迭代 `List` 会返回每个元素的不可变[引用](/docs/manual/values/lifetimes/#working-with-references)：

```mojo
var list = [2, 3, 4]
for item in list:
      print(item, end=", ")
```

```output
2, 3, 4,
```

如果你想修改列表的元素，请用 `ref` 捕获对元素的引用，而不是创建副本：

```mojo
var list = [2, 3, 4]
for ref item in list:     # Capture a ref to the list element
      print(item, end=", ")
      item = 0  # Mutates the element inside the list
print("\nAfter loop:", list[0], list[1], list[2])
```

```output
2, 3, 4,
After loop: 0 0 0
```

你可以看到原始的循环条目已被修改。

### Dict

[`Dict`](/docs/std/collections/dict/Dict/) 类型是一个保存键值对的关联数组。你可以通过将键类型和值类型指定为参数并使用字典字面量来创建 `Dict`：

```mojo
# Empty dictionary
var empty_dict: Dict[String, Float64] = {}

# Dictionary with initial key-value pairs
var values: Dict[String, Float64] = {"pi": 3.14159, "e": 2.71828}
```

你也可以使用初始化器语法：

```mojo
var values = Dict[String, Float64]()
```

字典的键类型必须遵循 [`KeyElement`](/docs/std/collections/dict/#keyelement) trait，值元素必须遵循 [`Copyable`](/docs/std/builtin/value/Copyable/) trait。

你可以插入和删除键值对，更新分配给某个键的值，以及遍历字典中的键、值或项。

`Dict` 的迭代器都会产出[引用](/docs/manual/values/lifetimes/#working-with-references)，默认情况下它们会被复制到所声明的名称中，但你可以使用 `ref` 标记来避免复制：

```mojo
var d: Dict[String, Float64] = {
    "plasticity": 3.1,
    "elasticity": 1.3,
    "electricity": 9.7
}
for item in d.items():
    print(item.key, item.value)
```

```output
plasticity 3.1000000000000001
elasticity 1.3
electricity 9.6999999999999993
```

在这种情况下，这是一种无法衡量的微优化，但在处理不可 `Copyable` 的类型时很有用。

### Set

[`Set`](/docs/std/collections/set/Set/) 类型表示一个唯一值的集合。你可以向集合中添加和删除元素，测试某个值是否存在于集合中，以及执行集合代数运算（如两个集合之间的并集和交集）。

集合是参数化的，元素类型必须遵循 [`KeyElement`](/docs/std/collections/dict/#keyelement) trait。与列表和字典一样，集合支持标准的字面量语法以及生成器推导式：

```mojo
var i_like = {"sushi", "ice cream", "tacos", "pho"}
var you_like = {"burgers", "tacos", "salad", "ice cream"}
var we_like = i_like.intersection(you_like)

print("We both like:")
for item in we_like:
    print("-", item)
```

```output
We both like:
- ice cream
- tacos
```

### Optional

[`Optional`](/docs/std/collections/optional/Optional/) 表示一个可能存在也可能不存在的值。与其他集合类型一样，它是参数化的，可以持有任何遵循 [`Copyable`](/docs/std/builtin/value/Copyable/) trait 的类型。

```mojo
# Two ways to initialize an Optional with a value
var opt1 = Optional(5)
var opt2: Optional[Int] = 5
# Two ways to initialize an Optional with no value
var opt3 = Optional[Int]()
var opt4: Optional[Int] = None
```

当 `Optional` 持有值时，它求值为 `True`，否则求值为 `False`。如果 `Optional` 持有值，你可以使用 `value()` 方法检索对该值的引用。但在没有值的 `Optional` 上调用 `value()` 会导致未定义行为，因此你应当始终在检查是否存在值的条件语句中保护对 `value()` 的调用。

```mojo
var opt: Optional[String] = "Testing"
if opt:
    var value_ref = opt.value()
    print(value_ref)
```

```output
Testing
```

或者，你可以使用 `or_else()` 方法，该方法在存在存储值时返回该存储值，否则返回用户指定的默认值：

```mojo
var custom_greeting: Optional[String] = None
print(custom_greeting.or_else("Hello"))  # Hello

custom_greeting = "Hi"
print(custom_greeting.or_else("Hello"))  # Hi
```
