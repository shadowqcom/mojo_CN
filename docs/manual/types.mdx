Mojo 中的所有值都有关联的数据类型。大多数类型是*名义类型*，由 [`struct`](/docs/manual/structs/) 定义。这些类型是名义的（或"命名"）类型，因为类型相等性由类型的*名称*决定，而不是由其*结构*决定。

有一些类型不是作为结构定义的：

- 函数根据其签名进行类型化。
- `NoneType` 是一种类型，只有一个实例，即 `None` 对象，用于表示"无值"。

Mojo 附带一个标准库，提供许多有用的类型和实用函数。这些标准类型不是特权类型。每个标准库类型都像用户定义类型一样定义——即使是像 [`Int`](/docs/std/builtin/int/Int/) 和 [`String`](/docs/std/collections/string/string/String/) 这样的基本类型。但这些标准库类型是你将用于大多数 Mojo 程序的构建块。

最常见的类型是*内置类型*，它们始终可用，无需导入。这包括数值、字符串、布尔值等的类型。

标准库还包括许多其他类型，你可以按需导入，包括集合类型、与文件系统交互和获取系统信息的工具等。

## 数值类型

Mojo 提供内置数值类型，表示有符号整数、无符号整数和浮点值。这些类型支持多种精度，用于对低级数据和高级数值计算进行建模。

以下章节介绍 Mojo 中的整数和浮点类型。

:::note
所有数值类型都支持常规数值和按位运算符。[`math`](/docs/std/math/) 模块提供了额外的数学函数。
:::

### 整数和无符号整数

Mojo 支持有符号 (`Int`) 和无符号 (`UInt`) 整数类型。这些类型包括固定大小和通用类型：

- 如果你需要固定大小的整数，Mojo 提供显式宽度整数类型，如 `Int8`、`Int16`、`UInt32` 和 `UInt64`。这些固定精度整数类型是 [`SIMD`](/docs/std/builtin/simd/SIMD/) 类型的别名。

- 当你不需要特定位宽时，使用通用 `Int` 或 `UInt` 类型。

`Int` 表示使用系统原生字大小的有符号整数，通常在 64 位 CPU 上为 64 位，在 32 位 CPU 上为 32 位。同样，`UInt` 表示使用系统默认字大小的无符号整数。

你可能想知道何时使用 `Int`，何时使用其他整数类型。通常，`Int` 是一个很好的安全默认值，当你需要整数类型且不需要特定位宽时。使用 `Int` 作为 API 的默认整数类型会使 API 更一致和可预测。

#### 有符号与无符号

具有相同位宽的有符号和无符号整数可以表示相同数量的不同值，但在不同范围内。例如：

- `Int8` 表示从 `-128` 到 `127` 的 256 个值
- `UInt8` 表示从 `0` 到 `255` 的 256 个值

#### 溢出行为

有符号和无符号整数在处理溢出的方式上有所不同。

- 当有符号整数溢出时，值使用二进制补码算术环绕到负范围。例如，向 `var si: Int8 = 127` 添加 `1` 结果为 `-128`。
- 当无符号整数溢出时，值环绕到其范围的开始。例如，向 `var ui: UInt8 = 255` 添加 `1` 结果为 `0`。

当不需要负值、你正在设计公共 API、或者你想最大化可用正范围时，你可能更喜欢无符号整数。

### 浮点数

Mojo 提供几种浮点类型，用于以不同精度表示实数。由于浮点值使用固定数量的位，有些数字无法精确表示。

浮点类型 `Float64`、`Float32` 和 `Float16` 遵循 IEEE 754-2008 标准来表示浮点值。每种类型都包括一个符号位、一组表示指数的位，以及一组表示尾数（也称为分数或有效数字）的位。表 3 显示了这些类型如何在内存中表示。

<figure id="table-3">
<figcaption><b>表 3.</b> 浮点类型详细信息</figcaption>

| 类型名称 | 符号  | 指数 | 尾数 |
|-----------|-------|----------|----------|
| `Float64` | 1 位 | 11 位  | 52 位  |
| `Float32` | 1 位 | 8 位   | 23 位  |
| `Float16` | 1 位 | 5 位   | 10 位  |

</figure>

所有零或全一的指数值表示特殊情况。这些模式允许浮点数编码正负无穷大、有符号零和非数字 (NaN)。这些值作为 [`FloatLiteral`](/docs/std/builtin/float_literal/FloatLiteral/) 提供的静态常量可用：

```mojo
from std.math import copysign
from std.utils.numerics import isfinite, isinf, isnan

var inf = FloatLiteral.infinity
print(isinf(inf))  # `True`
print(inf > 0)     # `True`

var neginf = FloatLiteral.negative_infinity
print(isinf(neginf))  # `True`
print(neginf < 0)     # `True`

var nan = FloatLiteral.nan
print(isnan(nan))  # `True`

var negzero = FloatLiteral.negative_zero
print(negzero == 0.0)              # `True`
print(copysign(1.0, negzero) < 0)  # `True`
```

有关浮点数表示的更多详细信息，请参阅 [IEEE 754](https://en.wikipedia.org/wiki/IEEE_754)。

#### 浮点近似和比较

由于浮点值是近似的，它们通常无法表示它们旨在建模的确切数学值。

- **舍入误差。** 舍入可能会产生意外结果。例如，`1/3` 无法在浮点格式中精确表示。随着更多浮点运算的执行，舍入误差可能会累积。

- **连续数字之间的间隔。** 可表示值之间的距离在浮点类型的范围内变化。接近零时，值密集打包。对于大的正数或负数，间距可能超过 1，使得无法表示某些连续整数。

由于值是近似的，使用相等运算符 (`==`) 比较浮点数很少有用。例如：

```mojo
var big_num = 1.0e16
var bigger_num = big_num + 1.0
print(big_num == bigger_num)
```

```output
True
```

比较运算符（如 `<` 和 `>=`）与浮点值一起按预期工作。要测试两个值是否在容差范围内相等，请使用 [`math.isclose()`](/docs/std/math/math/isclose/) 函数来比较两个浮点数是否在指定容差范围内相等。

#### Mojo 支持的浮点类型

在以下表中，**eXmX** 格式（例如 `Float8_e5m2` 和 `Float8_e4m3fn`）指的是分配给浮点数的指数和尾数的位数。

所有 IEEE 754 浮点格式都使用隐式的前导 1。这意味着 `Float32` 是 e8m23 但实际上是 e8m24，`Float16` 是 e5m10 但实际上是 e5m11，`BFloat16` 是 e8m7 但实际上是 e8m8，而 `Float8_e4m3fn` 是 e4m3 但实际上是 e4m4。

除了 eXmX 之外：

- **fn** 表示仅限有限数。这些数字是有效的浮点值，不是无限的。支持 NaN。
- **uz** 表示无符号零。仅支持 +0，不支持 -0。

虽然 Mojo 支持所有这些类型，但并非所有硬件都支持这些类型。

:::note
`BFloat16` 中的 *B* 代表 Brain，来自 Google Brain 人工智能研究小组。Google 开发它是专门用于他们的张量处理单元 (TPU) 以加速机器学习工作负载的。因此 B 是项目标识符，而不是技术格式指示符。
:::

#### AI 优化的浮点格式

几种浮点类型专门为 AI 和机器学习工作负载设计，以精度换取内存效率和计算吞吐量。

**BFloat16 (Brain 浮点)** 使用与 `Float32` 相同的 8 个指数位，保持其动态范围，但与 Float32 的 23 位相比，尾数使用 7 个显式位（8 个有效位）。这使其非常适合梯度幅度变化很大但高精度不太重要的神经网络训练。

**8 位格式** (`Float8_e5m2`、`Float8_e4m3fn` 及其 `fnuz` 变体) 是 AI 加速器的超紧凑格式，其中内存带宽是主要瓶颈。命名指示位分配：`e5m2` 表示 5 个指数位和 2 个尾数位。`fnuz` 后缀还表示无符号零（无 -0），用于 AMD 硬件。

**4 位格式** (`Float4_e2m1fn`) 仅提供 2 个指数位和 1 个尾数位的极端压缩，用于精度可以换取最大吞吐量的专用推理场景。

## 数值字面量

除了这些数值类型，标准库还提供整数和浮点字面量类型，[`IntLiteral`](/docs/std/builtin/int_literal/IntLiteral/) 和 [`FloatLiteral`](/docs/std/builtin/float_literal/FloatLiteral/)。

这些字面量类型在编译时用于表示代码中出现的字面量数字。通常，你绝不应该自己实例化这些类型。

表 5 概述了你可以用来表示数字的字面量格式。

<figure>
<figcaption><b>表 5.</b> 数值字面量格式</figcaption>

| 格式                 | 示例        | 注释                                                                                            |
|------------------------|-----------------|--------------------------------------------------------------------------------------------------|
| 整数字面量        | `1760`          | 整数字面量，十进制格式。                                                              |
| 十六进制字面量    | `0xaa`, `0xFF`  | 整数字面量，十六进制格式。<br />十六进制数字不区分大小写。                    |

在编译时，字面量类型是任意精度（也称为无限精度）值，因此编译器可以执行编译时计算而不会溢出或舍入错误。

在运行时，值转换为有限精度类型——整数值为 `Int`，浮点值为 `Float64`。（这种将仅在编译时存在的值转换为运行时值的过程称为*实例化*。）

以下代码示例显示了任意精度计算与使用 `Float64` 值在运行时执行相同计算的差异，后者会受到舍入错误的影响。

```mojo
var arbitrary_precision = 3.0 * (4.0 / 3.0 - 1.0)
# 使用变量强制以下计算在运行时发生
var three = 3.0
var finite_precision = three * (4.0 / three - 1.0)
print(arbitrary_precision, finite_precision)
```

```output
1.0 0.99999999999999978
```

### `SIMD` 和 `DType`

为了支持高性能数值处理，Mojo 使用 [`SIMD`](/docs/std/builtin/simd/SIMD/) 类型作为其数值类型的基础。SIMD（单指令，多数据）是一种处理器技术，允许你一次对一组操作数执行操作。Mojo 的 `SIMD` 类型抽象了 SIMD 运算。`SIMD` 值表示 SIMD *向量*——即可以放入处理器寄存器的固定大小值数组。SIMD 向量由两个 [*参数*](/docs/manual/parameters/) 定义：

- 一个 `DType` 值，定义向量中的数据类型（例如，32 位浮点数）。
- 向量中的元素数量，必须是 2 的幂。

例如，你可以这样定义四个 `Float32` 值的向量：

```mojo
var vec = SIMD[DType.float32, 4](3.0, 2.0, 2.0, 1.0)
```

SIMD 值上的数学运算在向量中的每个单个元素上*逐元素*应用。例如：

```mojo
var vec1 = SIMD[DType.int8, 4](2, 3, 5, 7)
var vec2 = SIMD[DType.int8, 4](1, 2, 3, 4)
var product = vec1 * vec2
print(product)
```

```output
[2, 6, 15, 28]
```

### 标量值

`SIMD` 模块定义了几个 [`comptime` 值](/docs/manual/metaprogramming/comptime-evaluation/#comptime-values)，它们充当*类型别名*——不同类型 `SIMD` 向量的简写名称。特别是，`Scalar` 类型只是一个具有单个元素的 `SIMD` 向量。[表 1](#table-1) 中列出的数值类型，如 `Int8` 和 `Float32` 实际上是不同类型标量值的类型别名：

```mojo
comptime Scalar = SIMD[size=1]
comptime Int8 = Scalar[DType.int8]
comptime Float32 = Scalar[DType.float32]
```

起初这可能看起来有点令人困惑，但这意味着无论你是在处理单个 `Float32` 值还是浮点值向量，数学运算都经过完全相同的代码路径。

#### `DType` 类型

`DType` 结构描述了 `SIMD` 向量可以持有的不同数据类型，并定义了许多用于对这些数据类型进行操作的实用函数。`DType` 结构定义了一组 [`comptime` 成员](/docs/manual/parameters/#comptime-members)，它们作为不同数据类型的标识符，如 `DType.int8` 和 `DType.float32`。在声明 `SIMD` 向量时使用这些 `comptime` 成员：

```mojo
var v: SIMD[DType.float64, 16]
```

请注意，`DType.float64` 不是*类型*，它是一个描述数据类型的值。你不能创建类型为 `DType.float64` 的变量。你可以创建类型为 `SIMD[DType.float64, 1]`（或 `Float64`，这是相同的）的变量。

```mojo
from std.utils.numerics import max_finite, min_finite

def describeDType[dtype: DType]():
    print(dtype, "is floating-point:", dtype.is_floating_point())
    print(dtype, "is integral:", dtype.is_integral())
    print("Min/max finite values for", dtype)
    print(min_finite[dtype](), max_finite[dtype]())

describeDType[DType.float32]()
```

```output
float32 is floating-point: True
float32 is integral: False
Min/max finite values for float32
-3.4028234663852886e+38 3.4028234663852886e+38
```

标准库中还有其他几种数据类型也使用 `DType` 抽象。

### 数值类型转换

[构造函数和隐式转换](/docs/manual/lifecycle/life/#constructors-and-implicit-conversion) 记录了 Mojo 自动将值从一个类型转换为另一个类型的情形。重要的是，数值 [运算符](/docs/manual/operators/) **不会**自动将操作数收窄或扩展为通用类型。

你可以通过调用其 [`cast()`](/docs/std/builtin/simd/SIMD/#cast) 方法或将值作为参数传递给目标类型的构造函数，将 `SIMD` 值显式转换为不同的 `SIMD` 类型。例如：

```mojo
simd1 = SIMD[DType.float32, 4](2.2, 3.3, 4.4, 5.5)
simd2 = SIMD[DType.int16, 4](-1, 2, -3, 4)
simd3 = simd1 * simd2.cast[DType.float32]()  # 使用 cast() 方法转换
print("simd3:", simd3)
simd4 = simd2 + SIMD[DType.int16, 4](simd1)  # 使用 SIMD 构造函数转换
print("simd4:", simd4)
```

```output
simd3: [-2.2, 6.6, -13.200001, 22.0]
simd4: [1, 5, 1, 9]
```

你可以通过将值作为参数传递给目标类型的构造函数来转换 `Scalar` 值。例如：

```mojo
var my_int: Int16 = 12                 # SIMD[DType.int16, 1]
var my_float: Float32 = 0.75           # SIMD[DType.float32, 1]
result = Float32(my_int) * my_float    # 结果是 SIMD[DType.float32, 1]
print("Result:", result)
```

```output
Result: 9.0
```

你可以通过将值传递给 [`Int()`](/docs/std/builtin/int/Int/#__init__) 构造函数方法，将任何数值类型的标量值转换为 `Int`。此外，你可以将实现 [`Intable`](/docs/std/builtin/int/Intable/) trait 或 [`IntableRaising`](/docs/std/builtin/int/IntableRaising/) trait 的任何结构的实例传递给 `Int()` 构造函数，将该实例转换为 `Int`。

你可以通过将值传递给 [`UInt()`](/docs/std/builtin/simd/#uint) 构造函数，将 `Int` 或 `IntLiteral` 值转换为 `UInt` 类型。不过，你不能直接将其他数值类型转换为 `UInt`，但你可以先将它们转换为 `Int`，然后再转换为 `UInt`。

## 字符串

字符串是 Mojo 的主要文本类型。它们存储 UTF-8 编码的文本，并为字符串操作提供安全、方便的接口。

Mojo 的 `String` 类型是可变字符串。`String` 支持各种运算符和常用方法：

```mojo
var s: String = "Testing"
s += " Mojo strings"
print(s) # Testing Mojo strings
```

### 构造

许多标准库类型符合 [`Writable`](/docs/std/format/Writable/) trait，这表示值可以使用 `String(...)` 构造函数转换为 `String`。

内置的 [`print()`](/docs/std/io/io/print/) 函数接受符合 `Writable` trait 的值。

使用 `String(value)` 显式将值转换为 `String`：

```mojo
var s = "Items in list: " + String(5)
print(s) # Items in list: 5
```

或者，使用带可变 `Writable` 类型的字符串构造函数，这样你就不必对每个值调用 `String()`：

```mojo
var s = String("Items in list: ", 5)
print(s) # Items in list: 5
```

### 表情符号和图符簇

Mojo 源文件是 UTF-8，允许你直接在字符串字面量中编写表情符号和其他非 ASCII 字符。

```mojo
var wave = "👋"
```

标准库以三种不同方式计算表情符号，答案通常不一致：

- `byte_length()` 返回 UTF-8 字节的数量。
- `count_codepoints()` 计算Unicode 码点。
- `count_graphemes()` 返回用户感知的字符（图符簇）数量，遵循 [UAX #29](https://www.unicode.org/reports/tr29/)。

图符计数是与你要求某人"计数字符"时他们会告诉你的相符的。家庭表情符号、旗帜和带肤色挥手的手各是一个图符，即使每个都是由几个连接的码点组成的：

```mojo
def show(label: StaticString, s: StringSlice):
    print(
        label,
        "bytes=", s.byte_length(),
        "codepoints=", s.count_codepoints(),
        "graphemes=", s.count_graphemes(),
    )

def main():
    show("family    ", "👨‍👩‍👧‍👦")
    show("flag      ", "🇺🇸")
    show("wave      ", "👋🏽")
    show("namaste   ", "नमस्ते")
```

输出：

```text
family     bytes=25  codepoints=7  graphemes=1
flag       bytes=8   codepoints=2  graphemes=1
wave       bytes=8   codepoints=2  graphemes=1
namaste    bytes=18  codepoints=6  graphemes=3
```

如果你不想在源代码中嵌入非 ASCII 字节，例如在仅限 ASCII 的代码库中，你可以使用十六进制转义或 `chr()` 来拼写码点：

```mojo
var wave = "\U0001F44B"   # 8 位十六进制转义
var wave2 = chr(0x1F44B)  # chr() 函数

var copy   = "\u00A9"   # 4 位十六进制转义，©
var euro   = "\u20AC"   # 4 位十六进制转义，€
```

Mojo 的 4 位 `\uHHHH` 转义拼写最多到 U+FFFF 的码点。8 位 `\U` 形式扩展到 U+10FFFF（Unicode 的上限），覆盖像 👋 (U+1F44B) 等表情符号和其他基本多语言平面以上的字符。`chr()` 函数也适用于完整范围。

这两种形式都拒绝代理码点（U+D800 到 U+DFFF）。代理是为 UTF-16 编码保留的，它们本身不是有效的。要转义 U+FFFF 以上的字符，请使用 `\U` 写入其完整码点。不要使用 UTF-16 代理对。

### 字符串格式化

`format()` 方法使用手动或自动位置索引将值插入字符串。替换字段使用大括号：

```mojo
print("{0} {1} {0}".format("Mojo", 1.125))  # Mojo 1.125 Mojo
print("{} {}".format(True, "hello world"))  # True hello world
```

Mojo 的 `TString`（模板字符串）用直接表达式和更好的性能特性替换了 `format()` 方法的功能。

`TString` 的工作方式与 `format()` 相同，但它们将表达式的 [`Writable`](/docs/std/format/Writable/) 表示插入替换字段。这提供了安全灵活的字符串处理：

```mojo
var count = 3
var items = "apples"
var template = t"Give me {count} {items}." # 模板字符串
print(template) # 输出：Give me 3 apples.
```

`TString` 值是惰性的。它们不会分配内存，直到你显式构造一个 `String`：

```mojo
var x = 41
print(t"The answer is {x + 1}")  # The answer is 42 (无分配)

var name = "Nate"
var template = t"Hello, {name}!" # 模板创建

print(template)          # Hello, Nate! (无分配)
var s = String(template) # 显式构造字符串
```

`TString` 可以在替换字段中添加任意表达式：

```mojo
var list = [1, 2, 3]
print(t"{list[0] + list[1]}") # 3
```

### 原始字符串

在 Mojo 中，**原始字符串**是带有 `r` 前缀的字符串字面量。如果你运行以下命令，它将在一行上打印，而不是两行，因为原始字符串阻止反斜杠转义序列被解释：

```mojo
print(r"Hello\nWorld")  # Hello\nWorld，带有反斜杠和 n
```

原始字符串有助于正则表达式、代码生成、序列化代码和其他应用程序，你希望在这些应用程序中将转义序列作为字符串中的字面条目使用。与普通字符串不同，转义序列不会被处理。

原始性适用于所有形式的字符串：单行、多行、文档字符串和 `TString`。原始 `TString` 支持插值但不会展开转义序列：

```mojo
var name = "Nate"
print(rt"Hello,\t{name}.")  # Hello,\tNate.,带有反斜杠和 t
```

原始字符串*仍然*需要一种终止方式，因此如果你必须在内容中使用 `"`，请使用另一种引号形式，如单引号 (`'`) 或三引号 (`"""`、`'''`) 来包围它：

```mojo
r'She said, "Hello, World!"'
```

### 字符串字面量

与数值类型一样，标准库包括一个字符串字面量类型，用于表示程序源中的字面量字符串。字符串字面量包含在单引号或双引号中。

相邻的字面量被连接在一起，因此你可以使用一系列跨多行拆分的字面量来定义长字符串：

```mojo
comptime s = "A very long string which is "
        "broken into two literals for legibility."
```

要定义多行字符串，请用三个单引号或双引号包围字面量：

```mojo
comptime s = """
Multi-line string literals let you
enter long blocks of text, including
newlines."""
```

请注意，三双引号形式也用于 API 文档字符串。

`StringLiteral` 在运行时使用时会实例化为 `String`：

```mojo
comptime param = "foo"        # type = StringLiteral
var runtime_value = "bar"  # type = String
var runtime_value2 = param # type = String
```

## 布尔值

Mojo 的 `Bool` 类型表示布尔值。它可以取两个值之一，`True` 或 `False`。你可以使用 `not` 运算符对布尔值进行求反。

```mojo
var conditionA = False
var conditionB: Bool
conditionB = not conditionA
print(conditionA, conditionB)
```

```output
False True
```

许多类型都有布尔表示形式。任何实现 [`Boolable`](/docs/std/builtin/bool/Boolable/) trait 的类型都有布尔表示形式。作为一般原则，如果集合包含任何元素则为 True，如果为空则为 False；字符串如果具有非零长度则为 True。

## 元组

Mojo 的 `Tuple` 类型表示由零个或多个值组成的不可变元组，用逗号分隔。元组可以由多种类型组成，你可以以多种方式索引元组。

```mojo
# 元组是不可变的，可以包含多种类型
example_tuple = Tuple[Int, String](1, "Example")

# 一次分配多个变量
x, y = example_tuple
print(x, y)

# 使用索引获取单个值
s = example_tuple[1]
print(s)
```

```output
1 Example
Example
```

你也可以不使用显式类型创建元组。

```mojo
example_tuple = (1, "Example")
s = example_tuple[1]
print(s)
```

```output
Example
```

## 集合类型

Mojo 标准库还包括一组基本集合类型，可用于构建更复杂的数据结构：

- [`List`](/docs/std/collections/list/List/)，元素的动态大小数组。
- [`Dict`](/docs/std/collections/dict/Dict/)，键值对关联数组。
- [`Set`](/docs/std/collections/set/Set/)，唯一项目的无序集合。
- [`Optional`](/docs/std/collections/optional/Optional/)
  表示可能存在也可能不存在的值。

集合类型是*泛型类型*：虽然给定集合只能包含特定类型的值（如 `Int` 或 `Float64`），但你使用[参数](/docs/manual/parameters/)在编译时指定类型。例如，你可以这样创建 `Int` 值的 `List`：

```mojo
var l: List[Int] = [1, 2, 3, 4]
# l.append(3.14) # 错误：FloatLiteral 无法转换为 Int
```

你并不总是需要显式指定类型。如果 Mojo 可以*推断*类型，你可以省略它。例如，当你从一组整数字面量构造列表时，Mojo 创建一个 `List[Int]`。

```mojo
# 推断的类型 == List[Int]
var l1 = [1, 2, 3, 4]
```

当你需要更灵活的集合时，[`Variant`](/docs/std/utils/variant/Variant/) 类型可以持有不同类型的值。例如，`Variant[Int32, Float64]` 可以在任何给定时间持有 `Int32` *或* `Float64` 值。（本节不涉及使用 `Variant`，请参阅 [API 文档](/docs/std/utils/variant/Variant/) 获取更多信息。）

以下章节简要介绍了主要集合类型。

### List

[`List`](/docs/std/collections/list/List/) 是元素的动态大小数组。列表元素需要符合 [`Copyable`](/docs/std/builtin/value/Copyable/) trait。大多数常见标准库原语，如 `Int`、`String` 和 `SIMD` 都符合此 trait。你可以通过将元素类型作为参数传递来创建 `List`，如下所示：

```mojo
var l = List[String]()
```

`List` 类型支持 Python `list` API 的子集，包括追加到列表、从列表中弹出项目和使用下标表示法访问列表项的功能。

```mojo
var list = [2, 3, 5]
list.append(7)
list.append(11)
print("Popping last item from list: ", list.pop())
for idx in range(len(list)):
      print(list[idx], end=", ")
```

```output
Popping last item from list:  11
2, 3, 5, 7,
```

请注意，前面的代码示例在创建列表时省略了类型参数。由于列表是用一组 `Int` 值创建的，Mojo 可以从参数*推断*类型。

- Mojo 支持列表、集合和字典字面量用于集合初始化：

  ```mojo
  # 列表字面量，元素类型推断为 Int。
  var nums = [2, 3, 5]
  ```

  如果想要特定元素类型，也可以使用显式类型：

  ```mojo
  var list : List[UInt8] = [2, 3, 5]
  ```

  你还可以使用列表"推导式"进行紧凑的条件初始化：

  ```mojo
  var list2 = [x*Int(y) for x in nums for y in list if x != 3]
  ```

- 你不能 `print()` 列表，也不能直接将其转换为字符串。

  ```mojo
  # 不工作
  print(list)
  ```

  如上所示，只要元素是 [`Writable`](/docs/std/format/Writable/) 类型，你就可以打印列表中的各个元素。

- 迭代 `List` 会返回每个项目的不可变[引用](/docs/manual/values/lifetimes/#working-with-references)：

```mojo
var list = [2, 3, 4]
for item in list:
      print(item, end=", ")
```

```output
2, 3, 4,
```

如果你想修改列表的元素，请使用 `ref` 捕获对元素的引用而不是创建副本：

```mojo
var list = [2, 3, 4]
for ref item in list:     # 捕获列表元素的引用
      print(item, end=", ")
      item = 0  # 修改列表内的元素
print("\nAfter loop:", list[0], list[1], list[2])
```

```output
2, 3, 4,
After loop: 0 0 0
```

你可以看到原始循环条目已被修改。

### Dict

[`Dict`](/docs/std/collections/dict/Dict/) 类型是保存键值对的关联数组。你可以通过指定键类型和值类型作为参数并使用字典字面量来创建 `Dict`：

```mojo
# 空字典
var empty_dict: Dict[String, Float64] = {}

# 带有初始键值对的字典
var values: Dict[String, Float64] = {"pi": 3.14159, "e": 2.71828}
```

你也可以使用构造函数语法：

```mojo
var values = Dict[String, Float64]()
```

字典的键类型必须符合 [`KeyElement`](/docs/std/collections/dict/#keyelement) trait，值元素必须符合 [`Copyable`](/docs/std/builtin/value/Copyable/) trait。

你可以插入和删除键值对，更新分配给键的值，并遍历字典中的键、值或项目。

`Dict` 迭代器都返回[引用](/docs/manual/values/lifetimes/#working-with-references)，默认情况下它们被复制到声明的名称中，但你可以使用 `ref` 标记来避免复制：

```mojo
var d: Dict[String, Float64] = {
    "plasticity": 3.1,
    "elasticity": 1.3,
    "electricity": 9.7
}
for item in d.items():
    print(item.key, item.value)
```

```output
plasticity 3.1000000000000001
elasticity 1.3
electricity 9.6999999999999993
```

在这种情况下，这是一个无法测量的微优化，但在处理不是 `Copyable` 的类型时很有用。

### Set

[`Set`](/docs/std/collections/set/Set/) 类型表示唯一值集合。你可以向集合添加和删除元素，测试值是否存在于集合中，并执行集合代数运算，如两个集合之间的并集和交集。

集合是泛型的，元素类型必须符合 [`KeyElement`](/docs/std/collections/dict/#keyelement) trait。与列表和字典一样，集合支持标准字面量语法以及生成器推导式：

```mojo
i_like = {"sushi", "ice cream", "tacos", "pho"}
you_like = {"burgers", "tacos", "salad", "ice cream"}
we_like = i_like.intersection(you_like)

print("We both like:")
for item in we_like:
    print("-", item)
```

```output
We both like:
- ice cream
- tacos
```

### Optional

[`Optional`](/docs/std/collections/optional/Optional/) 表示可能存在也可能不存在的值。与其他集合类型一样，它是泛型的，可以持有任何符合 [`Copyable`](/docs/std/builtin/value/Copyable/) trait 的类型。

```mojo
# 两种用值初始化 Optional 的方法
var opt1 = Optional(5)
var opt2: Optional[Int] = 5
# 两种用无值初始化 Optional 的方法
var opt3 = Optional[Int]()
var opt4: Optional[Int] = None
```

当 `Optional` 持有值时，它计算为 `True`，否则为 `False`。如果 `Optional` 持有值，你可以使用 `value()` 方法检索对值的引用。但在没有值的 `Optional` 上调用 `value()` 会导致未定义行为，因此你应该始终在检查是否存在值的条件中保护对 `value()` 的调用。

```mojo
var opt: Optional[String] = "Testing"
if opt:
    var value_ref = opt.value()
    print(value_ref)
```

```output
Testing
```

或者，你可以使用 `or_else()` 方法，该方法在有存储值时返回存储的值，否则返回用户指定的默认值：

```mojo
var custom_greeting: Optional[String] = None
print(custom_greeting.or_else("Hello"))

custom_greeting = "Hi"
print(custom_greeting.or_else("Hello"))
```

```output
Hello
Hi
```
