## Hello Mojo

在你喜欢的 IDE 或编辑器中创建 `analyzer.mojo` 文件。

在 `analyzer.mojo` 中添加：

```mojo
def main():
    print("Temperature Analyzer")
```

运行它：

```sh
mojo analyzer.mojo
```

要点：

- 如果你看到 "Temperature Analyzer"，说明你的设置正常工作。
- 所有 Mojo 可执行程序都使用 `main()` 作为入口点。

## 变量和数据

更新你的文件，添加温度数据：

```mojo
def main():
    print("Temperature Analyzer")

    # [Float64] tells Mojo the `List` type at compile time
    var temps: List[Float64] = [20.5, 22.3, 19.8, 25.1]

    print("Recorded", len(temps), "temperatures")
```

## 循环

打印每个温度。在 `main()` 中的 print 语句后添加：

```mojo
def main():
    # ... existing code ...

    for index in range(len(temps)):  # The range is [0, len(temps))
        print(t"  Day {index + 1}: {temps[index]}°C")
```

要点：

- 天数偏移 1 是因为 range 使用从零开始的索引。
- `t"..."` 前缀创建一个*模板字符串*（template string）：花括号 `{}` 会将表达式直接插值到输出中。这很有用，因为它避免了为中间值分配内存。

## 函数

在 `main()` 上方添加此函数来计算平均温度：

```mojo
def calculate_average(temps: List[Float64]) -> Float64:
    # The 0.0 floating point literal defaults to Float64
    var total = 0.0
    for temp in temps:
        total += temp
    return total / Float64(len(temps))

def main():
    # ... existing code ...
```

在 `main()` 末尾添加调用函数的代码：

```mojo
    var avg = calculate_average(temps)
    print(t"Average: {round(avg, 2)}°C")
```

此代码使用 `round()` 将平均值限制为两位小数。

## 条件语句

对平均温度进行分类。在 `main()` 末尾添加：

```mojo
    if avg > 25.0:
        print("Status: Hot week")
    elif avg > 20.0:
        print("Status: Comfortable week")
    else:
        print("Status: Cool week")
```

## 抛出错误

通过更新 `calculate_average` 来处理空数据。现在函数可以抛出错误了。

```mojo
def calculate_average(temps: List[Float64]) raises -> Float64:
    if len(temps) == 0:  # Empty list of temperatures
        raise Error("No temperature data")

    var total = 0.0
    for temp in temps:
        total += temp
    return total / Float64(len(temps))
```

变化：

- 在返回箭头前添加 `raises`。
- 添加空列表检查。
- 如果为空则抛出 `Error`。

:::note

进行此更改后，你的应用还无法编译。因为 `calculate_average()` 现在可以抛出错误，`main()` 中对它的调用必须处理该错误。你将在下一步添加该处理。

:::

## 处理错误

在 `main()` 中，用 `try-except` 包装你的代码以处理错误：

```mojo
    try:
        var avg = calculate_average(temps)
        print(t"Average: {round(avg, 2)}°C")

        if avg > 25.0:
            print("Status: Hot week")
        elif avg > 20.0:
            print("Status: Comfortable week")
        else:
            print("Status: Cool week")
    except e:
        print("Error:", e)
```

要测试错误，将 `temps` 替换为 `[]`。
确认你的应用输出 "No temperature data" 错误。

## 完整代码

你的完整 `analyzer.mojo`：

```mojo
from std.python import Python, PythonObject
from std.python.numpy import copy_to_numpy_array


def calculate_average(temps: List[Float64]) raises -> Float64:
    if len(temps) == 0:
        raise Error("No temperature data")

    var total = 0.0
    for temp in temps:
        total += temp
    return total / Float64(len(temps))


def main():
    print("Temperature Analyzer")
    var temps: List[Float64] = [20.5, 22.3, 19.8, 25.1]
    print("Recorded", len(temps), "temperatures")

    for index in range(len(temps)):
        print(t"  Day {index + 1}: {temps[index]}°C")

    try:
        var avg = calculate_average(temps)
        print(t"Average: {round(avg, 2)}°C")

        if avg > 25.0:
            print("Status: Hot week")
        elif avg > 20.0:
            print("Status: Comfortable week")
        else:
            print("Status: Cool week")

        var np = Python.import_module("numpy")
        var pytemps = copy_to_numpy_array(temps)
        var std_dev = np.std(pytemps)
        print("Temperature standard deviation:", std_dev)
    except e:
        print("Error:", e)
```
