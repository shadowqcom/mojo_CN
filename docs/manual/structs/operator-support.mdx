每个 Mojo 运算符都映射到一组你可以添加到结构体实现中的 dunder 方法。这些方法让你可以使用运算符语法，而不必直接调用方法。

了解运算符及其相关方法，可以为你的自定义结构体开启完整的运算符语法套件。

## 前向、反向和原地方法

每个二元运算符最多使用三种方法形式。例如，考虑加法 `a + b`：

- **前向**（Forward）：Mojo 首先尝试 `a.__add__(b)`。
- **反向**（Reverse）：如果前向方法不存在或无法处理 `b` 的类型，Mojo 会回退到 `b.__radd__(a)`。
- **原地**（In-place）：对于 `a += b`，Mojo 调用 `a.__iadd__(b)`。

反向方法适用于左操作数不知道右操作数类型的混合类型表达式：

```mojo
a + 5    # calls a.__add__(5)
5 + a    # Int doesn't know your type, falls back
         # to a.__radd__(5)
a += 5   # calls a.__iadd__(5)
```

## 一元运算符

一元运算符在值未改变时返回原值，否则返回表示结果的新值。例如，`-x` 使用一元取负运算符：

```mojo
@fieldwise_init
struct MyInt:
    var value: Int

    def __neg__(self) -> Self:
        return Self(-self.value)
```

如果 `x` 是一个 `MyInt`，那么 `-x` 会返回一个新实例，其 `value` 字段被取负。

## 比较运算符与 trait

运算符并不要求你为类型遵循某个 trait。但是，这样做会有好处。

`Comparable` trait 为 `<=`、`>` 和 `>=` 提供了默认实现。你只需实现 `__lt__()` 和 `__eq__()`。

类似地，当所有字段都是 `Equatable` 时，`Equatable` trait 为 `__eq__()` 和 `__ne__()` 提供了默认实现。

对于没有自然排序的类型（例如复数），只需实现 `Equatable`，而不要实现 `Comparable`。

## 下标运算符

实现 `__getitem__()` 用于读取，`__setitem__()` 用于写入。两个下标方法都接受可变参数，以支持多维索引。

对于简单的一维集合，你可以用一个简单的索引来启用下标：

```mojo
struct MySeq[T: Copyable]:
    def __getitem__(self, idx: Int) -> T:
        ...
    def __setitem__(mut self, idx: Int, value: T):
        ...
```

对于多维集合，可以使用可变参数或多个索引参数：

```mojo
struct Grid[T: Copyable]:
    # Fixed two dimensions
    def __getitem__(self, x: Int, y: Int) -> T:
        ...
    # Arbitrary dimensions
    def __getitem__(self, *indices: Int) -> T:
        ...
```

自定义下标也可以支持切片以及索引，例如 `obj[1:5]`。使用一个 [`Slice`](/docs/std/builtin/builtin_slice/Slice/) 参数而不是 `Int` 来实现 `__getitem__()`。

每个 `Slice` 都有三个可选字段：`start`、`end` 和 `step`。你可以通过调用 `indices()` 来规范化它们。传入你类型的大小。这会返回一个三元组，表示根据你的尺寸调整后的范围，并将省略值或负索引解析为非负位置：

```mojo
struct MySeq[T: Copyable]:
    var size: Int

    def __getitem__(self, span: Slice) -> Self:
        var start: Int
        var end: Int
        var step: Int
        start, end, step = span.indices(self.size)
        ...
```

## 演练：构建一个 `Complex` 类型

接下来几个小节会逐步构建一个 `Complex` 结构体。这个示例演示了每一类运算符的实现。

在本演练中，你将使用一元运算符、具有相同类型和混合类型操作数的二元运算符、反向方法、原地赋值、相等比较、布尔转换以及下标访问。

:::note
标准库中包含 [`ComplexSIMD`](/docs/std/complex/complex/ComplexSIMD/)，它是一种参数化的复数类型，提供基本的算术支持。本示例中的 `Complex` 类型是独立的，并不基于 `ComplexSIMD`。
:::

## 创建基础类型

一个复数包含实部和虚部，分别存储在实部字段 `re` 和虚部字段 `im` 中：

```mojo
from std.math import sqrt

@fieldwise_init
struct Complex(
    Boolable,
    Equatable,
    TrivialRegisterPassable,
    Writable,
):
    var re: Float64
    var im: Float64
```

- 遵循 `TrivialRegisterPassable` 让你获得值语义，而无需编写特殊的生命周期方法。
- `Equatable` 让你可以比较两个实例，`Writable` 为 `print()` 语句生成输出。
- `Boolable` 让你可以在布尔上下文中使用 `Complex` 值，例如作为 `if` 条件。

### 便捷初始化方法

添加一个便捷初始化方法，让你可以仅使用数值的实部来创建实例：

```mojo
def __init__(out self, re: Float64):
    self.re = re
    self.im = 0.0
```

## 让你的类型可打印

实现 `Writable` 让你可以直接使用 `print()` 和 `String()`。这个自定义实现提供了圆括号，并分别输出实部和虚部。

```mojo
# Struct method
def write_to(self, mut writer: Some[Writer]):
    writer.write("(", self.re)
    if self.im < 0:
        writer.write(" - ", -self.im)
    else:
        writer.write(" + ", self.im)
    writer.write("i)")
```

你也可以实现 `write_repr_to()` 来定义该值的 *表示*（representation）——即由 `repr()` 返回的、面向开发者的形式。该实现会产生一个字符串，镜像出你在代码中构造该值的方式：

```mojo
# Struct method
def write_repr_to(self, mut writer: Some[Writer]):
    t"Complex(re = {self.re}, im = {self.im})".write_to(writer)
```

```mojo
var c = Complex(3.14, -2.72)
print(c)        # (3.14 - 2.72i)
print(repr(c))  # Complex(re = 3.14, im = -2.72)
```

## 添加一元运算符支持

`+c` 原样返回该值。`-c` 将两个分量都取负：

```mojo
# methods
def __pos__(self) -> Self:
    return self

def __neg__(self) -> Self:
    return Self(-self.re, -self.im)

...

var c = Complex(-1.2, 6.5)
print(+c)  # (-1.2 + 6.5i)
print(-c)  # (1.2 - 6.5i)
```

## 支持二元算术

通过 dunder 方法为两个 `Complex` 值之间的加法、减法、乘法和除法添加支持。每种形式都返回一个新的 `Complex` 实例：

```mojo
    def __add__(self, rhs: Self) -> Self:
        return Self(self.re + rhs.re, self.im + rhs.im)

    def __sub__(self, rhs: Self) -> Self:
        return Self(self.re - rhs.re, self.im - rhs.im)

    def __mul__(self, rhs: Self) -> Self:
        return Self(
            self.re * rhs.re - self.im * rhs.im,
            self.re * rhs.im + self.im * rhs.re,
        )

    def __truediv__(self, rhs: Self) -> Self:
        var denom = rhs.squared_norm()
        return Self(
            (self.re * rhs.re + self.im * rhs.im) / denom,
            (self.im * rhs.re - self.re * rhs.im) / denom,
        )

    def squared_norm(self) -> Float64:
        return self.re * self.re + self.im * self.im

    def norm(self) -> Float64:
        return sqrt(self.squared_norm())
```

```mojo
var c1 = Complex(-1.2, 6.5)
var c2 = Complex(3.14, -2.72)
print(c1 + c2)  # (1.94 + 3.78i)
print(c1 * c2)  # (13.91 + 23.67i)
```

## 使用反向方法添加混合类型算术

要支持像 `2.5 + c` 这样 `Float64` 在左侧的表达式，你既需要重载的前向方法，也需要反向方法。如果没有 `__radd__()`，`2.5 + c` 会失败，因为 `Float64` 对 `Complex` 一无所知：

```mojo
    # Forward: Complex + Float64
    def __add__(self, rhs: Float64) -> Self:
        return Self(self.re + rhs, self.im)

    # Reversed: Float64 + Complex
    def __radd__(self, lhs: Float64) -> Self:
        return Self(self.re + lhs, self.im)

    def __sub__(self, rhs: Float64) -> Self:
        return Self(self.re - rhs, self.im)

    def __rsub__(self, lhs: Float64) -> Self:
        return Self(lhs - self.re, -self.im)

    def __mul__(self, rhs: Float64) -> Self:
        return Self(self.re * rhs, self.im * rhs)

    def __rmul__(self, lhs: Float64) -> Self:
        return Self(lhs * self.re, lhs * self.im)

    def __truediv__(self, rhs: Float64) -> Self:
        return Self(self.re / rhs, self.im / rhs)

    def __rtruediv__(self, lhs: Float64) -> Self:
        var denom = self.squared_norm()
        return Self(
            (lhs * self.re) / denom,
            (-lhs * self.im) / denom,
        )
```

现在两种顺序都能正常工作：

```mojo
var c = Complex(-1.2, 6.5)
print(c + 2.5)    # (1.3 + 6.5i)
print(2.5 + c)    # (1.3 + 6.5i)
print(2.5 * c)    # (-3.0 + 16.25i)
```

### 允许原地赋值

原地方法直接修改 `self`，而不是返回一个新值。你可以分别为 `Complex` 和 `Float64` 操作数进行重载：

```mojo
    def __iadd__(mut self, rhs: Self):
        self.re += rhs.re
        self.im += rhs.im

    def __iadd__(mut self, rhs: Float64):
        self.re += rhs

    def __isub__(mut self, rhs: Self):
        self.re -= rhs.re
        self.im -= rhs.im

    def __isub__(mut self, rhs: Float64):
        self.re -= rhs

    def __imul__(mut self, rhs: Self):
        var new_re = self.re * rhs.re - self.im * rhs.im
        var new_im = self.re * rhs.im + self.im * rhs.re
        self.re = new_re
        self.im = new_im

    def __imul__(mut self, rhs: Float64):
        self.re *= rhs
        self.im *= rhs

    def __itruediv__(mut self, rhs: Self):
        var denom = rhs.squared_norm()
        var new_re = (self.re * rhs.re + self.im * rhs.im) / denom
        var new_im = (self.im * rhs.re - self.re * rhs.im) / denom
        self.re = new_re
        self.im = new_im

    def __itruediv__(mut self, rhs: Float64):
        self.re /= rhs
        self.im /= rhs

...

var c = Complex(-1.0, -1.0)
c += Complex(0.5, -0.5)
print(c)       # (-0.5 - 1.5i)
c += 2.75
print(c)       # (2.25 - 1.5i)
c *= 0.75
print(c)       # (1.6875 - 1.125i)
c /= 2.0
print(c)       # (0.84375 - 0.5625i)
```

## 支持类型相等检查

复数没有自然的排序，因此 `Complex` 遵循 `Equatable`（而不是 `Comparable`）。这让你获得 `==` 和 `!=`，而不会暗示一个复数"小于"另一个。

你不需要自己实现 `__eq__()` 或 `__ne__()`——只有当某个类型的相等语义需要与逐字段比较不同时，才需要实现它们。`Equatable` 提供了一个默认的 `__eq__()`，它使用编译时反射来比较每一个字段，还提供了一个默认的 `__ne__()`，返回 `__eq__()` 的反值。一个 `Complex` 只有在两个字段都匹配时才等于另一个 `Complex`，因此基于反射的默认实现恰好就是你想要的行为。（请记住，由于浮点 `NaN` 永远不等于它自身，因此持有 `NaN` 的 `Complex` 也不会等于它自身。）

```mojo
var c1 = Complex(-1.2, 6.5)
var c2 = Complex(-1.2, 6.5)
var c3 = Complex(3.14, -2.72)
print(c1 == c2)  # True
print(c1 != c3)  # True
```

## 支持在布尔上下文中使用

遵循 `Boolable` 并实现 `__bool__()`，可以让你在布尔上下文中直接使用 `Complex` 值，例如作为 `if` 条件或调用 `Bool()`。Mojo 在内置数值非零时将其视为"真"，因此一个自然的定义是：只要任一分量非零，就把复数视为"真"：

```mojo
    def __bool__(self) -> Bool:
        return self.re != 0.0 or self.im != 0.0
```

```mojo
var c1 = Complex(0.0, 0.0)
var c2 = Complex(-1.2, 6.5)
print(Bool(c1))  # False
print(Bool(c2))  # True

if c2:
    print("c2 is nonzero")  # c2 is nonzero
```

## 启用下标访问

get 和 set 项的 dunder 方法允许你对类型中的内容进行索引。在本示例中，复数的实部对应索引 0，索引 1 返回虚部分量：

```mojo
    def __getitem__(self, idx: Int) raises -> Float64:
        if idx == 0:
            return self.re
        if idx == 1:
            return self.im
        raise "index out of bounds"

    def __setitem__(mut self, idx: Int, value: Float64) raises:
        if idx == 0:
            self.re = value
        elif idx == 1:
            self.im = value
        else:
            raise "index out of bounds"

...

var c = Complex(3.14)
print(c[0], c[1])  # 3.14 0.0
c[1] = 42.0
print(c)            # (3.14 + 42.0i)
```
