每个 Mojo 操作符都映射到一组你可以添加到结构体实现的双下划线方法。这些方法允许你使用操作符语法而不是直接调用方法。

了解你的操作符及其相关方法将为自定义结构体打开完整的操作符语法套件。

## 前向、反向和原地方法

每个二元操作符最多使用三种方法形式。例如，考虑加法 `a + b`：

- **前向**：Mojo 首先尝试 `a.__add__(b)`。
- **反向**：如果前向方法不存在或无法处理 `b` 的类型，Mojo 回退到 `b.__radd__(a)`。
- **原地**：对于 `a += b`，Mojo 调用 `a.__iadd__(b)`。

反向方法存在于混合类型表达式中，其中左操作数不知道右操作数的类型：

```mojo
a + 5    # 调用 a.__add__(5)
5 + a    # Int 不知道你的类型，回退
         # 到 a.__radd__(5)
a += 5   # 调用 a.__iadd__(5)
```

## 一元操作符

一元操作符如果未更改，则返回原始值，或表示结果的新值。例如，`-x` 使用一元否定操作符：

```mojo
@fieldwise_init
struct MyInt:
    var value: Int

    def __neg__(self) -> Self:
        return Self(-self.value)
```

如果 `x` 是 `MyInt`，那么 `-x` 返回一个新实例，其 `value` 字段取反。

## 比较操作符和 trait

操作符并不要求你将类型符合到 trait。然而，这样做是有益的。

`Comparable` trait 为 `<=`、`>` 和 `>=` 提供默认值。你只需要实现 `__lt__()` 和 `__eq__()`。

类似地，`Equatable` trait 在所有字段都是 `Equatable` 时为 `__eq__()` 和 `__ne__()` 提供默认值。

对于没有自然排序的类型（如复数），只实现 `Equatable`，而不是 `Comparable`。

## 下标操作符

实现 `__getitem__()` 用于读取，`__setitem__()` 用于写入。两个下标方法都接受可变参数用于多维索引。

对于简单的单维集合，你可以使用简单索引解锁下标：

```mojo
struct MySeq[T: Copyable]:
    def __getitem__(self, idx: Int) -> T:
        ...
    def __setitem__(mut self, idx: Int, value: T):
        ...
```

对于多维集合，请使用可变参数或多个索引参数：

```mojo
struct Grid[T: Copyable]:
    # 固定的两个维度
    def __getitem__(self, x: Int, y: Int) -> T:
        ...
    # 任意维度
    def __getitem__(self, *indices: Int) -> T:
        ...
```

自定义下标也可以支持切片和索引，如 `obj[1:5]`。使用 [`Slice`](/docs/std/builtin/builtin_slice/Slice/) 参数而不是 `Int` 来实现 `__getitem__()`。

每个 `Slice` 有三个可选字段：`start`、`end` 和 `step`。你通过调用 `indices()` 来规范化这些字段。传递你类型的 size。这返回一个三元组值，表示根据你的范围调整的跨度，将省略的值或负索引解析为非负位置：

```mojo
struct MySeq[T: Copyable]:
    var size: Int

    def __getitem__(self, span: Slice) -> Self:
        var start: Int
        var end: Int
        var step: Int
        start, end, step = span.indices(self.size)
        ...
```

## 演示：构建 `Complex` 类型

接下来的部分逐步构建一个 `Complex` 结构体。此示例演示了每个类别的操作符实现。

在此演练中，你将处理一元操作符、具有相同类型和混合类型操作数的二元操作符、反向方法、原地赋值、相等比较和下标访问。

:::note
标准库包含
[`ComplexSIMD`](/docs/std/complex/complex/ComplexSIMD/)，
一个具有基本算术支持的参数化复数类型。此示例中的 `Complex` 类型是独立的，并且不基于 `ComplexSIMD`。
:::

## 创建基础类型

复数包含实部和虚部，存储在实部 `re` 和虚部 `im` 字段中：

```mojo
from std.math import sqrt

@fieldwise_init
struct Complex(
    Equatable,
    Writable,
    TrivialRegisterPassable,
):
    var re: Float64
    var im: Float64
```

- 符合 `TrivialRegisterPassable` 让你获得值语义，而无需编写特殊生命周期方法。
- `Equatable` 让你可以比较两个实例，`Writable` 为 `print()` 语句生成输出。

### 便捷初始化器

添加便捷初始化器可以让你只使用数字的实部来创建实例：

```mojo
def __init__(out self, re: Float64):
    self.re = re
    self.im = 0.0
```

## 使你的类型可打印

实现 `Writable` 让你可以直接使用 `print()` 和 `String()`。此自定义实现提供括号和单独的实部和虚部输出。

```mojo
# 结构体方法
def write_to(self, mut writer: Some[Writer]):
    writer.write("(", self.re)
    if self.im < 0:
        writer.write(" - ", -self.im)
    else:
        writer.write(" + ", self.im)
    writer.write("i")

...

c = Complex(3.14, -2.72)
print(c)  # (3.14 - 2.72i)
```

## 添加一元操作符支持

`+c` 返回未更改的值。`-c` 取反两个分量：

```mojo
# 方法
def __pos__(self) -> Self:
    return self

def __neg__(self) -> Self:
    return Self(-self.re, -self.im)

...

c = Complex(-1.2, 6.5)
print(+c)  # (-1.2 + 6.5i)
print(-c)  # (1.2 - 6.5i)
```

## 支持二元算术

使用双下划线方法添加两个 `Complex` 值之间的加法、减法、乘法和除法。每种形式都返回一个新的 `Complex` 实例：

```mojo
    def __add__(self, rhs: Self) -> Self:
        return Self(self.re + rhs.re, self.im + rhs.im)

    def __sub__(self, rhs: Self) -> Self:
        return Self(self.re - rhs.re, self.im - rhs.im)

    def __mul__(self, rhs: Self) -> Self:
        return Self(
            self.re * rhs.re - self.im * rhs.im,
            self.re * rhs.im + self.im * rhs.re,
        )

    def __truediv__(self, rhs: Self) -> Self:
        denom = rhs.squared_norm()
        return Self(
            (self.re * rhs.re + self.im * rhs.im) / denom,
            (self.im * rhs.re - self.re * rhs.im) / denom,
        )

    def squared_norm(self) -> Float64:
        return self.re * self.re + self.im * self.im

    def norm(self) -> Float64:
        return sqrt(self.squared_norm())
```

```mojo
c1 = Complex(-1.2, 6.5)
c2 = Complex(3.14, -2.72)
print(c1 + c2)  # (1.94 + 3.78i)
print(c1 * c2)  # (13.91 + 23.67i)
```

## 使用反向方法添加混合类型算术

要支持像 `2.5 + c` 这样的表达式，其中 `Float64` 在左边，你需要两个重载的前向方法和反向方法。没有 `__radd__()`，`2.5 + c` 将会失败，因为 `Float64` 不知道 `Complex`：

```mojo
    # 前向：Complex + Float64
    def __add__(self, rhs: Float64) -> Self:
        return Self(self.re + rhs, self.im)

    # 反向：Float64 + Complex
    def __radd__(self, lhs: Float64) -> Self:
        return Self(self.re + lhs, self.im)

    def __sub__(self, rhs: Float64) -> Self:
        return Self(self.re - rhs, self.im)

    def __rsub__(self, lhs: Float64) -> Self:
        return Self(lhs - self.re, -self.im)

    def __mul__(self, rhs: Float64) -> Self:
        return Self(self.re * rhs, self.im * rhs)

    def __rmul__(self, lhs: Float64) -> Self:
        return Self(lhs * self.re, lhs * self.im)

    def __truediv__(self, rhs: Float64) -> Self:
        return Self(self.re / rhs, self.im / rhs)

    def __rtruediv__(self, lhs: Float64) -> Self:
        denom = self.squared_norm()
        return Self(
            (lhs * self.re) / denom,
            (-lhs * self.im) / denom,
        )
```

现在两种顺序都有效：

```mojo
c = Complex(-1.2, 6.5)
print(c + 2.5)    # (1.3 + 6.5i)
print(2.5 + c)    # (1.3 + 6.5i)
print(2.5 * c)    # (-3.0 + 16.25i)
```

### 允许原地赋值

原地方法直接修改 `self` 而不是返回新值。你可以为 `Complex` 和 `Float64` 操作数两者都重载：

```mojo
    def __iadd__(mut self, rhs: Self):
        self.re += rhs.re
        self.im += rhs.im

    def __iadd__(mut self, rhs: Float64):
        self.re += rhs

    def __isub__(mut self, rhs: Self):
        self.re -= rhs.re
        self.im -= rhs.im

    def __isub__(mut self, rhs: Float64):
        self.re -= rhs

    def __imul__(mut self, rhs: Self):
        var new_re = self.re * rhs.re - self.im * rhs.im
        var new_im = self.re * rhs.im + self.im * rhs.re
        self.re = new_re
        self.im = new_im

    def __imul__(mut self, rhs: Float64):
        self.re *= rhs
        self.im *= rhs

    def __itruediv__(mut self, rhs: Self):
        var denom = rhs.squared_norm()
        var new_re = (self.re * rhs.re + self.im * rhs.im) / denom
        var new_im = (self.im * rhs.re - self.re * rhs.im) / denom
        self.re = new_re
        self.im = new_im

    def __itruediv__(mut self, rhs: Float64):
        self.re /= rhs
        self.im /= rhs

...

c = Complex(-1.0, -1.0)
c += Complex(0.5, -0.5)
print(c)       # (-0.5 - 1.5i)
c += 2.75
print(c)       # (2.25 - 1.5i)
c *= 0.75
print(c)       # (1.6875 - 1.125i)
c /= 2.0
print(c)       # (0.84375 - 0.5625i)
```

## 支持类型相等检查

复数没有自然排序，因此你应该实现 `Equatable`（而不是 `Comparable`）。这让你获得 `==` 和 `!=` 而不会暗示一个复数"小于"另一个：

```mojo
    def __eq__(self, other: Self) -> Bool:
        return (self.re == other.re and
                self.im == other.im)

    # 符合 Equatable 会自动提供此功能
    def __ne__(self, other: Self) -> Bool:
        return not (self == other)
```

```mojo
c1 = Complex(-1.2, 6.5)
c2 = Complex(-1.2, 6.5)
c3 = Complex(3.14, -2.72)
print(c1 == c2)  # True
print(c1 != c3)  # True
```

## 解锁下标访问

获取和设置项双下划线允许你在类型中索引内容。对于此示例，复数的实部是索引 0，索引 1 返回虚部：

```mojo
    def __getitem__(self, idx: Int) raises -> Float64:
        if idx == 0: return self.re
        if idx == 1: return self.im
        raise "index out of bounds"

    def __setitem__(
        mut self, idx: Int, value: Float64
    ) raises:
        if idx == 0: self.re = value
        elif idx == 1: self.im = value
        else: raise "index out of bounds"

...

c = Complex(3.14)
print(c[0], c[1])  # 3.14 0.0
c[1] = 42.0
print(c)            # (3.14 + 42.0i)
```
