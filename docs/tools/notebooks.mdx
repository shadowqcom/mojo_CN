[Jupyter 笔记本](https://jupyter.org)提供了一个基于 Web 的环境，用于创建和共享 Mojo 计算文档。它们将代码、结果和说明结合在一起，让读者可以探索你构建了什么、如何构建的以及为什么重要。

你可以在本地或在支持 GPU 的 Google Colab 环境中运行 Mojo 语言笔记本，以加速工作负载。对于教学、学习和探索，笔记本提供了一种动手实践、迭代式的工作流程。

本页假设你将通过以下两种方式之一使用 Mojo 笔记本：

- **Google Colab** <br />
  快速设置，可选 GPU 加速，非常适合快速实验以及在你没有兼容的 GPU 计算机时学习 GPU 编程。
- **本地 JupyterLab** <br />
  私有环境，完全控制代码、数据和依赖项。

两种选项使用相同的笔记本模型和相同的 Mojo 单元魔法命令。

## 在 Google Colab 上使用 Mojo

1. 创建笔记本：

    访问 [Google Colab](https://colab.google) 并创建一个新笔记本。

2. 安装 Mojo：

   对于 nightly 版本：

    ```python
    !pip install --pre mojo --extra-index-url https://whl.modular.com/nightly/simple/
    ```

   对于稳定版本：

    ```python
    !pip install mojo
    ```

   等待"Successfully installed"消息。

3. 启用 Mojo：

    在第一个单元格中运行：

    ```python
    import mojo.notebook
    ```

    这会添加 `%%mojo` 单元魔法命令，使你可以编译和运行 Mojo 代码。

    你的 Colab 笔记本现在已准备好运行 Mojo 程序。

## 在本地 Jupyter 笔记本中使用 Mojo

本地笔记本使用 `pixi` 来管理包含 Jupyter 和 Mojo 的环境。

1. 创建项目：

    ```shell
    pixi init notebooks \
        -c https://conda.modular.com/max-nightly/ \
        -c conda-forge
    cd notebooks
    pixi shell
    ```

    这会创建一个项目目录并进入 Pixi shell。

2. 安装所需工具：

    ```shell
    pixi add mojo jupyterlab ipykernel
    ```

    这会安装：
   - Mojo
   - JupyterLab
   - 笔记本执行所需的 Python 内核

3. 启动 JupyterLab：

    ```shell
    jupyter lab
    ```

    JupyterLab 会在浏览器中打开。

4. 创建 Python 支持的笔记本：

    在 Web 浏览器中：

   - 选择 _File > New > Notebook_。
   - 选择 _Python_ 内核。

5. 启用 Mojo 支持：

    在第一个单元格中运行：

    ```python
    import mojo.notebook
    ```

    这会注册 `%%mojo` 魔法命令。
    你的本地环境现在已准备好进行交互式 Mojo 开发。

## 编写和运行 Mojo 代码

Mojo 代码在标记有 `%%mojo` 指令的笔记本单元格中运行。每个 Mojo 单元格必须包含一个完整的程序，包括 `main()` 函数。

### 示例：Hello Mojo

```mojo
%%mojo

def main():
  print("Hello Mojo")
```

输出：

```output
Hello Mojo
```

### 示例：参数化编译

```mojo
%%mojo

# 编译器参数化函数
def repeat[count: Int](msg: String):
    comptime for i in range(count):
        print(msg)

# 编译器参数调用函数
def threehello():
    repeat[3]("Hello 🔥!")

# 运行
def main():
    threehello()
```

输出：

```output
Hello 🔥!
Hello 🔥!
Hello 🔥!
```

## 使用 Mojo 的 GPU 支持

Google Colab 提供支持 GPU 的运行时，让你即使没有本地硬件也可以运行 Mojo GPU 示例。可用的特定加速器取决于你的 Colab 套餐；有关 Mojo 支持的加速器列表，请参见 [GPU 兼容性](/docs/requirements/#gpu-compatibility)。在运行 GPU 代码之前，选择 _Runtime > Change runtime type > [GPU]_。

### 示例：GPU Hello World

```mojo
%%mojo

from std.gpu.host import DeviceContext

def kernel():
    print("Hello from the GPU")

def main() raises:
    # 启动 GPU 内核
    with DeviceContext() as ctx:
        ctx.enqueue_function[kernel](grid_dim=1, block_dim=1)
        ctx.synchronize()
```

输出：

```output
Hello from the GPU
```

### 示例：Hello 写入

此示例向设备内存写入一个值，然后在主机端读回：

```mojo
%%mojo
from std.memory import UnsafePointer
from std.gpu.host import DeviceContext

comptime `✅`: Int32 = 1
comptime `❌`: Int32 = 0

def kernel(value: UnsafePointer[Scalar[DType.int32], MutAnyOrigin]):
    value[0] = `✅`

def main() raises:
    with DeviceContext() as ctx:
        # 构建它
        var out = ctx.enqueue_create_buffer[DType.int32](1)
        out.enqueue_fill(`❌`)

        # 运行它
        ctx.enqueue_function[kernel](out, grid_dim=1, block_dim=1)

        # 报告结果
        with out.map_to_host() as out_host:
            print("GPU responded:", \
                "👋, 🔥" if out_host[0] == `✅` else "😢")
```

输出：

```output
👋, 🔥
```

### 示例：GPU 向量加法

此示例在 GPU 上运行逐元素向量加法。每个 GPU 线程更新一个元素。

```mojo
%%mojo

from std.gpu import thread_idx
from std.gpu.host import DeviceContext
from layout import TileTensor, row_major
from std.sys import has_accelerator

comptime VECTOR_WIDTH = 10
comptime layout = row_major[VECTOR_WIDTH]()
comptime active_dtype = DType.uint8


# GPU 线程上的逐元素向量加法
def vector_addition(
    left: TileTensor[active_dtype, type_of(layout), MutAnyOrigin],
    right: TileTensor[active_dtype, type_of(layout), MutAnyOrigin],
    output: TileTensor[active_dtype, type_of(layout), MutAnyOrigin],
):
    var idx = thread_idx.x
    output[idx] = left[idx] + right[idx]


def main() raises:
    # 确保有支持的 GPU（NVIDIA 或 AMD）可用
    comptime assert has_accelerator(), "This example requires a supported GPU"

    # 创建 GPU 设备上下文
    var ctx = DeviceContext()

    # 为左操作数、右操作数和输出分配缓冲区和张量
    var left_buffer = ctx.enqueue_create_buffer[active_dtype](VECTOR_WIDTH)
    var left_tensor = TileTensor(left_buffer, layout)

    var right_buffer = ctx.enqueue_create_buffer[active_dtype](VECTOR_WIDTH)
    var right_tensor = TileTensor(right_buffer, layout)

    var output_buffer = ctx.enqueue_create_buffer[active_dtype](VECTOR_WIDTH)
    var output_tensor = TileTensor(output_buffer, layout)

    # 用示例数据初始化输入缓冲区
    var message_bytes: List[UInt8] = [
        71, 100, 107, 107, 110, 31, 76, 110, 105, 110
    ]
    with left_buffer.map_to_host() as mapped_buffer:
        var mapped_tensor = TileTensor(mapped_buffer, layout)
        for idx in range(VECTOR_WIDTH):
            mapped_tensor[idx] = message_bytes[idx]
    _ = right_buffer.enqueue_fill(1)

    # 启动 GPU 内核
    ctx.enqueue_function[vector_addition](
        left_tensor,
        right_tensor,
        output_tensor,
        grid_dim=1,
        block_dim=VECTOR_WIDTH,
    )
    ctx.synchronize()

    # 读回结果并打印为 ASCII
    with output_buffer.map_to_host() as mapped_buffer:
        var mapped_tensor = TileTensor(mapped_buffer, layout)
        for idx in range(VECTOR_WIDTH):
            print(chr(Int(mapped_tensor[idx])), end="")
        print()
```

输出：

```output
Hello Mojo
```
