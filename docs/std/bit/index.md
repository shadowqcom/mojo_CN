# bit

位操作：操作、计数、旋转和 2 的幂次工具。

`bit` 包提供了低级位操作和工具，用于对整数值和 SIMD 向量进行高效的位操作。它包括用于计数位、反转位模式、字节交换、旋转位和计算 2 的幂边界的函数。这些操作对于系统编程、加密、数据压缩和性能关键算法至关重要。

此包适用于低级位操作、实现自定义哈希函数、优化内存布局、处理打包数据结构或任何需要直接位级控制的算法。
