# testing

单元测试：断言（相等、真、抛出）和测试套件。

`testing` 包提供 Mojo 代码的单元测试框架。它包括用于验证条件和值的断言函数，以及用于组织和运行测试套件的基础设施。该框架遵循其他测试库的熟悉模式，使编写和维护测试变得简单。

使用此包为您的 Mojo 代码编写单元测试、验证正确性，并在开发过程中捕获回归问题。
