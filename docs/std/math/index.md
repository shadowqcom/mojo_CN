# math

数学函数和常量：三角函数、指数函数、对数函数和特殊函数。

`math` 包提供用于数值计算的数学函数和常量。它包括三角学中的标准数学运算、指数和对数函数、特殊函数和数值工具。此包实现了精确的数学运算和用于性能关键代码的快速近似，以及舍入、截断和 IEEE 754 浮点行为支持。

使用此包进行科学计算、数值算法、图形和游戏开发、统计计算，或任何需要超越基本算术的数学运算的应用。`fast` 模块提供了当可以牺牲绝对精度换取性能时的优化近似。
