# stat

文件类型常量和 stat 系统调用检测。

`stat` 包提供用于处理 POSIX stat 系统调用文件元数据的常量和工具函数。它定义标准文件类型位掩码和用于从模式值确定文件类型的谓词。此包支持跨类 Unix 系统的可移植文件类型检查。

使用此包处理文件系统元数据、实现可移植的文件类型检测，或与 POSIX 文件操作交互。
