# stat

提供解释文件模式位的常量和函数。

此模块定义文件类型常量和测试文件模式的函数，类似于 Python 的 `stat` 模块。它包括用于识别不同文件类型（常规文件、目录、符号链接、设备等）的位掩码和方便的模式测试函数。
