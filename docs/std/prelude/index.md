# prelude

标准库前导：基本类型、trait 和操作自动导入。

此包的内容构成了每位 Mojo 开发者使用的基本词汇。它被隐式导入到每个 Mojo 程序中。

`prelude` 包包含自动导入到每个 Mojo 程序的核心类型、trait 和函数。它提供语言的基础构建块，包括基本类型（Int、String、Bool）、基本 trait（Copyable、Movable、Equatable）、内存原语（Pointer、Span）和常用操作（print、len、range）。此包定义了默认命名空间，使 Mojo 代码无需显式导入即可立即使用。
