# random

伪随机数生成，支持均匀分布和正态分布。

`random` 包提供用于模拟、游戏和统计应用的伪随机数生成。它提供通过包级函数访问的便捷全局 PRNG 状态，以及用于可重现序列的显式生成器类型。该包支持各种数值类型的均匀分布和正态（高斯）分布。

使用此包进行蒙特卡洛模拟、随机算法、随机抽样或使用随机输入进行测试。此包的功能不具备加密安全性，不应用于安全敏感的应用。
