# pathlib

文件系统路径操作和导航。

`pathlib` 包提供面向对象的文件系统路径处理，具有独立于平台的路径操作。它提供 `Path` 类型用于表示和操作文件系统路径，以及用于路径连接、展开和目录操作的工具。此包使处理文件路径比手动字符串操作更安全、更直观。

使用此包进行任何文件系统路径操作，包括构建路径、导航目录、检查文件存在性，或以独立于平台的方式执行路径相关查询。
