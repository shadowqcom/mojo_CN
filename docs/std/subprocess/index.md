# subprocess

执行外部进程和命令。

`subprocess` 包提供用于生成和与外部进程交互的工具。它支持运行 shell 命令、捕获其输出，以及将外部工具集成到 Mojo 程序中。此包自动处理进程执行、输出捕获和资源清理。

使用此包当您需要执行 shell 命令、与外部工具集成，或从 Mojo 代码中自动化系统任务时。
