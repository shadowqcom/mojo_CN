# len

提供 `len()` 函数及其关联的 trait。

这些是 Mojo 内置类型，因此您不需要导入它们。

## Traits

### Sized

`trait Sized`

**Methods:**

- **__len__**: `def __len__(self) -&gt; Int`

### SizedRaising

`trait SizedRaising`

**Methods:**

- **__len__**: `def __len__(self) raises -&gt; Int`
