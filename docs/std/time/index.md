# time

计时操作：单调时钟、性能计数器、休眠、time_function。

`time` 包提供用于测量经过时间、基准测试代码性能和引入延迟的工具。它提供不受系统时钟调整影响的单调时钟，适合测量间隔和分析执行时间。

使用此包进行性能测量、基准测试、分析，或当您需要在代码中引入延迟时。
