# tempfile

管理临时文件和目录：创建、定位和清理。

`tempfile` 包提供用于创建和管理临时文件和目录的工具。它处理特定于平台的临时存储位置，并确保正确清理临时资源。临时文件对于中间数据、测试以及需要临时空间而不污染永久存储的操作非常有用。

使用此包当您需要中间计算的临时空间、测试期间的临时存储，或任何需要程序执行后不应持久存在的文件的操作时。
