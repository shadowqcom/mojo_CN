# mojo format

格式化 Mojo 源文件。

## 用法概要

```
mojo format [options] <sources...>
```

## 描述

使用 Mojo 专用的 lint 工具格式化给定的 Mojo 源文件集。

## 选项

### 格式选项

#### `--line-length <INTEGER>`, `-l <INTEGER>`

设置最大字符行长度。默认值为 80。

### 诊断选项

#### `--quiet`, `-q`

禁用非错误消息。

### 通用选项

#### `--help`, `-h`

显示帮助信息。

#### `--help-hidden`

显示隐藏选项的帮助信息。
