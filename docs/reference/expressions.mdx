*表达式*是任何产生值的代码片段。表达式是计算的基本构建块：你可以将它们与运算符组合、作为参数传递、将结果赋值给变量，并在控制流中用作条件。

## 标识符表达式

标识符引用命名元素：变量、函数、类型或模块。在表达式中使用标识符可以获得它所引用的内容：

```mojo
score        # 一个变量
Int          # 一个类型
range        # 一个函数
```

## 括号表达式

括号用于分组子表达式，覆盖默认优先级：

```mojo
(a + b) * c  # 将 a 和 b 相加，再乘以 c
(x)          # 就是 x
```

括号还允许表达式跨越多行而无需使用反斜杠转义：

```mojo
var result = (
    first_value
    + second_value
    + third_value
)
```

## 元组

*元组*是固定大小、有序的值组。逗号创建元组，而不是括号：

```mojo
var a = 2, 3       # 没有括号的元组
var b = (2, 3)     # 带括号的相同元组
var x, y = b       # x 是 2，y 是 3
```

使用尾随逗号创建单元素元组。没有它，`(1)` 只是括号中的整数 `1`：

```mojo
()          # 空元组
(1,)        # 单元素元组
(1, 2, 3)   # 三元素元组
```

元组支持索引：

```mojo
var point = (10, 20)
print(point[0])  # 10
```

## 集合显示

编译器称这些为*显示*。显示类似于字面量，但与字面量不同，显示可以包含表达式和固定值。

### 列表

*列表显示*从逗号分隔的值创建列表：

```mojo
var empty = []
var numbers = [1, 2, 3]
var mixed = [1, "two", 3.0,]
```

Mojo 允许在所有集合元素后使用尾随逗号，包括最后一个。

### 字典

*字典显示*使用 `:` 分隔每个键值对：

```mojo
var empty = {}
var ages = {"Alice": 30, "Bob": 25}
```

### 集合

*集合显示*使用带值但不带冒号的花括号：

```mojo
var primes = {2, 3, 5, 7}
```

不要混淆集合和字典语法。`{1, 2}` 是集合。`{1: 2}` 是字典。

```mojo
{"a": 1, 2}   # 错误：不能混合 'key: value' 对和集合元素
{1, "b": 2}   # 错误：不能混合 'key: value' 对和集合元素
```

花括号语法还用作*初始化列表*，创建推断类型的实例。没有类型上下文，编译器无法区分集合和初始化列表，因此区别在类型检查时解决。初始化列表可以包含位置值和关键字参数：

```mojo
{x, y}           # 集合或初始化列表，没有上下文
{z=4, "foo"}     # 带关键字参数的初始化列表
```

初始化列表是构造函数调用的语法糖。当类型 `T` 从上下文中已知时，`{1, "hello"}` 等同于 `T(1, "hello")`。使用它们将初始化的实例作为参数传递：

```mojo
process({1, "hello"})  # 类型从签名推断
```

## 成员访问

点运算符访问值上的属性或方法：

```mojo
var length = text.count()
var x = point.x
var name = person.name.upper()
```

链式调用从左到右：`a.b.c` 访问 `a.b` 结果上的 `c`。

## 调用

*调用表达式*通过在表达式后附加 `()` 来调用函数或构造值：

```mojo
print("hello")
var result = compute(a, b)
var p = Point(1.0, 2.0)
```

### 位置参数和关键字参数

任何关键字参数之前的参数是位置参数。关键字参数使用 `name=value` 语法。

```mojo
def greet(name: String, loud: Bool = False):
    print(t"Hello, {name if not loud else name.upper()}!")

greet("Alice")  # Hello, Alice!
greet("Alice", loud=True)  # Hello, ALICE!
greet(name="Bob") # Hello, Bob!
```

位置参数不能跟在关键字参数之后：

```mojo
    # greet(loud=True, "Alice")
    # 错误：位置参数跟在关键字参数之后
```

关键字参数不能重复：

```mojo
greet(name="Alice", name="Bob")
# 错误：重复的关键字参数 'name'
```

## 下标和切片

表达式后的方括号通过索引或键查找值：

```mojo
var item = collection[0]
var value = mapping["key"]
var cell = matrix[i, j]
```

### 切片

方括号内的冒号创建*切片*。切片使用 `start:stop` 或 `start:stop:stride` 选择元素范围：

```mojo
var items = [0, 1, 2, 3, 4, 5]

var first_three = items[0:3]   # [0, 1, 2]（不包含 3）
var from_three  = items[3:]    # [3, 4, 5]
var every_other = items[::2]   # [0, 2, 4]
var reversed    = items[::-1]  # [5, 4, 3, 2, 1, 0]
```

所有三个部分都是可选的。起始默认为开头，结束默认为末尾，步长默认为 1。结束位置的元素不包含在结果中。

## 三元条件

`if`-`else` 表达式根据条件在两个值之间选择：

```mojo
var label = "even" if x % 2 == 0 else "odd"
```

条件跟在 `if` 后，替代值跟在 `else` 后。如果条件为真，表达式求值为第一个值。如果为假，则为替代值。

三元表达式是右结合的，可以链式使用：

```mojo
var size = (
    "small" if n < 10
        else "large" if n > 100
        else "medium"
)
```

这分组为
`"small" if n < 10 else ("large" if n > 100 else "medium")`。

## 海象运算符

常规赋值（`=`）是语句。它不能出现在更大的表达式中。海象运算符（也称为赋值表达式）`:=` 是赋值的表达式形式：它将值绑定到名称并求值为该值，因此结果可以立即使用：

```mojo
if (n := len(items)) > 10:
    print(n)

while (name := input("Prompt: ")) != "quit":
    print(name)
```

海象运算符在 `def` 方法和函数中隐式声明变量。它是所有表达式运算符中优先级最低的，因此通常需要在更大的表达式中使用时加括号。

```mojo
# 海象运算符需要函数作用域
n := len(items)      # 错误：表达式必须在函数内部

# 海象运算符在下标中无效
def main():
    items = [1, 2, 3]
    items[n := 2]    # 错误：下标中不允许使用海象运算符
```

## 编译时表达式

`comptime` 强制表达式在编译时求值。需要括号：

```mojo
def heavy_calculation() -> Int:
    var sum = 0
    for i in range(1_000_000):
        sum += i
    return sum

# var x = comptime heavy_calculation()
# 错误：需要括号

var x = comptime(heavy_calculation())  # 运行时 O(1)
print(x)  # 499999500000
```

循环在编译期间运行一次。在运行时，`x` 是常量。如果表达式无法在编译时求值，编译器会报错。

Mojo 还为编译时类型内省提供内置表达式。这些看起来像函数调用，但它们是对类型和 trait 在编译时操作的关键字：

```mojo
type_of(x)             # 表达式的类型
conforms_to(T, Trait)  # 测试 trait 一致性
origin_of(x)           # 引用的来源
```

这三个表达式的工作方式与大多数人预期的不同。它们用于反射、条件类型一致性和源集。它们返回编译器内部类型，不会打印。

## 推导式表达式

推导式是一种通过遍历现有值并可选地过滤或转换它们来构建新集合的简洁方式。它用单个（通常）可读的表达式替换常见的循环追加模式。

### 列表推导式

列表推导式创建列表：

```mojo
var squares = [x * x for x in [0, 1, 2, 3, 4] if x % 2 == 0]
# [0, 4, 16]

var positive = [x for x in range(-3, 3) if x > 0]
# [1, 2]
```

**语法：** `[expr for pattern in iterable if condition]`

- 多个 `for` 子句创建嵌套迭代
- `if` 子句过滤元素

### 集合推导式

集合推导式创建集合。集合不存储重复项，因此你可能得到比迭代次数更少的元素：

```mojo
var fibs = {fib(x) for x in range(6)}
# {1, 2, 3, 5, 8}，6 次迭代得到 5 个元素
```

**语法：** `{expr for pattern in iterable if condition}`

### 字典推导式

字典推导式创建字典：

```mojo
var dict_squares = {x: x * x for x in range(3)}
# {0: 0, 1: 1, 2: 4}

var lengths: Dict[String, Int] = {
    k: len(k) for k in ["one", "two", "three", "four"]
}
# {one: 3, two: 3, three: 5, four: 4}
```

**语法：**
`{key_expr: value_expr for pattern in iterable if condition}`

### 推导式子句

推导式支持多个 `for` 和 `if` 子句：

```mojo
var products = [
    (x, y, x * y)
    for x in range(3)
    for y in range(3)
    if (x + y) % 2 == 0
]
# [(0, 0, 0), (0, 2, 0), (1, 1, 1), (2, 0, 0), (2, 2, 4)]
```

子句从左到右求值：

- 每个 `for` 引入一个新的迭代变量
- 每个 `if` 基于当前值进行过滤
