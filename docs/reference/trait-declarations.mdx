*Trait 声明*定义一组方法签名和关联类型。Trait 指定类型必须提供的行为，而不定义具体实现。结构体可以*一致*于 trait，提供所需的方法实现。

```mojo
trait Printable:
    def __str__(self) -> String: ...

struct Point(Printable):
    var x: Float64
    var y: Float64

    def __str__(self) -> String:
        return t"Point({self.x}, {self.y})"
```

## Trait 名称

Trait 名称必须是有效的标识符。使用 PascalCase 命名 trait：

```mojo
trait Comparable:
    def __lt__(self, rhs: Self) -> Bool: ...
```

## 方法签名

Trait 方法签名以 `...` 结尾，表示实现必须提供具体实现：

```mojo
trait Addable:
    def __add__(self, rhs: Self) -> Self: ...
```

### 默认实现

Trait 方法可以有默认实现。使用 `pass` 或具体代码：

```mojo
trait Equatable:
    def __eq__(self, rhs: Self) -> Bool: ...

    def __ne__(self, rhs: Self) -> Bool:
        return not (self == rhs)
```

## Trait 继承

Trait 可以继承其他 trait。子 trait 要求一致类型实现所有父 trait 的方法：

```mojo
trait Comparable(Equatable):
    def __lt__(self, rhs: Self) -> Bool: ...

    def __le__(self, rhs: Self) -> Bool:
        return self < rhs or self == rhs

    def __gt__(self, rhs: Self) -> Bool:
        return not (self <= rhs)

    def __ge__(self, rhs: Self) -> Bool:
        return not (self < rhs)
```

### 多重继承

Trait 可以继承多个 trait：

```mojo
trait Numeric(Addable, Multipliable):
    def __neg__(self) -> Self: ...
```

## 关联类型

Trait 可以声明关联类型。一致类型必须指定具体类型：

```mojo
trait Container:
    comptime Element: AnyType

    def get(self) -> ref Element: ...
    def set(mut self, value: Element): ...

struct IntContainer(Container):
    comptime Element = Int
    var value: Int

    def get(self) -> ref Int:
        return self.value

    def set(mut self, value: Int):
        self.value = value
```

### 关联类型约束

关联类型可以有约束：

```mojo
trait Container:
    comptime Element: Copyable & Movable
```

## Self 类型

在 trait 方法中，`Self` 引用一致类型：

```mojo
trait Cloneable:
    def __copyinit__(out self, *, copy: Self): ...
```

## Trait 组合

使用 `&` 组合 trait：

```mojo
def process[T: Copyable & Movable](value: T):
    ...
```

### Trait 别名

使用 `comptime` 创建 trait 别名：

```mojo
comptime Value = Copyable & Movable & Stringable

def process[T: Value](value: T):
    ...
```

## 一致性检查

编译器验证一致类型实现了所有必需方法：

```mojo
trait Printable:
    def __str__(self) -> String: ...

# 错误：'Point' 不符合 trait 'Printable'
# 缺少方法 '__str__'
struct Point(Printable):
    var x: Float64
    var y: Float64
```

## 条件一致性

一致性可以有条件地基于编译时参数：

```mojo
struct Optional[T: AnyType](Equatable) where T: Equatable:
    var value: T
    var has_value: Bool

    def __eq__(self, rhs: Self) -> Bool:
        if not self.has_value and not rhs.has_value:
            return True
        if self.has_value != rhs.has_value:
            return False
        return self.value == rhs.value
```

## 内置 Trait

Mojo 提供许多内置 trait：

| Trait                  | 描述                           |
|------------------------|--------------------------------|
| `AnyType`              | 所有类型的基 trait             |
| `Copyable`             | 可以复制                       |
| `Movable`              | 可以移动                       |
| `Equatable`            | 可以比较相等性                 |
| `Comparable`           | 可以比较大小                   |
| `Stringable`           | 可以转换为字符串               |
| `Intable`              | 可以转换为整数                 |
| `Floatable`            | 可以转换为浮点数               |
| `Collection`           | 集合类型                       |
| `Iterable`             | 可以迭代                       |
| `Sized`                | 有已知大小                     |
| `Container`            | 可以包含元素                   |

## Trait 对象

Trait 可以用作类型，表示"任何一致的类型"：

```mojo
def print_all(items: List[Printable]):
    for item in items:
        print(item)
```

## 静态方法

Trait 可以定义静态方法：

```mojo
trait Factory:
    @staticmethod
    def create() -> Self: ...

struct Point(Factory):
    var x: Float64
    var y: Float64

    @staticmethod
    def create() -> Point:
        return Point(0.0, 0.0)
```
