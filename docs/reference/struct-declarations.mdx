*结构体声明*定义一个命名的复合类型。结构体将相关数据和方法组合成一个单元。在 Mojo 中，结构体是定义自定义类型的主要方式。

```mojo
struct Point:
    var x: Float64
    var y: Float64

    def __init__(out self, x: Float64, y: Float64):
        self.x = x
        self.y = y

    def magnitude(self) -> Float64:
        return (self.x ** 2 + self.y ** 2).sqrt()
```

## 结构体名称

结构体名称必须是有效的标识符。反引号转义标识符允许使用关键字作为结构体名称：

```mojo
struct `class`:
    pass
```

## 字段

*字段*是存储在结构体实例中的变量。每个字段都需要类型注解：

```mojo
struct Person:
    var name: String
    var age: Int
```

字段默认不初始化。使用 `__init__` 方法初始化字段。

### 字段默认值

字段可以有默认值。当提供默认值时，调用者可以省略该参数：

```mojo
struct Config:
    var verbose: Bool = False
    var retries: Int = 3
```

### 字段可见性

字段默认为私有。使用 `pub` 使字段公开：

```mojo
struct Point:
    pub var x: Float64
    pub var y: Float64
```

公开字段可以从结构体外部直接访问。

## 初始化器

`__init__` 方法初始化结构体实例。它必须有 `out self` 结果：

```mojo
struct Point:
    var x: Float64
    var y: Float64

    def __init__(out self, x: Float64, y: Float64):
        self.x = x
        self.y = y
```

### 默认初始化器

当没有定义 `__init__` 时，Mojo 会生成默认初始化器。默认初始化器接受与结构体字段匹配的参数：

```mojo
struct Point:
    var x: Float64
    var y: Float64

# 自动生成的初始化器：
# def __init__(out self, x: Float64, y: Float64):
#     self.x = x
#     self.y = y

def main():
    var p = Point(1.0, 2.0)
```

### `@fieldwise_init` 装饰器

`@fieldwise_init` 装饰器自动生成一个初始化器，接受所有字段作为参数：

```mojo
@fieldwise_init
struct Point:
    var x: Float64
    var y: Float64

def main():
    var p = Point(1.0, 2.0)
```

## 方法

*方法*是在结构体内部定义的函数。它们可以访问结构体的字段和其他方法：

```mojo
struct Counter:
    var count: Int

    def increment(mut self):
        self.count += 1

    def get(self) -> Int:
        return self.count
```

### `self` 参数

实例方法的第一个参数是 `self`，它引用结构体的实例。`self` 的约定决定方法可以做什么：

| 约定    | 含义                     |
|---------|--------------------------|
| 无      | 只读访问（不可变借用）   |
| `mut`   | 读写访问（可变借用）     |
| `out`   | 初始化（构造函数）       |
| `deinit`| 销毁（析构函数）         |

### 静态方法

使用 `@staticmethod` 装饰器定义静态方法。静态方法不接受 `self` 参数：

```mojo
struct Math:
    @staticmethod
    def square(x: Int) -> Int:
        return x * x

def main():
    print(Math.square(5))  # 25
```

## Trait 一致性

结构体可以实现 trait。使用括号列出 trait：

```mojo
struct Point(Comparable, Stringable):
    var x: Float64
    var y: Float64

    def __lt__(self, rhs: Point) -> Bool:
        return (self.x ** 2 + self.y ** 2) < (rhs.x ** 2 + rhs.y ** 2)

    def __str__(self) -> String:
        return t"Point({self.x}, {self.y})"
```

## 编译时参数

结构体可以接受编译时参数。这些参数在方括号中传递：

```mojo
struct Array[T: AnyType, size: Int]:
    var data: SIMD[T, size]

    def __init__(out self):
        self.data = SIMD[T, size]()

def main():
    var arr = Array[DType.float32, 4]()
```

### 参数约束

使用 `where` 子句约束编译时参数：

```mojo
struct Vector[T: AnyType, size: Int] where size > 0:
    var data: SIMD[T, size]
```

## 生命周期方法

### 复制构造函数

复制构造函数创建结构体的副本：

```mojo
struct Buffer:
    var data: Pointer[Int]

    def __init__(out self, *, copy: Self):
        # 深拷贝
        self.data = allocate(copy.size)
        memcpy(self.data, copy.data, copy.size)
```

### 移动构造函数

移动构造函数转移资源所有权：

```mojo
struct Buffer:
    var data: Pointer[Int]

    def __init__(out self, *, deinit take: Self):
        # 浅拷贝（所有权转移）
        self.data = take.data
        take.data = None
```

### 析构函数

析构函数在结构体实例被销毁时运行：

```mojo
struct Buffer:
    var data: Pointer[Int]

    def __del__(deinit self):
        if self.data:
            free(self.data)
```

## 平凡类型

*平凡类型*是没有自定义生命周期方法的类型。它们可以被平凡地复制、移动和销毁。使用 `@register_passable` 装饰器声明平凡类型：

```mojo
@register_passable
struct Color:
    var r: UInt8
    var g: UInt8
    var b: UInt8
```

平凡类型可以通过 CPU 寄存器传递，这可以提高性能。

## 装饰器

### `@register_passable`

声明类型可以通过寄存器传递。寄存器可传递类型必须是平凡可复制和可移动的：

```mojo
@register_passable
struct Point:
    var x: Float64
    var y: Float64
```

### `@value`

`@value` 装饰器自动生成生命周期方法：

```mojo
@value
struct Point:
    var x: Float64
    var y: Float64
```

这会生成：
- `__init__`（字段初始化器）
- `__copyinit__`（复制构造函数）
- `__moveinit__`（移动构造函数）
- `__del__`（析构函数，如果需要）

## 嵌套结构体

结构体可以嵌套在其他结构体中：

```mojo
struct Outer:
    struct Inner:
        var value: Int

    var inner: Inner
```
