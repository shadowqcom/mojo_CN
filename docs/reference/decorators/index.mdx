Mojo 装饰器（decorator）在编译时修改或扩展 struct、函数（function）或其他声明的行为。你将装饰器放在它所修饰的声明上方那一行，并以 `@` 为前缀。

```mojo
@fieldwise_init
struct Point:
    var x: Float64
    var y: Float64
```

在 `@` 之后，装饰器后跟一个名称，括号中可带可选参数。每个装饰器单独占一行。你可以在单个声明上堆叠多个装饰器：

```mojo
@fieldwise_init
@align(64)
struct CacheLine:
    var data: SIMD[DType.float32, 16]
```

装饰器按自下而上的顺序应用：最靠近声明的装饰器最先被应用。

:::note 不支持自定义装饰器
Mojo 不支持自定义装饰器。本节中的装饰器都是内置在编译器中的。
:::

## 装饰器目标

并非每个装饰器都能作用于每个声明。下表展示了哪些装饰器在哪些目标上有效。

| 装饰器                   | `struct` | `def` | method | `trait` | `comptime` | `var` | field |
|--------------------------|----------|-------|--------|---------|------------|-------|-------|
| `@align`                 | yes      |       |        |         |            |       |       |
| `@always_inline`         |          | yes   | yes    |         |            |       |       |
| `@extensibility.register`| yes      |       |        |         |            |       |       |
| `@__copy_capture`        |          |       | yes    |         |            |       |       |
| `@deprecated`            | yes      | yes   | yes    | yes     | yes        |       |       |
| `@doc_hidden`            | yes      | yes   | yes    |         | yes        |       | yes   |
| `@export`                |          | yes   |        |         |            |       |       |
| `@fieldwise_init`        | yes      |       |        |         |            |       |       |
| `@implicit`              |          |       | yes    |         |            |       |       |
| `@no_inline`             |          | yes   | yes    |         |            |       |       |
| `@nonmaterializable`     | yes      |       |        |         |            |       |       |
| `@__parameter`           |          |       | yes    |         |            |       |       |
| `@staticmethod`          |          |       | yes    |         |            |       |       |
