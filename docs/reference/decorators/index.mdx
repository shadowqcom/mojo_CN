*装饰器*修改函数、结构体或参数的行为。它们以 `@` 开头，放在声明之前。

## 概览

| 装饰器               | 适用对象       | 用途                             |
|----------------------|----------------|----------------------------------|
| `@value`             | 结构体         | 自动生成生命周期方法             |
| `@staticmethod`      | 方法           | 声明静态方法                     |
| `@register_passable` | 结构体         | 声明寄存器可传递类型             |
| `@always_inline`     | 函数           | 强制内联                         |
| `@no_inline`         | 函数           | 禁止内联                         |
| `@parameter`         | 函数           | 标记为参数函数                   |
| `@deprecated`        | 函数、结构体   | 标记为已弃用                     |
| `@doc_hidden`        | 函数、结构体   | 从文档中隐藏                     |
| `@fieldwise_init`    | 结构体         | 生成字段初始化器                 |
| `@implicit`          | 转换函数       | 标记为隐式转换                   |
| `@export`            | 函数           | 导出为公共符号                   |
| `@align`             | 函数、结构体   | 指定对齐要求                     |
| `@copy_capture`      | 闭包           | 按值捕获变量                     |
| `@compiler_register` | 参数           | 指定寄存器分配                   |
| `@explicit_destroy`  | 结构体         | 要求显式销毁                     |

## 结构体装饰器

### `@value`

`@value` 装饰器自动生成生命周期方法：

```mojo
@value
struct Point:
    var x: Float64
    var y: Float64
```

生成的生命周期方法包括：

- `__init__`：字段初始化器
- `__copyinit__`：复制构造函数
- `__moveinit__`：移动构造函数
- `__del__`：析构函数（如果需要）

你可以选择性生成：

```mojo
@value(new="none")      # 不生成 __init__
@value(copy="none")     # 不生成 __copyinit__
@value(move="none")     # 不生成 __moveinit__
@value(destroy="none")  # 不生成 __del__
```

### `@register_passable`

声明类型可以通过寄存器传递。寄存器可传递类型必须是平凡可复制和可移动的：

```mojo
@register_passable
struct Color:
    var r: UInt8
    var g: UInt8
    var b: UInt8
```

### `@fieldwise_init`

自动生成一个初始化器，接受所有字段作为参数：

```mojo
@fieldwise_init
struct Point:
    var x: Float64
    var y: Float64

def main():
    var p = Point(1.0, 2.0)
```

### `@explicit_destroy`

要求显式销毁结构体实例：

```mojo
@explicit_destroy
struct Resource:
    var handle: Int

    def __del__(deinit self):
        _release(self.handle)
```

## 函数装饰器

### `@staticmethod`

声明静态方法。静态方法不接受 `self` 参数：

```mojo
struct Math:
    @staticmethod
    def square(x: Int) -> Int:
        return x * x

def main():
    print(Math.square(5))  # 25
```

### `@always_inline`

强制函数内联：

```mojo
@always_inline
def add(a: Int, b: Int) -> Int:
    return a + b
```

### `@no_inline`

禁止函数内联：

```mojo
@no_inline
def complex_operation(x: Int) -> Int:
    ...
```

### `@parameter`

标记函数为参数函数。参数函数在编译时求值：

```mojo
@parameter
def factorial(n: Int) -> Int:
    if n <= 1:
        return 1
    return n * factorial(n - 1)

def main():
    comptime result = factorial(5)  # 120
```

### `@deprecated`

标记函数或结构体为已弃用：

```mojo
@deprecated("Use new_function() instead")
def old_function():
    pass

@deprecated
struct OldStruct:
    pass
```

### `@doc_hidden`

从生成的文档中隐藏函数或结构体：

```mojo
@doc_hidden
def internal_helper():
    pass
```

### `@export`

导出函数为公共符号，可以从其他模块或共享库调用：

```mojo
@export
def public_api():
    pass
```

### `@implicit`

标记转换函数为隐式转换：

```mojo
struct MyInt:
    var value: Int

    @implicit
    def __init__(out self, value: Int):
        self.value = value

def process(x: MyInt):
    pass

def main():
    process(42)  # 隐式转换 Int 到 MyInt
```

### `@align`

指定函数或结构体的对齐要求：

```mojo
@align(16)
struct AlignedBuffer:
    var data: SIMD[DType.float32, 4]
```

## 闭包装饰器

### `@copy_capture`

按值捕获变量而不是按引用：

```mojo
def make_counter() -> def() -> Int:
    var count = 0
    @copy_capture
    def increment() -> Int:
        count += 1
        return count
    return increment
```

## 参数装饰器

### `@compiler_register`

指定参数的寄存器分配：

```mojo
def fast_add(@compiler_register("rax") a: Int, @compiler_register("rbx") b: Int) -> Int:
    return a + b
```

## 组合装饰器

多个装饰器可以组合使用：

```mojo
@value
@register_passable
struct Point:
    var x: Float64
    var y: Float64

@always_inline
@deprecated("Use fast_add() instead")
def slow_add(a: Int, b: Int) -> Int:
    return a + b
```

## 自定义装饰器

Mojo 支持创建自定义装饰器。自定义装饰器是接受声明并返回修改后声明的函数：

```mojo
def logged(func):
    def wrapper(*args, **kwargs):
        print(t"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@logged
def process():
    print("Processing...")
```
