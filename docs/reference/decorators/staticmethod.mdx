你可以在 struct 方法上添加 `@staticmethod` 装饰器来声明一个静态方法。

例如：

```mojo
from std.pathlib import Path


struct MyStruct(Movable):
    var data: List[UInt8]

    def __init__(out self):
        self.data = List[UInt8]()

    @staticmethod
    def load_from_file(file_path: Path) raises -> Self:
        var new_struct = MyStruct()
        new_struct.data = file_path.read_bytes()
        return new_struct ^
```

与实例方法不同，静态方法不接受隐式的 `self` 参数。它不附加到 struct 的特定实例，因此无法访问实例数据。

有关更多信息，请参阅
[静态方法](/docs/manual/structs/#static-methods)的文档。
