`@staticmethod` 装饰器声明静态方法。静态方法不接受 `self` 参数，可以直接通过类型名调用。

## 语法

```mojo
struct TypeName:
    @staticmethod
    def method_name(...):
        ...
```

## 用法

```mojo
struct Math:
    @staticmethod
    def square(x: Int) -> Int:
        return x * x

def main():
    print(Math.square(5))  # 25
```

## 示例

### 工厂方法

```mojo
struct Point:
    var x: Float64
    var y: Float64

    def __init__(out self, x: Float64, y: Float64):
        self.x = x
        self.y = y

    @staticmethod
    def origin() -> Point:
        return Point(0.0, 0.0)

def main():
    var p = Point.origin()
```

### 工具方法

```mojo
struct StringUtils:
    @staticmethod
    def is_empty(s: String) -> Bool:
        return len(s) == 0

    @staticmethod
    def trim(s: String) -> String:
        return s.strip()

def main():
    print(StringUtils.is_empty(""))  # True
```

### 常量定义

```mojo
struct Constants:
    comptime PI: Float64 = 3.141592653589793
    comptime E: Float64 = 2.718281828459045

    @staticmethod
    def golden_ratio() -> Float64:
        return 1.618033988749895

def main():
    print(Constants.PI)
    print(Constants.golden_ratio())
```

## 与实例方法对比

| 特性         | 静态方法         | 实例方法         |
|--------------|------------------|------------------|
| self 参数    | 无               | 有               |
| 访问实例字段 | 不能             | 可以             |
| 调用方式     | TypeName.method()| instance.method()|

## 注意事项

- 静态方法不能访问实例字段
- 通过类型名调用，不需要实例
- 适用于工具函数和工厂方法
