`@fieldwise_init` 装饰器自动生成一个初始化器，接受所有字段作为参数。

## 语法

```mojo
@fieldwise_init
struct TypeName:
    ...
```

## 用法

```mojo
@fieldwise_init
struct Point:
    var x: Float64
    var y: Float64

def main():
    var p = Point(1.0, 2.0)
```

## 示例

### 带默认值

```mojo
@fieldwise_init
struct Config:
    var host: String = "localhost"
    var port: Int = 8080
    var debug: Bool = False

def main():
    var c1 = Config()  # 使用默认值
    var c2 = Config("example.com")  # 指定 host
    var c3 = Config("example.com", 443)  # 指定 host 和 port
    var c4 = Config(debug=True)  # 使用关键字参数
```

### 与其他装饰器组合

```mojo
@fieldwise_init
@register_passable
struct Color:
    var r: UInt8
    var g: UInt8
    var b: UInt8

def main():
    var red = Color(255, 0, 0)
```

## 与 `@value` 对比

| 特性           | `@fieldwise_init` | `@value`              |
|----------------|-------------------|-----------------------|
| 生成 __init__  | 是                | 是                    |
| 生成 __copyinit__ | 否             | 是                    |
| 生成 __moveinit__ | 否             | 是                    |
| 生成 __del__   | 否                | 是（如果需要）        |

## 注意事项

- 只生成初始化器，不生成其他生命周期方法
- 字段顺序决定参数顺序
- 支持默认值
