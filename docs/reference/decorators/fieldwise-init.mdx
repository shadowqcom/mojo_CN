你可以在 struct 上添加 `@fieldwise_init` 装饰器来生成逐字段的 `__init__()` 初始化器。

例如，考虑这样一个简单的 struct：

```mojo
@fieldwise_init
struct MyPet:
    var name: String
    var age: Int
```

Mojo 看到 `@fieldwise_init` 装饰器后会合成一个逐字段的初始化器，其结果就像你实际编写了以下代码一样：

```mojo
struct MyPet:
    var name: String
    var age: Int

    def __init__(out self, var name: String, age: Int):
        self.name = name^
        self.age = age
```

你可以通过向 struct 添加 `Copyable` trait 来合成拷贝初始化器和移动初始化器。有关这些生命周期方法的更多信息，请阅读[值的生命](/docs/manual/lifecycle/life/)。

## 隐式转换

隐式转换允许你传递一个值并让类型自行构建，而无需直接调用初始化器。这使调用方代码保持简洁干净。你可以通过将初始化器标记为
[`@implicit`](/docs/reference/decorators/implicit/) 或使用
`@fieldwise_init("implicit")` 为你创建一个来启用此功能。

例如，如果 `MyStruct` 有一个接受 `Int` 的初始化器，你可以像这样构造一个实例：

```mojo
var an_instance = MyStruct(42)
```

一个接受 `MyStruct` 的函数将接受该实例、一个显式的初始化器调用，或者一个可以转换为此类型的值：

```mojo
some_function(an_instance)      # pass an instance
some_function(MyStruct(42))     # build one directly
some_function(42)               # implicit conversion
```

这三种形式都会为该调用创建一个 `MyStruct`。其中一些可能在编译时或运行时有细微差异。

### 声明隐式初始化

你可以通过两种方式声明隐式初始化器：

- 使用 `@fieldwise_init("implicit")` 自动创建一个，前提是你的类型恰好有 _一个_ 实例字段。此限制适用于类型本身，而不仅仅是初始化器参数。
- 向你编写的初始化器添加 [`@implicit`](/docs/reference/decorators/implicit/)。该初始化器只能接受一个参数。

:::note
阅读更多关于
[初始化器和隐式转换](/docs/manual/lifecycle/life/#constructors-and-implicit-conversion)的内容。
:::

### 逐字段与隐式示例

以下是一个存储 `Int` 的类型。它可以通过整数或任何可以向下取整并转换为整数的值创建。
它对整数使用 `@fieldwise_init("implicit")`，并为其他值创建一个 `@implicit` 初始化器：

```mojo
from std.math import Floorable, floor

# Creates an implicit initializer and limits the type to one instance field.
@fieldwise_init("implicit")
struct FlooringInt:
    var floored: Int

    # Allows implicit conversion from types that can be floored and made into an Int.
    @implicit
    def __init__[T: Floorable & Intable](out self, value: T):
        self.floored = Int(floor(value))

def floored(value: FlooringInt) -> Int:
    return value.floored

def main():
    print(floored(FlooringInt(42)))  # pass an instance, output: 42
    print(floored(2))                # pass Int, output: 2
    print(floored(52.6))             # pass Float64, output: 52
    var x = BFloat16(192.3)
    print(floored(x))                # pass BFloat16, output: 192
    var y: FlooringInt = 180
    print(y.floored)                 # output 180
    var z: FlooringInt = 3.14159
    print(z.floored)                 # output: 3
```

在这个示例中你看不到的是用于整数的初始化器。添加 `@fieldwise_init("implicit")` 让编译器为你构建它。如果你手动编写，它可能看起来像这样：

```mojo
@implicit
def __init__(out self, floored: Int):
    self.floored = floored
```
