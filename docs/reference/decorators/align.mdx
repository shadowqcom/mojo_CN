`@align` 装饰器指定函数或结构体的内存对齐要求。对齐确保数据在内存中按特定边界排列，这可以提高某些硬件操作的性能。

## 语法

```mojo
@align(n)
```

其中 `n` 是以字节为单位的对齐值，必须是 2 的幂。

## 用法

### 结构体对齐

```mojo
@align(16)
struct AlignedBuffer:
    var data: SIMD[DType.float32, 4]
```

这确保 `AlignedBuffer` 的实例在 16 字节边界上对齐。

### 函数对齐

```mojo
@align(32)
def simd_operation():
    ...
```

## 常见对齐值

| 对齐值 | 用途                           |
|--------|--------------------------------|
| 16     | SSE/AVX 向量操作               |
| 32     | AVX-256 向量操作               |
| 64     | AVX-512 向量操作、缓存行对齐   |

## 示例

```mojo
@align(64)
struct CacheLineAligned:
    var data: SIMD[DType.float64, 8]

def main():
    var buffer = CacheLineAligned()
    # buffer 在 64 字节边界上对齐
    print(t"Address alignment: {Int(address_of(buffer)) % 64}")
```

## 注意事项

- 对齐值必须是 2 的幂（1, 2, 4, 8, 16, 32, 64, ...）
- 较大的对齐值可能增加内存使用
- 某些硬件操作要求特定的对齐
