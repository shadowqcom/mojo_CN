`@deprecated` 装饰器标记函数或结构体为已弃用。当用户使用已弃用的代码时，编译器会发出警告。

## 语法

```mojo
@deprecated
@deprecated("message")
```

## 用法

### 无消息

```mojo
@deprecated
def old_function():
    pass

@deprecated
struct OldStruct:
    pass
```

### 带消息

```mojo
@deprecated("Use new_function() instead")
def old_function():
    pass

@deprecated("Use NewStruct instead")
struct OldStruct:
    pass
```

## 示例

```mojo
struct Calculator:
    @deprecated("Use add() instead")
    def sum(self, a: Int, b: Int) -> Int:
        return a + b

    def add(self, a: Int, b: Int) -> Int:
        return a + b

def main():
    var calc = Calculator()
    # 警告：'sum' is deprecated: Use add() instead
    var result = calc.sum(1, 2)
```

## 弃用级别

编译器会对已弃用的代码发出警告，但不会阻止编译。这允许现有代码继续工作，同时鼓励迁移到新 API。

## 最佳实践

- 提供清晰的迁移说明
- 指向替代 API
- 在主要版本更新前弃用
- 保持已弃用的代码正常工作
