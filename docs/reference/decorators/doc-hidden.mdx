`@doc_hidden` 装饰器从生成的文档中隐藏函数或结构体。代码仍然可用，但不会出现在公共 API 文档中。

## 语法

```mojo
@doc_hidden
```

## 用法

### 隐藏函数

```mojo
@doc_hidden
def internal_helper():
    pass
```

### 隐藏结构体

```mojo
@doc_hidden
struct InternalType:
    pass
```

## 示例

```mojo
struct PublicAPI:
    def public_method(self):
        pass

    @doc_hidden
    def _internal_helper(self):
        pass

@doc_hidden
def _private_implementation():
    pass

def public_function():
    _private_implementation()
```

## 适用场景

- 内部实现细节
- 私有辅助函数
- 实验性功能
- 不稳定的 API

## 与私有成员对比

| 特性         | `@doc_hidden` | 私有成员       |
|--------------|---------------|----------------|
| 可访问性     | 公开可访问    | 仅内部可访问   |
| 文档可见性   | 隐藏          | 隐藏           |
| 用途         | 隐藏实现细节  | 强制封装       |

## 注意事项

- `@doc_hidden` 不限制访问，只是隐藏文档
- 代码仍然可以被调用
- 与 `pub` 修饰符一起使用时，代码公开但文档隐藏
