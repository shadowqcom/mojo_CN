`@compiler_register` 装饰器指定函数参数应该分配到特定的 CPU 寄存器。这允许对性能关键代码进行底层优化。

## 语法

```mojo
@compiler_register("register_name")
```

## 用法

```mojo
def fast_add(
    @compiler_register("rax") a: Int,
    @compiler_register("rbx") b: Int
) -> Int:
    return a + b
```

## 常见寄存器

### x86-64 架构

| 寄存器 | 用途               |
|--------|--------------------|
| rax    | 累加器、返回值     |
| rbx    | 基址寄存器         |
| rcx    | 计数器             |
| rdx    | 数据寄存器         |
| rsi    | 源索引             |
| rdi    | 目标索引           |
| r8-r15 | 通用寄存器         |

### 浮点寄存器

| 寄存器   | 用途           |
|----------|----------------|
| xmm0-xmm15 | SSE/AVX 寄存器 |

## 示例

```mojo
@always_inline
def compute(
    @compiler_register("xmm0") a: Float64,
    @compiler_register("xmm1") b: Float64
) -> Float64:
    return a * b + a / b
```

## 适用场景

- 系统编程和底层优化
- 与汇编代码交互
- 性能关键的热点代码

## 注意事项

- 寄存器分配取决于目标架构
- 不正确的寄存器分配可能导致编译错误
- 通常让编译器自动分配寄存器更好
