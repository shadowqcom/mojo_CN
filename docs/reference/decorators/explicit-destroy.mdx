`@explicit_destroy` 装饰器要求结构体实例必须显式销毁。这用于需要精确控制资源释放时机的类型。

## 语法

```mojo
@explicit_destroy
struct TypeName:
    ...
```

## 用法

```mojo
@explicit_destroy
struct Resource:
    var handle: Int

    def __init__(out self, handle: Int):
        self.handle = handle

    def __del__(deinit self):
        if self.handle != 0:
            _release(self.handle)
```

## 示例

```mojo
@explicit_destroy
struct FileHandle:
    var fd: Int

    def __init__(out self, path: String) raises:
        self.fd = _open(path)

    def __del__(deinit self):
        if self.fd >= 0:
            _close(self.fd)

def main():
    var file = FileHandle("data.txt")
    # 使用文件...
    __del__(file)  # 显式销毁
```

## 与自动销毁对比

| 特性         | 自动销毁           | `@explicit_destroy` |
|--------------|--------------------|--------------------|
| 销毁时机     | 作用域结束         | 显式调用           |
| 内存安全     | 自动保证           | 需要手动管理       |
| 资源控制     | 编译器决定         | 程序员控制         |

## 适用场景

- 需要精确控制资源释放时机
- 资源释放顺序重要
- 与 C 库交互
- 性能关键代码

## 注意事项

- 忘记显式销毁会导致资源泄漏
- 必须定义 `__del__` 方法
- 不适用于平凡类型
