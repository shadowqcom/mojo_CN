`@export` 装饰器将函数导出为公共符号。导出的函数可以从其他模块或共享库调用。

## 语法

```mojo
@export
def function_name(...):
    ...
```

## 用法

```mojo
@export
def public_api():
    pass
```

## 示例

### 导出共享库函数

```mojo
# mylib.mojo
@export
def add(a: Int, b: Int) -> Int:
    return a + b

@export
def multiply(a: Int, b: Int) -> Int:
    return a * b
```

### 与 C ABI 兼容

```mojo
@export
def process_data(data: Pointer[Int], size: Int) -> Int:
    var sum = 0
    for i in range(size):
        sum += data[i]
    return sum
```

## 适用场景

- 创建共享库
- FFI（外部函数接口）
- 插件系统
- C 互操作

## 与 `pub` 对比

| 特性         | `pub`           | `@export`         |
|--------------|-----------------|-------------------|
| 可见性       | 模块内公开      | 二进制符号公开    |
| 链接         | 可能被优化      | 保证导出          |
| 用途         | Mojo 内部使用   | 外部调用          |

## 注意事项

- 导出的函数使用 C 调用约定
- 函数签名应与 C 兼容
- 避免导出内部实现细节
