:::caution 已弃用
`@__copy_capture` 装饰器已弃用，并将在未来版本中移除。请改用当前的[闭包](/docs/manual/functions/closures/)语法配合捕获列表。
:::

你可以在旧版闭包上添加 `@__copy_capture` 装饰器，以按拷贝方式捕获寄存器可传递的值。此装饰器使嵌套函数在闭包对象形成时将指定变量的值复制到闭包对象中，而不是按引用捕获该变量。这允许你将闭包作为参数传递，但不保证生命周期会被正确尊重。

```mojo
  def foo(x: Int):
      var z = x

      @__copy_capture(z)
      @__parameter
      def formatter() -> Int:
          return z
      z = 2
      print(formatter())

  def main():
      foo(5)
```
