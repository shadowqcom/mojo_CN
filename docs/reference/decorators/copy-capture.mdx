`@copy_capture` 装饰器控制闭包如何捕获外部变量。默认情况下，闭包按引用捕获变量。使用 `@copy_capture` 可以按值捕获。

## 语法

```mojo
@copy_capture
def closure(...):
    ...
```

## 用法

### 默认行为（按引用捕获）

```mojo
def make_counter() -> def() -> Int:
    var count = 0
    def increment() capturing -> Int:
        count += 1  # 按引用捕获 count
        return count
    return increment
```

### 按值捕获

```mojo
def make_adder(x: Int) -> def(Int) -> Int:
    @copy_capture
    def add(y: Int) -> Int:
        return x + y  # 按值捕获 x
    return add

def main():
    var add5 = make_adder(5)
    print(add5(10))  # 15
```

## 示例

### 捕获当前值

```mojo
def create_closures() -> List[def() -> Int]:
    var closures: List[def() -> Int] = []
    for i in range(3):
        var value = i
        @copy_capture
        def get_value() -> Int:
            return value  # 捕获 value 的副本
        closures.append(get_value)
    return closures

def main():
    var closures = create_closures()
    for closure in closures:
        print(closure())  # 0, 1, 2
```

### 与按引用捕获对比

```mojo
def demo_capture():
    var x = 10

    # 按引用捕获
    def by_ref() capturing -> Int:
        return x

    # 按值捕获
    @copy_capture
    def by_value() -> Int:
        return x

    x = 20

    print(by_ref())   # 20（看到更新后的值）
    print(by_value()) # 10（看到捕获时的值）
```

## 注意事项

- 按值捕获需要变量是可复制的
- 按值捕获会增加内存使用（存储副本）
- 选择捕获方式取决于具体需求
