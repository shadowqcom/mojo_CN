`@implicit` 装饰器标记转换函数为隐式转换。当类型不匹配时，编译器会自动调用标记的转换函数。

## 语法

```mojo
@implicit
def __init__(out self, ...):
    ...
```

## 用法

```mojo
struct MyInt:
    var value: Int

    @implicit
    def __init__(out self, value: Int):
        self.value = value

def process(x: MyInt):
    print(x.value)

def main():
    process(42)  # 隐式转换 Int 到 MyInt
```

## 示例

### 类型包装

```mojo
struct Meters:
    var value: Float64

    @implicit
    def __init__(out self, value: Float64):
        self.value = value

def measure(distance: Meters):
    print(t"Distance: {distance.value}m")

def main():
    measure(10.5)  # 隐式转换
```

### 多种转换

```mojo
struct Flexible:
    var value: Int

    @implicit
    def __init__(out self, value: Int):
        self.value = value

    @implicit
    def __init__(out self, value: Float64):
        self.value = Int(value)

def process(x: Flexible):
    print(x.value)

def main():
    process(42)     # 从 Int 隐式转换
    process(3.14)   # 从 Float64 隐式转换
```

## 注意事项

- 过度使用隐式转换可能导致代码难以理解
- 隐式转换可能有性能开销
- 编译器只会尝试一次隐式转换
- 避免创建循环转换链
