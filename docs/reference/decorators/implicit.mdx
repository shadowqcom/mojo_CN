你可以在任何单参数初始化器上添加 `@implicit` 装饰器，将其标识为可进行隐式转换。

例如：

```mojo
struct MyInt:
    var value: Int

    @implicit
    def __init__(out self, value: Int):
        self.value = value

    def __init__(out self, value: Float64):
        self.value = Int(value)
```

此隐式转换初始化器允许你将 `Int` 传递给接受 `MyInt` 参数的函数，或将 `Int` 赋值给 `MyInt` 类型的变量。但是，接受 `Float64` 值的初始化器 **不是** 隐式转换初始化器，因此必须显式调用：

```mojo
def func(n: MyInt):
    print("MyInt value: ", n.value)

def main():
    func(Int(42))             # Implicit conversion from Int: OK
    func(MyInt(Float64(4.2))) # Explicit conversion from Float64: OK
    func(Float64(4.2))        # Error: can't convert Float64 to MyInt
```

## 弃用

随着时间的推移，你可能会决定隐式转换不再适合你的代码库。例如，它可能掩盖复杂性或导致函数重载歧义。在这种情况下，Mojo 允许你使用 `@implicit` 装饰器内置的 `deprecated` 参数将转换标记为已弃用。弃用允许你逐步淘汰转换，而不是导致行为的突然变化。

向 `deprecated` 参数提供一个布尔值：

```mojo
struct MyStruct:
    @implicit(deprecated=True)
    def __init__(out self, value: Int):
        # ...
```

这告诉编译器在隐式使用该转换时发出警告，而不会破坏现有代码：

```mojo
_: MyStruct = 1  # Warns on implicit conversion

_ = MyStruct(1)  # No warning. Conversion is explicit
```
