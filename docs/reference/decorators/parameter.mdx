`@parameter` 装饰器标记函数为参数函数。参数函数在编译时求值，用于编译时计算。

## 语法

```mojo
@parameter
def function_name(...):
    ...
```

## 用法

```mojo
@parameter
def factorial(n: Int) -> Int:
    if n <= 1:
        return 1
    return n * factorial(n - 1)

def main():
    comptime result = factorial(5)  # 编译时计算
    print(result)  # 120
```

## 示例

### 编译时常量

```mojo
@parameter
def compute_size() -> Int:
    return 1024 * 1024

def main():
    var buffer: Array[UInt8, compute_size()]
```

### 类型计算

```mojo
@parameter
def select_type[use_float: Bool]() -> type:
    if use_float:
        return Float64
    return Int64

def main():
    var x: select_type[True]() = 3.14
```

### 编译时断言

```mojo
@parameter
def static_assert(condition: Bool, message: StringLiteral):
    if not condition:
        _compile_error(message)

def main():
    static_assert(size_of[Int]() == 8, "Expected 64-bit Int")
```

## 与运行时函数对比

| 特性         | 参数函数         | 运行时函数       |
|--------------|------------------|------------------|
| 求值时机     | 编译时           | 运行时           |
| 参数要求     | 编译时已知       | 任意             |
| 性能         | 无运行时开销     | 有调用开销       |
| 用途         | 编译时计算       | 运行时逻辑       |

## 注意事项

- 参数函数的参数必须是编译时已知的
- 不能有副作用
- 递归深度受编译器限制
