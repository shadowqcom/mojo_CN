:::caution 已弃用
`@__parameter` 装饰器已弃用，并将在未来版本中移除。请改用当前的[闭包](/docs/manual/functions/closures/)语法。先前的拼写 `@parameter` 仍被接受，但会发出弃用警告。
:::

你可以在嵌套函数上添加 `@__parameter` 来创建一个旧版的捕获式闭包。这意味着你可以创建一个闭包函数，该函数捕获来自外部作用域的值（无论它们是变量还是参数），然后将该闭包作为参数使用。例如：

```mojo
def use_closure[func: fn(Int) capturing [_] -> Int](num: Int) -> Int:
    return func(num)

def create_closure():
    var x = 1

    @__parameter
    def add(i: Int) -> Int:
        return x + i

    var y = use_closure[add](2)
    print(y)

create_closure()
```

```output
3
```

请注意函数类型中的 `[_]`：

```mojo
def use_closure[func: fn(Int) capturing [_] -> Int](num: Int) -> Int:
```

此 origin 指定符表示旧版闭包所捕获值的 origin 集合。这允许编译器正确延长这些值的生命周期。有关生命周期和 origin 的更多信息，请参阅[生命周期、origin 和引用](/docs/manual/values/lifetimes/)。
