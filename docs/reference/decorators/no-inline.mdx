`@no_inline` 装饰器禁止函数内联。编译器会生成真正的函数调用，而不是将函数体插入到调用位置。

## 语法

```mojo
@no_inline
def function_name(...):
    ...
```

## 用法

```mojo
@no_inline
def complex_operation(x: Int) -> Int:
    # 复杂的实现...
    return result
```

## 适用场景

### 减少代码膨胀

```mojo
@no_inline
def large_function():
    # 大量代码
    pass
```

### 调试

```mojo
@no_inline
def debug_helper():
    # 在调试器中更容易设置断点
    pass
```

### 热点代码分离

```mojo
@no_inline
def cold_path():
    # 很少执行的代码
    pass

@always_inline
def hot_path():
    # 频繁执行的代码
    pass
```

## 与 `@always_inline` 对比

| 装饰器         | 行为               |
|----------------|--------------------|
| `@always_inline` | 强制内联         |
| `@no_inline`     | 禁止内联         |
| 无装饰器         | 编译器决定       |

## 注意事项

- 可能增加函数调用开销
- 可能减少代码膨胀
- 适用于调试和性能分析
