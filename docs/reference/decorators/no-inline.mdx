你可以在任何函数上添加 `@no_inline` 装饰器，以阻止编译器将其内联。

```mojo
@no_inline
def my_large_function():
    ...
```

内联是一种优化，可减少小型、频繁调用函数的调用开销。可以使用
[`@always_inline`](/docs/reference/decorators/always-inline/) 显式标记函数进行内联，或者由编译器自动内联。

过多的内联函数会拖慢编译速度，并大幅增加编译后程序的二进制大小。特别是对于大型或复杂的函数，内联可能不会带来太多收益。
