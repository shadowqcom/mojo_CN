Mojo 提供丰富的数值类型，包括有符号和无符号整数、浮点数和 SIMD 向量。本页涵盖这些类型及其操作。

## 整数类型

### 有符号整数

| 类型    | 范围                                      | 大小   |
|---------|-------------------------------------------|--------|
| `Int`   | 机器宽度（通常 -2^63 到 2^63-1）          | 64 位  |
| `Int8`  | -128 到 127                               | 8 位   |
| `Int16` | -32,768 到 32,767                         | 16 位  |
| `Int32` | -2,147,483,648 到 2,147,483,647           | 32 位  |
| `Int64` | -2^63 到 2^63-1                           | 64 位  |

### 无符号整数

| 类型     | 范围                    | 大小   |
|----------|-------------------------|--------|
| `UInt8`  | 0 到 255                | 8 位   |
| `UInt16` | 0 到 65,535             | 16 位  |
| `UInt32` | 0 到 4,294,967,295      | 32 位  |
| `UInt64` | 0 到 2^64-1             | 64 位  |

### 整数字面量

```mojo
var decimal = 42
var hex = 0xFF
var octal = 0o52
var binary = 0b101010
```

### 整数运算

```mojo
var a: Int = 10
var b: Int = 3

print(a + b)   # 13（加法）
print(a - b)   # 7（减法）
print(a * b)   # 30（乘法）
print(a / b)   # 3（除法，向零取整）
print(a // b)  # 3（截断除法）
print(a % b)   # 1（取模）
print(a ** 2)  # 100（幂运算）
```

### 位运算

```mojo
var a: Int = 0b1010
var b: Int = 0b1100

print(a & b)   # 8（与）
print(a | b)   # 14（或）
print(a ^ b)   # 6（异或）
print(~a)      # -11（取反）
print(a << 2)  # 40（左移）
print(a >> 2)  # 2（右移）
```

## 浮点类型

| 类型      | 描述             | 精度           | 大小   |
|-----------|------------------|----------------|--------|
| `Float16` | 半精度浮点数     | ~3 位小数      | 16 位  |
| `Float32` | 单精度浮点数     | ~7 位小数      | 32 位  |
| `Float64` | 双精度浮点数     | ~15 位小数     | 64 位  |

### 浮点字面量

```mojo
var a = 3.14
var b = 2.5e-3
var c: Float32 = 1.0
```

### 浮点运算

```mojo
var a: Float64 = 3.14
var b: Float64 = 2.0

print(a + b)   # 5.14
print(a - b)   # 1.14
print(a * b)   # 6.28
print(a / b)   # 1.57
print(a ** 2)  # 9.8596
```

### 特殊值

```mojo
var inf = Float64.inf
var neg_inf = Float64.neg_inf
var nan = Float64.nan
```

## SIMD 类型

SIMD（单指令多数据）类型允许并行处理多个值：

```mojo
var a = SIMD[DType.float32, 4](1.0, 2.0, 3.0, 4.0)
var b = SIMD[DType.float32, 4](5.0, 6.0, 7.0, 8.0)

var sum = a + b   # [6.0, 8.0, 10.0, 12.0]
var prod = a * b  # [5.0, 12.0, 21.0, 32.0]
```

### 创建 SIMD 值

```mojo
# 从标量广播
var a = SIMD[DType.float32, 4](1.0)

# 从列表
var b = SIMD[DType.float32, 4]([1.0, 2.0, 3.0, 4.0])

# 从值
var c = SIMD[DType.float32, 4](1.0, 2.0, 3.0, 4.0)
```

### SIMD 运算

```mojo
var a = SIMD[DType.int32, 4](1, 2, 3, 4)
var b = SIMD[DType.int32, 4](5, 6, 7, 8)

# 算术运算
var sum = a + b
var diff = a - b
var prod = a * b
var quot = a / b

# 比较运算
var eq = a == b  # SIMD[bool, 4]
var lt = a < b

# 位运算
var and_result = a & b
var or_result = a | b
var xor_result = a ^ b
```

### 归约运算

```mojo
var a = SIMD[DType.float32, 4](1.0, 2.0, 3.0, 4.0)

print(a.sum())     # 10.0
print(a.product()) # 24.0
print(a.min())     # 1.0
print(a.max())     # 4.0
```

## DType 枚举

`DType` 枚举指定数值类型：

```mojo
alias int8 = DType.int8
alias int16 = DType.int16
alias int32 = DType.int32
alias int64 = DType.int64
alias float16 = DType.float16
alias float32 = DType.float32
alias float64 = DType.float64
alias bool = DType.bool
```

### 类型大小

```mojo
print(size_of[Int32]())   # 4
print(size_of[Float64]()) # 8
```

## 类型转换

### 整数之间

```mojo
var a: Int32 = 42
var b: Int64 = Int64(a)
var c: Int16 = Int16(a)
```

### 整数到浮点

```mojo
var a: Int = 42
var b: Float64 = Float64(a)
```

### 浮点到整数

```mojo
var a: Float64 = 3.14
var b: Int = Int(a)  # 3（截断）
```

### 饱和转换

```mojo
var a: Int64 = 300
var b: UInt8 = UInt8(a)  # 255（饱和到最大值）
```

## 数值 Trait

### `Numeric`

`Numeric` trait 组合基本数值操作：

```mojo
trait Numeric(
    Addable, Subable, Mulable, Divable,
    Comparable, Copyable
):
    ...
```

### `Intable`

可以转换为整数：

```mojo
def process[T: Intable](value: T):
    var n = Int(value)
```

### `Floatable`

可以转换为浮点数：

```mojo
def process[T: Floatable](value: T):
    var f = Float64(value)
```

## 数值函数

### 数学函数

```mojo
from math import sqrt, sin, cos, tan, exp, log, abs

print(sqrt(16.0))  # 4.0
print(abs(-5))     # 5
print(sin(0.0))    # 0.0
```

### 舍入函数

```mojo
from math import floor, ceil, round, trunc

print(floor(3.7))  # 3
print(ceil(3.2))   # 4
print(round(3.5))  # 4
print(trunc(3.7))  # 3
```

### 范围检查

```mojo
from math import clamp, min, max

print(clamp(15, 0, 10))  # 10
print(min(3, 5))         # 3
print(max(3, 5))         # 5
```
