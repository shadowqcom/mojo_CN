*函数声明*引入一个命名的、可调用的代码单元。Mojo 中的每个函数都以 `def` 关键字开头：

```mojo
def greet(name: String) -> String:
    return "Hello, " + name
```

最简单的函数只有名称、空括号和主体：

```mojo
def do_nothing():
    pass
```

## 函数名称

函数名称必须是有效的标识符。反引号转义标识符允许使用关键字作为函数名：

```mojo
def `import`():
    print("In `import`")

def main():
    `import`() # In `import`
```

## 函数签名

{/*  VERIFIED: From ParserStmts.cpp, Signatures.h  */}

```text
def name(argument-list) -> ReturnType:
    body

def name[parameter-list](argument-list) -> ReturnType:
    body

def name(argument-list) raises -> ReturnType:
    body

def name[parameter-list](argument-list)
    -> ReturnType where constraint:
    body

def name[parameter-list](argument-list) raises
    -> ReturnType where constraint:
    body
```

签名可以包含名称、参数列表、参数列表、效果、返回类型和 `where` 子句。只有括号和冒号是必需的。

*参数*是括号中的运行时值。*形参*是方括号中的编译时值。在其他语言中，这两者都被称为"参数"。Mojo 区分它们以避免混淆：

```mojo
def clamp[T: Comparable & ImplicitlyCopyable](
    val: T, lo: T, hi: T,
) -> T:
    if val < lo:
        return lo
    if val > hi:
        return hi
    return val
```

## 标记符

三个标记符将参数和形参列表划分为控制调用者如何传递值的区域：

| 标记符 | 参数           | 形参           |
|--------|----------------|----------------|
| `//`   | 无             | 推断           |
| `/`    | 仅位置         | 仅位置         |
| `*`    | 仅关键字       | 仅关键字       |

标记符必须按此顺序出现：`//`，然后 `/`，然后 `*`。每个只能出现一次。`/` 不能是列表中的第一个，`*` 不能是最后一个。

:::note
Mojo 标记符遵循 Python 的 PEP 570 和 PEP 3102 约定。
:::

### 仅推断标记符（`//`，仅用于形参）

`//` 分隔推断形参和命名形参。编译器从调用点参数推断推断形参：

```mojo
from std.reflection import reflect

def inferred_type[T: Writable, //](value: T):
    print(t"Value is {value}. Type is {reflect[T].name()}.")

def main():
    inferred_type(5)       # Value is 5. Type is Int.
    inferred_type("Hello") # Value is Hello. Type is String.
```

仅推断形参不能按位置指定：

```mojo
# 错误：'inferred_type' 期望 0 个位置参数，
# 但指定了 1 个
inferred_type[Int](5)
```

关键字语法可以绕过此限制：

```mojo
inferred_type[T=Int](5) # OK: Value is 5. Type is Int.

# 错误：传递给 'value' 的值无法从
# 'StringLiteral["Hello"]' 转换为 'Int'
inferred_type[T=Int]("Hello")
```

推断不限于仅推断形参。在有足够上下文的情况下，编译器也可以推断命名形参：

```mojo
def add[T: Intable](a: T, b: T) -> Int:
    return Int(a) + Int(b)

def main():
    print(t"Sum is {add[Int](1, 2)}.")         # 显式 T
    print(t"Sum is {add(1, 2)}.")              # 推断 T
    print(t"Sum is {add[Float64](4.5, 1.2)}.") # 显式
    print(t"Sum is {add(4.5, 1.2)}.")          # 推断
```

### 仅位置标记符（`/`）

`/` 之前的所有内容都是仅位置的。调用者必须按位置传递这些值，不能按名称：

```mojo
def div(a: Int, b: Int, /):
    return a // b

div(10, 3)       # OK
div(a=10, b=3)   # 错误
```

### 仅关键字标记符（`*`）

`*` 之后的所有内容都是仅关键字的。调用者必须按名称传递值：

```mojo
def configure(*, verbose: Bool, retries: Int):
    ...

configure(verbose=True, retries=3)  # OK
configure(True, 3)                  # 错误
```

`*args` 可变参数对跟随它的参数有相同的效果：

```mojo
def sum(*values: Int, name: String) -> Int:
    print(name, end=": ")
    total = 0
    for value in values:
        total += value
    return total

def main():
    print(sum(1, 2, 3, name="total"))  # total: 6
    # print(sum(1, 2, 3, "subtotal"))
        # 错误：缺少必需的关键字参数
```

## 默认值

参数可以有默认值。一旦出现默认值，后续的每个位置参数也必须有默认值：

```mojo
def connect(
    host: String = "www.modular.com", port: Int = 80,
):
    print(t"Connecting to {host}:{port}")

def main():
    connect()             # Connecting to www.modular.com:80
    connect(port=8080)    # Connecting to www.modular.com:8080
```

```mojo
def my_function(x: Int, y: Int = 0, z: Int = 0) -> Int:
    return x + y + z

# 错误：必需的位置参数跟在可选
# 位置参数之后
# def bad(x: Int, y: Int = 0, z: Int):
#     return x + y + z
```

仅关键字参数不受此排序规则限制。它们可以自由混合必需和可选参数：

```mojo
def configure(*, retries: Int = 3, verbose: Bool):
    pass
```

形参也支持默认值。

## 函数约束

`where` 子句约束编译时形参。它出现在声明的末尾，返回类型之后（如果没有返回类型则在参数列表之后）：

```mojo
comptime LESS_THAN: Int32 = -1
comptime EQUAL: Int32 = 0
comptime GREATER_THAN: Int32 = 1

def compare[T: AnyType](
    x: T, y: T,
) -> Int32 where conforms_to(T, Comparable):
    if x < y:
        return LESS_THAN
    elif x > y:
        return GREATER_THAN
    else:
        return EQUAL

def main():
    print(compare(5, 10))  # -1 (LESS_THAN)
    print(compare(7, 7))   # 0 (EQUAL)
    print(compare("Z", "A")) # 1 (GREATER_THAN)
```

`where` 子句可以表达复杂的约束，例如将 SIMD 向量大小限制为特定的 2 的幂：

```mojo
def process[
    n: Int,
](data: SIMD[DType.float32, n]) -> Float32 where (
    n == 1 or n == 2 or n == 4 or n == 8 or n == 16 or n == 32
):
    var sum: Float32 = 0.0
    for i in range(n):
        sum += data[i]
    return sum


def main():
    var data = SIMD[DType.float32, 16](255.0)
    var sum = process[n=16](data)
    print(t"Sum: {sum}")  # Sum: 4080.0
```

`where` 子句只在声明末尾有效。它们在参数或形参列表内无效：

```mojo
# 错误：where 子句在参数列表中无效
def bad[n: Int where n > 0]():
    pass

# 错误：where 子句在参数列表中无效
def bad(x: Int where x > 0):
    pass
```

## 参数约定

*参数约定*控制值如何传递给函数。它出现在参数名称之前。

### `mut`

调用者的值通过可变引用传递。函数内的更改对调用者可见：

```mojo
def double_it(mut x: Int):
    x *= 2
```

`mut` 参数不能有默认值：

```mojo
# 错误：'mut' 参数不能有默认值
def bad(mut x: Int = 0):
    pass
```

### `var`

函数接收一个拥有的副本。如果调用者使用 `^` 转移所有权，原始值将不可访问。否则，值会被复制，调用者保持访问权限：

```mojo
def consume(var s: String):
    s += "!"
    print(s)

def main():
    var greeting = "Hello"
    consume(greeting)   # Hello!（复制）
    print(greeting)     # Hello

    consume(greeting^)  # Hello!（移动）
    # print(greeting)   # 错误：移动后未初始化
```

### `out`

`out` 参数是函数的返回槽。只允许一个 `out` 参数。它替代 `->` 返回类型：

```mojo
def make_int(out result: Int):
    result = 42

def main():
    var x = make_int()
    print(x)  # 42
```

函数不能同时使用 `out` 和 `-> Type`：

```mojo
# 错误：函数不能同时有 'out' 参数
#        和显式结果类型
def bad(out result: Int) -> Int:
    result = 0
```

`out` 参数不能有默认值，也不能是可变参数。

### `deinit`

函数获取所有权并销毁值。`__del__` 中的 `self` 和移动构造函数中的 `existing` 参数需要此约定：

```mojo
struct Resource:
    var handle: Int

    def __del__(deinit self):
        _release(self.handle)
```

析构函数不能引发。平凡类型不能定义析构函数。

### `ref`

传递带有显式*源*说明符的引用。源跟踪引用的来源：

```mojo
def get_first[T: Copyable](
    ref data: List[T],
) -> ref [origin_of(data)]T:
    return data[0]

def main():
    data = ["one", "two", "three"]
    first = get_first(data)
    print(first)  # one
```

### 默认约定

没有约定时，参数是不可变且借用的。调用者保持所有权：

```mojo
def length[T: Copyable](s: List[T]) -> Int:
    return len(s)
```

## 可变参数

可变参数接受可变数量的值（"不定元数"）。这在像 `print` 这样可以接受任意数量参数的函数中可以看到。

### 同质可变参数

参数名前的 `*` 接受任意数量的相同类型的位置参数（同质参数）：

```mojo
def sum_all(*values: Int) -> Int:
    var total = 0
    for v in values:
        total += v
    return total
```

### 可变参数包

类型注解前的 `*` 和名称前的 `*` 创建*可变参数包*，接受不同类型的参数（异质参数）：

```mojo
def print_all[*Ts: Writable](*args: *Ts):
    comptime for idx in range(args.__len__()):
        print(args[idx], end=" ")
    print()

def main():
    print_all("Hello", 42, 3.14) # Hello 42 3.14
```

### 可变参数限制

函数最多只能有一个 `*args`。可变参数不能有默认值：

```mojo
# 错误：可变参数不能有默认值
def bad(*args: Int = 0):
    pass
```

`out` 参数不能是可变参数：

```mojo
# 错误：'out' 约定不能是可变参数
def bad(out *results: Int):
    pass
```

## 函数效果

效果出现在闭括号之后、`->` 之前。

### `raises`
声明函数可以引发错误。可选的错误类型可以跟在 `raises` 之后：

```mojo
def parse(text: String) raises -> Int:
    ...

def parse_strict(text: String) raises ValueError -> Int:
    ...
```

函数最多可以在 `raises` 后指定一种错误类型。

### `thin`
声明函数类型不从其定义作用域捕获值。thin 函数是函数指针，不是闭包。

```mojo
def map[
    T: Copyable, U: Copyable
](f: def(T) thin -> U, input: List[T]) -> List[U]:
    var result: List[U] = []
    for item in input:
        result.append(f(item))
    return result^

# `square` 不捕获任何值，所以它是 `thin`
def square(x: Int) -> Int:
    return x * x

def main():
    var nums: List[Int] = [1, 2, 3]
    var squares = map(square, nums)
    print(squares)  # 输出：[1, 4, 9]
```

### `abi("C")`
声明函数使用 C 调用约定。因为 C 没有闭包机制，`abi("C")` 总是与 `thin` 一起出现：

```mojo
from std.ffi import OwnedDLHandle

def main() raises:
    # 在 Linux 上。在 macOS 上，使用 "libSystem.dylib" 等
    var lib = OwnedDLHandle("libm.so")
    var sqrt = lib.get_function[def(Float64) thin abi("C") -> Float64](
        "sqrt"
    )
    print(sqrt(4.0))  # 2.0
```

### `register_passable`
声明函数值可以通过寄存器传递而不是通过引用传递。可寄存器传递的函数没有堆捕获，也没有需要稳定内存地址的捕获，使其适合高性能上下文，如并行执行和 GPU 内核。

```mojo
def apply[F: def(Int) register_passable -> Int](f: F, x: Int) -> Int:
    return f(x)

def double(x: Int) register_passable -> Int:
    return x * 2

def main():
    print(apply(double, 21))  # 42
```

`F` 上的类型约束
`def(Int) register_passable -> Int` 强制调用者只能传递 `register_passable` 可调用对象。

## 返回类型

`->` 引入返回类型。它出现在任何效果之后：

```mojo
def square(x: Int) -> Int:
    return x * x
```

没有 `->`，函数返回 `None`。

## 特殊方法

某些方法名称有强制签名。编译器检查参数数量、约定和返回类型。

### `__init__`

初始化器必须有 `out self` 结果：

```mojo
struct Point:
    var x: Int
    var y: Int

    def __init__(out self, x: Int, y: Int):
        self.x = x
        self.y = y
```

没有 `out self`，编译器会拒绝该方法：

```mojo
# 错误：__init__ 方法必须返回 Self 类型
#        并带有 'out' 参数
def __init__(self):
    pass
```

### 复制构造函数

复制构造函数是带有单个名为 `copy` 的仅关键字参数的 `__init__`：

```mojo
def __init__(out self, *, copy: Self):
    self.x = copy.x
    self.y = copy.y
```

`copy` 参数必须使用 `read` 约定（默认）。复制构造函数不能引发。平凡类型不能定义复制构造函数。

### 移动构造函数

移动构造函数是带有单个名为 `take` 的仅关键字参数的 `__init__`：

```mojo
def __init__(out self, *, deinit take: Self):
    self.x = take.x
    self.y = take.y
```

`take` 参数必须使用 `deinit` 约定。移动构造函数不能引发。

:::note
`@register_passable` 类型不能定义移动构造函数。
它们总是可以通过复制寄存器来移动。
:::

### `__del__`

析构函数使用 `deinit self`：

```mojo
def __del__(deinit self):
    _release(self.handle)
```

析构函数不能引发。平凡类型不能定义析构函数。

## 嵌套函数

函数可以在其他函数内部定义。嵌套函数捕获外部作用域的值：

```mojo
def outer(x: Int) -> Int:
    def inner() unified {read} -> Int:
        return x + 1
    return inner()
```

编译器立即解析嵌套函数主体，以便正确绑定捕获。

## 静态方法

`@staticmethod` 使结构体方法可以在没有实例的情况下调用。静态方法不接受 `self`：

```mojo
struct MathUtils:
    comptime pi: Float64 = 3.141592653589793

    @staticmethod
    def square(x: Int) -> Int:
        return x * x

def main():
    print(MathUtils.square(5))  # 25
    print(MathUtils.pi)         # 3.141592653589793
```
