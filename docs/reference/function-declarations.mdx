*函数声明*（function declaration）引入一个命名的、可调用的代码单元。Mojo 中的每个函数都以 `def` 关键字开头：

```mojo
def greet(name: String) -> String:
    return "Hello, " + name
```

最简单的函数只有名称、空括号和主体：

```mojo
def do_nothing():
    pass
```

## 函数名称

函数名称必须是有效的标识符。反引号转义标识符允许使用关键字作为函数名：

```mojo
def `import`():
    print("In `import`")

def main():
    `import`() # In `import`
```

## 函数签名

{/* VERIFIED: From ParserStmts.cpp, Signatures.h */}

```text
def name(argument-list) -> ReturnType:
    body

def name[parameter-list](argument-list) -> ReturnType:
    body

def name(argument-list) raises -> ReturnType:
    body

def name[parameter-list](argument-list)
    -> ReturnType where constraint:
    body

def name[parameter-list](argument-list) raises
    -> ReturnType where constraint:
    body
```

签名可以包含名称、参数列表、参数列表、效果、返回类型和 `where` 子句。只有括号和冒号是必需的。

*参数*（arguments）是括号中的运行时值。*形参*（parameters）是方括号中的编译时值。在其他语言中这两者都被称为"parameters"。Mojo 区分它们以避免混淆：

```mojo
# T must be both `Comparable` (to test with `<` and `>`) and
# `ImplicitlyCopyable` or you won't be able to return
def clamp[T: Comparable & ImplicitlyCopyable](
    val: T, lo: T, hi: T,
) -> T:
    if val < lo:
        return lo
    if val > hi:
        return hi
    return val
```

## 标记符

三个标记符将参数和形参列表划分为控制调用者如何传递值的区域：

| 标记符 | 参数           | 形参            |
|--------|----------------|-----------------|
| `//`   | 无             | 仅推断          |
| `/`    | 仅位置         | 仅位置          |
| `*`    | 仅关键字       | 仅关键字        |

标记符必须按此顺序出现：`//`，然后 `/`，然后 `*`。每个只能出现一次。`/` 不能是列表中的第一个，`*` 不能是最后一个。

:::note
Mojo 标记符遵循 Python 的 PEP 570 和 PEP 3102 约定。
:::

### 仅推断标记符（`//`，仅用于形参）

`//` 分隔推断形参与命名形参。编译器从调用点参数推断推断形参：

```mojo
def inferred_type[T: Writable, //](value: T):
    print(t"Value is {value}. Type is {reflect[T].name()}.")

def main():
    inferred_type(5)       # Value is 5. Type is SIMD[DType.int, 1].
    inferred_type("Hello") # Value is Hello. Type is String.
```

推断形参不能按位置指定：

```mojo
# Error because 'inferred_type' got 1 positional parameter
# but expected none.
inferred_type[Int](5)
```

关键字语法可以绕过此限制：

```mojo
inferred_type[T=Int](5) # OK: Value is 5. Type is Int.

# Error because value passed to 'value' cannot be converted from
# 'StringLiteral["Hello"]' to 'Int'
inferred_type[T=Int]("Hello")
```

推断不限于推断形参。在有足够上下文的情况下，编译器也可以推断命名形参：

```mojo
def add[T: Intable](a: T, b: T) -> Int:
    return Int(a) + Int(b)

def main():
    print(t"Sum is {add[Int](1, 2)}.")         # Explicit T
    print(t"Sum is {add(1, 2)}.")              # Inferred T
    print(t"Sum is {add[Float64](4.5, 1.2)}.") # Explicit
    print(t"Sum is {add(4.5, 1.2)}.")          # Inferred
```

### 仅位置标记符（`/`）

`/` 之前的所有内容都是仅位置的。调用者必须按位置传递这些值，不能按名称：

```mojo
def div(a: Int, b: Int, /):
    return a // b

div(10, 3)       # OK
div(a=10, b=3)   # Error
```

### 仅关键字标记符（`*`）

`*` 之后的所有内容都是仅关键字的。调用者必须按名称传递值，无论是形参还是参数：

```mojo
def configure(*, verbose: Bool, retries: Int):
    # ...

configure(verbose=True, retries=3)  # OK
configure(True, 3)                  # Error
```

`*args` 可变参数对跟随它的参数有相同的效果：

```mojo
def sum(*values: Int, name: String) -> Int:
    print(name, end=": ")
    var total = 0
    for value in values:
        total += value
    return total

def main():
    print(sum(1, 2, 3, name="total"))  # total: 6
    # print(sum(1, 2, 3, "subtotal"))
        # Error because missing required keyword argument
```

## 默认值

参数可以有默认值。一旦出现默认值，后续的每个位置参数也必须有默认值：

```mojo
def connect(
    host: String = "www.modular.com", port: Int = 80,
):
    print(t"Connecting to {host}:{port}")

def main():
    connect()             # Connecting to www.modular.com:80
    connect(port=8080)    # Connecting to www.modular.com:8080
```

```mojo
def my_function(x: Int, y: Int = 0, z: Int = 0) -> Int:
    return x + y + z

# Error because required positional argument follows optional
# positional argument
# def wrong(x: Int, y: Int = 0, z: Int):
#     return x + y + z
```

仅关键字参数不受此排序规则限制。它们可以自由混合必需和可选参数：

```mojo
def configure(*, retries: Int = 3, verbose: Bool):
    pass
```

形参也支持默认值。

## 函数约束

`where` 子句约束编译时形参。它出现在声明的末尾，返回类型之后（如果没有返回类型则在参数列表之后）：

```mojo
comptime LESS_THAN: Int32 = -1
comptime EQUAL: Int32 = 0
comptime GREATER_THAN: Int32 = 1

def compare[T: AnyType](
    x: T, y: T,
) -> Int32 where conforms_to(T, Comparable):
    if x < y:
        return LESS_THAN
    elif x > y:
        return GREATER_THAN
    else:
        return EQUAL

def main():
    print(compare(5, 10))  # -1 (LESS_THAN)
    print(compare(7, 7))   # 0 (EQUAL)
    print(compare("Z", "A")) # 1 (GREATER_THAN)
```

`where` 子句可以表达复杂的约束，例如将 SIMD 向量大小限制为特定的 2 的幂：

```mojo
def process[
    n: Int,
](data: SIMD[DType.float32, n]) -> Float32 where (
    n == 1 or n == 2 or n == 4 or n == 8 or n == 16 or n == 32
):
    var sum: Float32 = 0.0
    for i in range(n):
        sum += data[i]
    return sum


def main():
    var data = SIMD[DType.float32, 16](255.0)
    var sum = process[n=16](data)
    print(t"Sum: {sum}")  # Sum: 4080.0
```

`where` 子句应位于声明末尾：

```mojo
# Correct: the `where` clause follows the signature.
def correct[n: Int]() where n > 0:
    pass
```

`where` 子句在形参列表中无效。请将其添加到声明末尾：

```mojo
# Wrong: `where` is not allowed inside a parameter list.
def wrong[n: Int where n > 0]():
    pass
```

`where` 子句在参数列表中无效：

```mojo
# Wrong: `where` clauses can only be used with compile-time parameters.
def wrong(x: Int where x > 0):
    pass
```

一个 [`thin`](#thin) 函数*类型*可以携带自己的尾部 `where` 子句，用于约束该类型声明的形参。参见[受约束的函数类型](#constrained-function-types)。

## 参数约定

*参数约定*（argument convention）控制参数值如何传递给函数。它出现在参数名称之前。

### `mut`

调用者的值通过可变引用传递。函数内的修改对调用者可见：

```mojo
def double_it(mut x: Int):
    x *= 2
```

`mut` 参数不能有默认值：

```mojo
# Error because 'mut' arguments may not have defaults
def wrong(mut x: Int = 0):
    pass
```

### `var`

函数接收一个拥有的副本。如果调用者使用 `^` 转移所有权，原始值将变得不可访问。否则值会被复制，调用者保持访问权限：

```mojo
def consume(var s: String):
    s += "!"
    print(s)

def main():
    var greeting = "Hello"
    consume(greeting)   # Hello! (copied)
    print(greeting)     # Hello

    consume(greeting^)  # Hello! (moved)
    # print(greeting)   # Error because uninitialized after move
```

### `out`

`out` 参数是函数的返回槽。只允许一个 `out` 参数。它替代 `->` 返回类型：

```mojo
def make_int(out result: Int):
    result = 42

def main():
    var x = make_int()
    print(x)  # 42
```

函数不能同时使用 `out` 和 `-> Type`：

```mojo
# Error because function cannot have both an 'out' argument
#        and an explicit result type
def wrong(out result: Int) -> Int:
    result = 0
```

### `deinit`

函数获取所有权并销毁值。`__deinit__()` 中的 `self` 以及移动初始化器中的参数需要此约定：

```mojo
struct Resource:
    var handle: Int

    def __deinit__(deinit self):
        _release(self.handle)
```

### `ref`

传递带有显式*来源*（origin）说明符的引用。来源跟踪引用的来源：

```mojo
def get_first[T: Copyable](ref data: List[T]) -> ref[data[0]] T:
    return data[0]

def main():
    var data = ["one", "two", "three"]
    ref first = get_first(data)  # mutable because `data` is mutable
    print(first)  # one
    first = "Первый"
    print(data)  # ['Первый', 'two', 'three']
```

### 默认约定

没有约定时，参数是不可变的只读引用。调用者保持所有权：

```mojo
def length[T: Copyable](s: List[T]) -> Int:
    return len(s)
```

## 可变参数

可变参数接受可变数量的值（"不定元数"）。像 `print` 这样的函数使用可变参数来接受任意数量的值。

### 同质可变参数

参数名前的 `*` 接受任意数量的相同类型的位置参数（同质参数）：

```mojo
def sum_all(*values: Int) -> Int:
    var total = 0
    for v in values:
        total += v
    return total
```

### 可变参数包

在名称*和*类型注解前都使用 `*` 会创建*可变参数包*（variadic pack），它接受不同类型的参数（异质参数）：

```mojo
def print_all[*Ts: Writable](*args: *Ts):
    comptime for idx in range(args.__len__()):
        print(args[idx], end=" ")
    print()

def main():
    print_all("Hello", 42, 3.14)  # Hello 42 3.14
```

:::note 为什么不用 `len(args)`？
`args` 的类型是 `VariadicPack`，而 `VariadicPack.__len__()` 是一个 `@staticmethod`，所以 `args.__len__()` 等同于 `type_of(args).__len__()`。编译器可以在编译时求值它。

`len(args)` 不起作用是因为 `args` 是一个动态值，因此 `len(args)` 是一个动态表达式。你不能用动态值来驱动 `comptime for`。
:::

### 可变参数限制

函数最多只能有一个 `*args`。可变参数不能有默认值：

```mojo
# Error because variadic arguments may not have defaults
def wrong(*args: Int = 0):
    pass
```

`out` 参数不能是可变参数：

```mojo
def wrong(out *results: Int):
    pass
```

## 函数效果

效果出现在闭括号之后、`->` 之前。

### `raises`

声明函数可以引发错误。可选的错误类型可以跟在 `raises` 之后：

```mojo
def parse(text: String) raises -> Int:
    # ...

def parse_strict(text: String) raises SomeError -> Int:
    # ...
```

函数最多可以在 `raises` 后指定一种错误类型。

### `thin`

仅用于函数*类型*，`thin` 表示函数指针类型（不是闭包），并确保函数值不从其定义作用域捕获值。不要在函数声明中使用 `thin`。

```mojo
def map[
    T: Copyable, U: Copyable
](f: def(T) thin -> U, input: List[T]) -> List[U]:  # Used as type
    var result: List[U] = []
    for item in input:
        result.append(f(item))
    return result^

# `square` doesn't capture values. It can be passed to a thin type
def square(x: Int) -> Int:
    return x * x

def main():
    var nums: List[Int] = [1, 2, 3]
    var squares = map(square, nums)
    print(squares)  # Output: [1, 4, 9]
```

#### 受约束的函数类型

声明了形参的 `thin` 函数类型可以用尾部 `where` 子句约束这些形参，子句写在结果类型之后。该约束是类型的一部分：调用者必须证明它对所绑定的形参成立。

```mojo
comptime Kernel = def[w: Int](Int) thin -> None where (
    w > 0, "width must be positive"
)

def apply[F: Kernel](x: Int):
    F[4](x)     # ok
    F[0](x)     # error: violated constraint
```

约束是逆变的。当一个函数自身的 `where` 子句被类型的 `where` 子句蕴含，或者它没有 `where` 子句时——即类型向调用者承诺的比函数要求的更多——该函数就满足此类型。要求比类型所承诺的更多的函数会被拒绝。

只有 `thin` 函数类型接受 `where` 子句。该子句绑定到最内层的函数类型，因此当声明级别的 `where` 紧跟一个函数类型结果时，需要将该结果用括号括起来：

```mojo
# The `where` clause constrains the returned function type.
def inner_constraint[n: Int]() -> def() thin -> None where n > 0: ...

# The `where` clause constrains `outer_constraint` itself.
def outer_constraint[n: Int]() -> (def() thin -> None) where n > 0: ...
```

### `abi("C")`

声明函数使用 C 调用约定。因为 C 没有闭包机制，`abi("C")` 通常与 `thin` 一起在函数类型中出现：

```mojo
# `add` is compiled with the C calling convention, so it can be called
# from C or stored in a C-ABI function pointer.
def add(a: Int32, b: Int32) abi("C") -> Int32:
    return a + b

def main():
    var fp: def(Int32, Int32) thin abi("C") -> Int32 = add
    print(fp(1, 2))  # 3
```

:::caution
不要将非 Mojo 的 `abi()` 效果与引发错误的函数组合使用。引发错误的函数以非显而易见的方式改变调用约定。

Mojo 编译器：

- 接受 `def (String) abi("Mojo") raises`
- 拒绝 `def (String) abi("C") raises`

`abi("Mojo")` 已经是默认值。你不需要指定它。

:::

## 返回类型

`->` 引入返回类型。它出现在任何效果之后：

```mojo
def square(x: Int) -> Int:
    return x * x
```

没有 `->`，函数返回 `None`。

## 特殊方法

某些方法名称有强制的签名。编译器检查参数数量、约定和返回类型。

### 初始化器

初始化器必须有 `out self` 结果：

```mojo
struct Point:
    var x: Int
    var y: Int

    def __init__(out self, x: Int, y: Int):
        self.x = x
        self.y = y
```

没有 `out self`，编译器会拒绝该方法：

```mojo
# Error because __init__ method must return Self type
#        with 'out' argument
def __init__(self):
    pass
```

### 复制初始化器

复制初始化器使用一个名为 `copy` 的仅关键字参数：

```mojo
def __init__(out self, *, copy: Self):
    self.x = copy.x
    self.y = copy.y
```

使用 `Type.__init__(copy=value)`、`Type(copy=value)` 或 `value.copy()` 复制值：

- `copy` 参数必须使用可读的不可变引用默认约定。
- 复制初始化器不能引发。
- 平凡类型不能定义复制初始化器。
- 符合 `Copyable` 或 `ImplicitlyCopyable` 时，如果尚未定义复制初始化器，会自动生成一个。
- 如果该类型与复制不兼容，编译器会拒绝此符合。

不要把复制和转换混淆。`Type(value)` 在 Mojo 中是转换。`Type(copy=value)` 和 `value.copy()` 是复制。

在惯用的 Mojo 风格中，优先使用显式的 `.copy()` 调用而不是 `copy` 关键字参数形式。

### 移动初始化器

移动初始化器使用一个名为 `move` 的仅关键字参数：

```mojo
def __init__(out self, *, deinit move: Self):
    self.x = move.x
    self.y = move.y
```

调用 `Type.__init__(move=value)` 或 `Type(move=value)`：

- `move` 参数必须使用 `deinit` 约定。
- 移动初始化器不能引发。
- `RegisterPassable` 类型不能定义移动初始化器。
  它们总是可以通过复制一个寄存器来移动。

### 析构器

析构器接受 `deinit self`：

```mojo
def __deinit__(deinit self):
    _release(self.handle)
```

- 析构器不能引发。
- 平凡类型不能定义析构器。

你可以显式调用 `value.__deinit__()`，但编译器会在该值的最后一次使用时通过 ASAP 销毁自动调用它。对于[显式销毁](/docs/manual/lifecycle/death/#explicitly-destroyed-types)，优先使用自定义析构器。

## 嵌套函数

函数可以在其他函数内部定义。嵌套函数可以捕获外部作用域的值作为*闭包*（closures）：

```mojo
def outer(x: Int) -> Int:
    def inner() {imm} -> Int:  # Read-only references (`imm`) to outer scope
        return x + 1
    return inner()
```

编译器会立即解析嵌套函数主体，以便正确绑定捕获。

## 静态方法

`@staticmethod` 使结构体方法可以在没有实例的情况下调用。静态方法不接受 `self`：

```mojo
struct MathUtils:
    comptime pi: Float64 = 3.141592653589793

    @staticmethod
    def square(x: Int) -> Int:
        return x * x

def main():
    print(MathUtils.square(5))  # 25
    print(MathUtils.pi)         # 3.141592653589793
```

## 函数重载

{/* VERIFIED: OverloadFitness::isBetter in OverloadFitness.cpp,
     filterForBestCandidates in OverloadSet.cpp, ParamInf.cpp.
     "Cannot overload on return type only" diagnostic:
     DeclResolution.cpp around the `redefinition of function` emit.
     Raises-only redefinition behavior: verified by experiment to
     emit `redefinition of function '<name>' with identical
     signature` from the same DeclResolution.cpp path; `raises` is
     not part of the signature for overload-set purposes. */}

*函数重载*（function overload）是共享同一名称但签名不同的两个或多个函数声明之一。编译器在每个调用点选择其中一个。这是*静态分派*（static dispatch）：没有运行时查找。选择在调用被类型检查时固定下来。

*重载集*（overload set）是编译器在调用点考虑的重载集合。它包含同一作用域中共享同一名称的声明。

使用重载可以为一个操作提供多种形态：不同的参数类型、不同的参数数量、不同的关键字名称、不同的 `self` 约定，或不同的编译时形参签名。

```mojo
def add(x: Int, y: Int) -> Int:
    return x + y

def add(x: String, y: String) -> String:
    return x + y

def main():
    print(add(1, 2))           # 3
    print(add("Hi, ", "Mojo")) # Hi, Mojo
```

### 重载集在哪里形成

每个作用域构建自己的重载集：

- *模块作用域*。同一模块中具有相同名称的声明构成一个重载集。
- *结构体作用域*。结构体上的方法（包括 `@staticmethod`）按方法名构成一个重载集。
- *trait 作用域*。trait 上的必需方法和提供的方法按方法名构成一个重载集。

重载集不能跨作用域扩展。import 将名称作为非函数引用引入：你不能从自己的模块向其添加另一个重载，也不能重定义它。与 import 冲突的本地声明会产生错误。

要避免此错误，请使用别名：

```mojo
from some_package import add as imported_add

def add(x: Float64, y: Float64) -> Float64:
    return x + y

# `add` resolves to the local definition.
# `imported_add` resolves to the imported one.
```

### 编译器考虑的因素

重载决议会查看：

- 每个参数的数量、位置和关键字。
- 每个参数和每个编译时形参的类型。
- 每个参数的参数约定。
- 候选是实例方法还是 `@staticmethod`。
- 析构器是否是 `@implicit` 的。

重载决议不会查看返回类型或调用周围的任何其他上下文。

### 决议规则

编译器丢弃所有签名无法被调用满足的候选。然后它对剩余候选进行两两比较。

它按顺序应用以下规则直到有一个胜出。编译器选择该候选。

1. 选择在参数和形参之间使用更少隐式转换的候选。与 `*args` 参数的空匹配算作一次隐式转换，因此精确匹配胜过它。

2. 选择不绑定非空可变参数的候选。没有 `*args` 的签名胜过其 `*args` 参数接收至少一个值的签名。

3. 选择不匹配参数约定更少的候选。

4. 选择形参列表更短的候选。没有编译时形参的函数胜过声明了一个形参的函数。形参列表还会计入从参数类型合成的隐式形参（例如，`SIMD[...]` 参数的未绑定形参会成为该函数的隐式形参）。

在适配度比较之后，编译器应用两个决胜规则：

5. 在同名情况下，选择实例方法候选而不是 `@staticmethod` 候选。

6. 选择非隐式析构器候选而不是隐式析构器候选。

如果两个候选在这些步骤后仍然同样好，则该调用是歧义的。编译器会拒绝它。

:::note
规则 4 意味着具体函数胜过参数化函数。`def foo(a: Int)` 对于一个 `Int` 参数的调用胜过 `def foo[T: AnyType](a: T)`，即使两个签名都匹配。
:::

### 重载形参

函数可以基于编译时形参进行重载，也可以基于参数进行重载：

```mojo
def take_param[a: Int, b: Int]():
    print("take_param[a: Int, b: Int]")

def take_param[a: Int, b: String]():
    print("take_param[a: Int, b: String]")

def main():
    take_param[1, 2]()       # take_param[a: Int, b: Int]
    take_param[1, "hi"]()    # take_param[a: Int, b: String]
```

### 重载 `self` 约定

方法可以按其 `self` 约定进行重载。默认调用点对 `self` 使用不可变引用，因此 `ref self` 胜出。要调用 `var self` 重载，调用者需在调用点使用 `^` 转移：

```mojo
@fieldwise_init
struct Counter(Copyable):
    var n: Int

    def which(ref self) -> Int:
        return 1

    # Constrain `var self` to types where `^` actually transfers.
    # For `TrivialRegisterPassable` types, `^` is a no-op. This
    # overload would otherwise be silently unreachable.
    def which(var self) -> Int where not conforms_to(
        Self, TrivialRegisterPassable
    ):
        return 2

def main():
    var c1 = Counter(0)
    print(c1.which())     # 1: default call uses an immutable self reference
    var c2 = Counter(0)
    print((c2^).which())  # 2: caller transfers self
```

:::caution Sharp edge
对于 `TrivialRegisterPassable` 类型，转移运算符 `^` 是一个 no-op。当使用平凡寄存器类型如 `Int`、`Float64` 或类似类型时，`(c^).which()` 变成 `c.which()`。编译器会警告你，但不会拒绝你的代码。

上面 `where` 子句中的编译时符合检查使一个非平凡约束变得显式。它为平凡寄存器类型过滤掉 `var self` 重载，而不是让它静默地不可达。
:::

### 实例方法胜过静态方法

当实例方法和 `@staticmethod` 同名时，方法调用表达式会选择实例方法（规则 5）：

```mojo
struct StaticOverload:
    def __init__(out self):
        pass

    def foo(mut self):
        print("instance method")

    @staticmethod
    def foo():
        print("static method")

def main():
    var a = StaticOverload()
    a.foo()  # instance method
```

要显式调用静态方法，请使用类型名：

```mojo
StaticOverload.foo()  # static method
```

### 可变参数候选在平局中失败

当没有 `*args` 的签名和可变参数签名都匹配调用时，没有 `*args` 的签名胜出，因为可变参数版本为空包付出一次隐式转换（规则 1），或者当有值提供时在规则 2 上失败：

```mojo
def take(x: Int):
    print("take(x: Int)")

def take(*xs: Int):
    print("take(*xs: Int)")

def main():
    take(1)        # take(x: Int)
    take(1, 2, 3)  # take(*xs: Int): the only match.
```

### 歧义调用

当两个候选同样好时，调用失败：

```mojo
struct MyString:
    @implicit
    def __init__(out self, s: String):
        pass

struct YourString:
    @implicit
    def __init__(out self, s: String):
        pass

def foo(name: MyString):
    print("MyString")

def foo(name: YourString):
    print("YourString")

def main():
    # Error because the call is ambiguous: both overloads need exactly
    # one implicit conversion from `String`
    foo("Hello")
```

通过在调用点进行转换来解决歧义：

```mojo
def main():
    foo(MyString("Hello"))   # MyString
    foo(YourString("Hello")) # YourString
```

字面量可能触发同种歧义。一个 `IntLiteral` 以相同代价转换为 `Int` 和 `Float64`，因此对下面两个重载的 `take_param[1, 2]()` 调用是歧义的：

```mojo
def take_param[a: Int, b: Int]():
    pass

def take_param[a: Int, b: Float64]():
    pass

def main():
    # Error because `IntLiteral` converts to both `Int` and `Float64`
    # at equal cost; the compiler can't pick a winner
    take_param[1, 2]()
```

要解决此问题，请移除歧义，或通过重命名一个版本来移除该重载。

### 返回类型不能消歧

仅在返回类型上不同的两个重载对重载决议来说是无法区分的：

```mojo
def parse(s: String) -> Int:
    return 0

# Error because `parse` cannot overload on return type only;
# the differing return type doesn't form a new overload
def parse(s: String) -> Float64:
    return 0.0
```

请使用不同的参数类型、额外的形参，或不同的函数名代替。

### `raises` 不能消歧

仅在是否 `raises` 上不同的两个函数对于重载集目的来说具有相同的签名。编译器会拒绝第二个声明：

```mojo
def maybe_raise(x: Int) -> Int:
    return x

# Error because `maybe_raise` already has this signature;
# `raises` isn't part of the signature for overload purposes
def maybe_raise(x: Int) raises -> Int:
    raise Error("nope")
```

如果两种行为都需要，给它们不同的名称，或让引发版本接受不同的参数形态。

### 最佳实践

- 当每个版本对不同的输入形态实现相同的操作时使用重载。不要用重载让同一名称表示不同含义。
- 不要依赖两个隐式初始化器都能从同一源类型到达。在调用点进行转换，或将一个初始化器设为非隐式。
- 优先基于参数*类型*进行重载，而不是基于约定。基于约定的重载可行，但容易被误读。
- 当一个重载集应该接受多种类型时，编写一个用 `where` 约束的参数化函数，而不是许多近似的副本。当两者同时存在时，编译器会选择具体签名（规则 4）。
- 不要定义与已 import 的函数同名的函数。编译器会拒绝它。当你需要两个名称时，请在别名下 import。
