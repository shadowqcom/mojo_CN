*字面量*是直接在源代码中写入的值：`42`、`"hello"`、`True`。字面量产生值而无需读取变量或调用函数。以下各节涵盖每种字面量类型、其语法和词法分析器强制执行的任何规则。

## 整数字面量

*整数字面量*以四种进制表示整数：

```mojo
42        # 十进制
0xFF      # 十六进制（0x 或 0X 前缀）
0o52      # 八进制（0o 或 0O 前缀）
0b101010  # 二进制（0b 或 0B 前缀）
```

整数字面量遵循以下词法规则：

```text
integer     → decinteger | bininteger | octinteger | hexinteger
decinteger  → nonzerodigit ("_" | digit)* | "0"+ ("_" | "0")*
bininteger  → "0" ("b" | "B") ("_" | bindigit)+
octinteger  → "0" ("o" | "O") ("_" | octdigit)+
hexinteger  → "0" ("x" | "X") ("_" | hexdigit)+
```

整数字面量总是非负的。`-1024` 是一元取负运算符 `-` 应用于字面量 `1024`。

下划线可以出现在数字之间以提高可读性。Mojo 在这方面比 Python 更宽松。允许连续和尾随下划线：

```mojo
1_000_000  # 可读的分组
1__000_    # 也有效（连续和尾随下划线都可以）
```

十进制字面量中不允许前导零。八进制请使用 `0o` 前缀：

```mojo
0123   # 错误：十进制整数字面量中不允许前导零
0o123  # OK：八进制
```

进制前缀后必须至少跟一个数字：

```mojo
0x  # 错误：十六进制字面量未指定数字
0b  # 错误：二进制字面量未指定数字
0o  # 错误：八进制字面量未指定数字
```

## 浮点字面量

*浮点字面量*表示带有小数或指数部分的数字：

```mojo
1.0
3.14159
.5       # 只有小数部分（无整数部分）
2.       # 带小数点的整数部分
2.5e-3   # 带指数
1E10     # 大写 E 也可以
```

浮点字面量遵循以下词法规则：

```text
floatnumber   → pointfloat | exponentfloat
pointfloat    → digitpart? fraction | digitpart "."
exponentfloat → (digitpart | pointfloat) exponent
fraction      → "." digitpart
exponent      → ("e" | "E") ("+" | "-")? digitpart
digitpart     → digit ("_" | digit)*
```

浮点字面量总是非负的。`-3.14` 是一元取负运算符 `-` 应用于字面量 `3.14`。

包含时，指数标记（`e` 或 `E`）后必须至少跟一个数字：

```mojo
2.5e    # 错误：指数后需要数字
2.5e-   # 错误：指数后需要数字
2.5e-3  # OK
```

浮点字面量中的下划线与整数中的工作方式相同。将它们放在任何提高可读性的地方：

```mojo
1_000.000_5
```

## 字符串字面量

*字符串字面量*表示文本值。Mojo 支持单引号和双引号，以及用于多行字符串的三引号形式：

```mojo
"Hello"
'world'
"""Multi-line
string"""
'''Also
multi-line'''
```

相邻行的字符串字面量连接成单个字符串。这在同一行或跨行（当续行缩进时）都有效：

```mojo
"Hello, " "World"        # "Hello, World"

x = "line one "
    "line two"           # "line one line two"（缩进续行）
```

使用 `r` 或 `R` 前缀创建*原始字符串*，禁用转义处理：

```mojo
r"C:\path\to\file"  # 反斜杠按字面处理
```

### 转义序列

Mojo 在非原始字符串字面量中识别这些转义序列：

| 序列  | 含义           | 序列     | 含义                     |
|-------|----------------|----------|--------------------------|
| `\\`  | 反斜杠         | `\a`     | 响铃                     |
| `\"`  | 双引号         | `\b`     | 退格                     |
| `\'`  | 单引号         | `\f`     | 换页                     |
| `\n`  | 换行           | `\v`     | 垂直制表符               |
| `\r`  | 回车           | `\xHH`   | 十六进制值（恰好 2 位）   |
| `\t`  | 制表符         | `\0`–`\377` | 八进制值（1-3 位）     |

三引号字符串内行尾的反斜杠抑制换行，直接连接下一行：

```mojo
x = """\
    This string has no leading newline.\
    """
```

## T-string 字面量

*T-string 字面量*支持使用 `{}` 进行表达式插值：

```mojo
name = "World"
t"Hello, {name}!"   # "Hello, World!"
t"1 + 1 = {1 + 1}"  # "1 + 1 = 2"
```

`{}` 内的表达式在运行时求值。相邻的 t-string 字面量会连接，就像常规字符串字面量一样。

T-string 可以三引号化并与原始前缀组合（`rt`、`tr`、`rT`、`tR`）：

```mojo
t"""
Hello, {name}!
"""

rt"Path: {base}\subdir"  # 原始 t-string：反斜杠是字面量
```

使用 `{{` 和 `}}` 在 t-string 中包含字面大括号：

```mojo
t"Use {{braces}} in t-strings"  # "Use {braces} in t-strings"
```

T-string 可以嵌套。插值表达式本身可以包含 t-string，最多 20 层深度。

```mojo
var name = "world"
var greeting = t"Hello, {t"dear {name}"}!"
print(greeting) # "Hello, dear world!"
```

## 布尔字面量

`True` 和 `False` 表示布尔真值。

```mojo
x = True
y = False
```

## None 字面量

`None` 表示值的缺失。它是 `NoneType` 类型的唯一值。

```mojo
x: NoneType = None
```

没有显式返回类型的函数返回 `None`。这两个声明是等价的：

```mojo
def greet():
    print("hello")

def greet() -> None:
    print("hello")
```

## Self 字面量

`Self` 在结构体或 trait 定义内引用封闭类型：

```mojo
struct Point:
    var x: Float64
    var y: Float64

    def create() -> Self:          # Self 引用 Point
        return Self(0.0, 0.0)

    def distance(self) -> Float64: # self 是参数名，不是 Self
        return (self.x ** 2 + self.y ** 2).sqrt()
```

`Self`（大写 S）是引用类型的关键字。`self`（小写）是实例的常规参数名。

## 丢弃模式

下划线 `_` 在赋值中丢弃值：

```mojo
_, y = get_pair()  # 忽略第一个元素
```

## 省略号字面量

`...` 将 trait 方法标记为必需。一致类型必须提供自己的实现。它只在 trait 定义内有效：

```mojo
trait Drawable:
    def draw(self) -> None: ...   # 必需：一致类型必须实现
```

`...` 和 `pass` 不可互换。`pass` 是提供空主体的空操作语句。`...` 是表示"你必须实现这个"的要求标记。
