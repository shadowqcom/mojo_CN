*简单语句*在单个逻辑行上执行单个操作。多个简单语句可以用分号分隔在同一行上。

## 导入语句

*导入语句*将模块及其成员暴露给当前作用域。导入可以出现在模块级别、函数内部或其他作用域内。它们不需要出现在文件顶部。

```mojo
import math
from collections import Dict, Set
```

### 模块导入

```mojo
import math
import numpy as np            # 别名模块名以避免冲突
```

### 选择性导入

```mojo
from math import sqrt, pi
from collections import Dict as Dictionary   # 别名导入的名称
```

### 通配符导入

```mojo
from math import *  # 导入 math 模块的所有公共名称
```

## 表达式语句

*表达式语句*为副作用求值表达式。当结果未使用（除 `None` 外）时，编译器会警告：

```mojo
x + y              # 警告：结果未使用
```

当结果为 `None` 时，编译器不会警告，这对于为副作用调用的函数很常见：

```mojo
print("hello")     # 副作用：打印
trigger()          # 副作用：为行为调用
```

将结果赋值给 `_` 以显式丢弃并消除警告：

```mojo
_ = update()       # 显式丢弃结果
```

表达式在模块作用域或结构体主体内的方法外部无效。

## 赋值语句

*赋值语句*使用 `=` 将值绑定到名称：

```mojo
var x = 42
var name = "Alice"
var result = compute()
```

当类型可以从初始化器推断时，使用 `var` 是可选的，就像在 Python 中一样，但不推荐。显式的 `var`（和 `ref`）声明表明你打算声明新变量，并且易于扫描。

```mojo
x = 42          # 类型推断为 Int
name = "Alice"  # 类型推断为 String
```

### 带注解的赋值

带注解的赋值将类型绑定到名称，带有可选的初始化器：

```mojo
x: Int = 42
name: String = "Alice"
values: List[Float64] = []
```

没有类型和初始化器的 `var` 是错误的：

```mojo
var x        # 错误：声明必须有类型或初始化器
var x: Int   # OK：提供了类型，值未初始化
var x = 42   # OK：类型从初始化器推断
```

你不需要为变量添加类型，但添加类型注解是一个好习惯，可以提高可读性、表明意图并捕获错误：

```mojo
var x: Int16 = 42
var name: String = "Alice"
```

当类型复杂且冗长时，可以使用 comptime 别名保持代码简洁：

```mojo
comptime Vec3 = List[Float64]
var position: Vec3 = [0.0, 0.0, 0.0]
```

### 多重赋值

```mojo
x = y = z = 0        # 将相同的值赋给多个名称
a, b = 1, 2          # 解构赋值
(a, b) = (1, 2)      # 等价的解构，不是"将元组赋给元组"
```

### 增强赋值

增强赋值是将操作与赋值组合的语法糖。左边只求值一次：

```mojo
x += 5       # x = x + 5
x -= 2       # x = x - 2
x *= 3       # x = x * 3
x /= 4       # x = x / 4
x //= 2      # x = x // 2
x %= 7       # x = x % 7
x **= 2      # x = x ** 2
x @= m       # x = x @ m（矩阵乘法）
x &= mask    # x = x & mask
x |= flags   # x = x | flags
x ^= bits    # x = x ^ bits
x <<= 1      # x = x << 1
x >>= 1      # x = x >> 1
```

## pass 语句

`pass` 是空操作。在需要语句但不需要操作的地方使用它作为占位符：

```mojo
def not_ready():
    pass

struct Empty:
    pass
```

在空函数和结构体主体中需要 `pass` 以避免语法错误。

:::note[省略号语句]
`...` 在大多数代码中作为语句功能上等同于 `pass`。为了可读性，优先使用 `pass` 而不是 `...`。

在 trait 定义中，`...` 将方法标记为必需。将 `...` 的使用限制在 trait 中，可以在阅读使用它的代码时更容易确定其角色。
:::

## return 语句

`return` 退出函数并可选地返回值：

```mojo
def greet(name: String):
    if not name:  # String 为空时为假
        return
    print(t"Hello, {name}!")

def get_value() -> Int:
    return 42

def early_exit(items: List[Int], target: Int) -> Bool:
    for item in items:
        if item == target:
            return True
    return False
```

没有显式 `return` 的函数隐式返回 `None`。`return` 只在函数内部有效：

```mojo
return 42    # 错误：不能从此上下文返回
```

## raise 语句

`raise` 引发错误。函数必须声明为 `raises` 或包含在 `try` 块中：

```mojo
def validate(value: Int) raises -> Bool:
    if value < 0:
        raise Error("value must be non-negative")
    return True

def mitigate_risk():
    try:
        if not perform_some_test():
            raise Error("test failed")
        # 执行有风险的工作，知道测试通过了
    except e:
        log(e)
```

要从 `try` 块传播错误，使用裸 `raise` 重新引发当前错误：

```mojo
try:
    validate(value)
    # 执行工作，知道 value 有效
except e:
    raise  # 重新引发当前错误给下一个处理程序
```

在无效上下文外引发是错误的：

```mojo
raise Error("oops")   # 错误：不能在此上下文中引发错误
                      # （用 try 包围，或将函数标记为 raises）

raise                 # 错误：没有上下文错误可重新引发
                      # （裸 raise 需要活动的 except 块）
```

## 使用 break 和 continue 语句控制流

`break` 立即退出最内层循环。`continue` 跳到下一次迭代：

```mojo
for x in range(10):
    if x == 5:
        break        # 在 5 处停止
    if x % 2 == 0:
        continue     # 跳过偶数
    print(x)         # 打印 1, 3
```

## 编译时声明

`comptime` 声明编译时常量。值必须在编译时可计算：

```mojo
comptime SIZE = 256
comptime MAX = SIZE * 2
```

`comptime` 赋值也用于在 trait 中声明关联类型，并可用于创建类型别名和 trait 组合别名：

```mojo
comptime Permissive = ImplicitlyCopyable & ImplicitlyDestructible

trait SimpleTrait (Writable):  # `SimpleTrait` 细化 `Writable`
    comptime Element = Permissive  # 使用 comptime 别名的关联类型
```
