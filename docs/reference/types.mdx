Mojo 是静态类型语言。每个值都有在编译时已知的类型。本页涵盖 Mojo 的类型系统，包括基本类型、复合类型和类型注解。

## 基本类型

### 数值类型

Mojo 提供标准数值类型：

| 类型      | 描述                       | 大小     |
|-----------|----------------------------|----------|
| `Int`     | 机器宽度有符号整数         | 64 位    |
| `Int8`    | 8 位有符号整数             | 8 位     |
| `Int16`   | 16 位有符号整数            | 16 位    |
| `Int32`   | 32 位有符号整数            | 32 位    |
| `Int64`   | 64 位有符号整数            | 64 位    |
| `UInt8`   | 8 位无符号整数             | 8 位     |
| `UInt16`  | 16 位无符号整数            | 16 位    |
| `UInt32`  | 32 位无符号整数            | 32 位    |
| `UInt64`  | 64 位无符号整数            | 64 位    |
| `Float16` | 半精度浮点数               | 16 位    |
| `Float32` | 单精度浮点数               | 32 位    |
| `Float64` | 双精度浮点数               | 64 位    |

### 布尔类型

```mojo
var flag: Bool = True
```

### 字符串类型

```mojo
var name: String = "Alice"
var literal: StringLiteral = "hello"  # 编译时字符串
```

### 无类型

`NoneType` 表示值的缺失：

```mojo
var nothing: NoneType = None
```

## 复合类型

### 元组

元组是固定大小的异质集合：

```mojo
var pair: Tuple[Int, String] = (42, "hello")
var triple: (Int, Float64, Bool) = (1, 2.0, True)
```

### 列表

列表是动态大小的同质集合：

```mojo
var numbers: List[Int] = [1, 2, 3]
var names: List[String] = ["Alice", "Bob"]
```

### 字典

字典存储键值对：

```mojo
var ages: Dict[String, Int] = {"Alice": 30, "Bob": 25}
```

### 集合

集合存储唯一值：

```mojo
var primes: Set[Int] = {2, 3, 5, 7}
```

### 可选类型

`Optional` 表示可能存在或不存在的值：

```mojo
var maybe: Optional[Int] = Some(42)
var none: Optional[Int] = None
```

### 变体类型

`Variant` 表示多种可能类型之一：

```mojo
var value: Variant[Int, String] = 42
value = "hello"  # 可以改变类型
```

## 类型注解

类型注解指定变量、参数和返回值的类型：

```mojo
var x: Int = 42

def greet(name: String) -> String:
    return "Hello, " + name
```

### 类型推断

当类型可以从上下文推断时，类型注解是可选的：

```mojo
var x = 42           # 推断为 Int
var name = "Alice"   # 推断为 String
var items = [1, 2, 3]  # 推断为 List[Int]
```

## 泛型

泛型允许编写适用于多种类型的代码：

```mojo
struct Box[T: AnyType]:
    var value: T

    def __init__(out self, value: T):
        self.value = value

def main():
    var int_box = Box(42)
    var str_box = Box("hello")
```

### 泛型约束

使用 trait 约束泛型参数：

```mojo
def max[T: Comparable](a: T, b: T) -> T:
    if a > b:
        return a
    return b
```

### 多个泛型参数

```mojo
struct Pair[K: AnyType, V: AnyType]:
    var key: K
    var value: V
```

## 类型别名

使用 `comptime` 创建类型别名：

```mojo
comptime Vec3 = List[Float64]
var position: Vec3 = [0.0, 0.0, 0.0]
```

## 函数类型

函数类型描述函数签名：

```mojo
var callback: def(Int) -> String
```

### 带约束的函数类型

```mojo
var processor: def(Int) raises -> String
```

## SIMD 类型

SIMD 类型表示向量操作：

```mojo
var vec: SIMD[DType.float32, 4] = [1.0, 2.0, 3.0, 4.0]
```

### DType 枚举

`DType` 枚举指定数据类型：

```mojo
alias float32 = DType.float32
alias int32 = DType.int32
```

## 指针类型

指针类型表示内存地址：

```mojo
var ptr: Pointer[Int]
var unsafe_ptr: UnsafePointer[Int]
```

## 引用类型

引用类型表示对值的引用：

```mojo
def get_first[T: Copyable](ref data: List[T]) -> ref T:
    return data[0]
```

## 类型检查

### `type_of`

`type_of` 返回表达式的类型：

```mojo
var x = 42
comptime T = type_of(x)  # Int
```

### `conforms_to`

`conforms_to` 检查类型是否符合 trait：

```mojo
comptime is_copyable = conforms_to(Int, Copyable)  # True
```

## 类型转换

使用构造函数进行类型转换：

```mojo
var x: Float64 = Float64(42)  # Int 到 Float64
var s: String = String(42)    # Int 到 String
var n: Int = Int("42")        # String 到 Int
```

### 显式转换

某些类型需要显式转换：

```mojo
var ptr = Pointer[Int].alloc(10)
var unsafe_ptr = UnsafePointer[Int](ptr)
```
