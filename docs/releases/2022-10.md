title: Mojo 2022 年 10 月
date: 2022-10-31

## 2022-10-31 那一周

- 修改了 `return` 的处理方式，使不带表达式的 return 语句成为
  `return None` 的语法糖。这让隐式返回 `None` 的函数中的提前返回更简洁：

  ```mojo
  def just_return():
      return
  ```

- 增加了对更多表达式的解析支持：if-else、位运算符、
  移位运算符、比较运算符、向下取整除法、余数和矩阵乘法。

- 📢 成员方法现在可以省略 `self` 参数的类型。

## 2022-10-24 那一周

- 添加了解析器对右结合性和一元运算的支持，例如幂运算符
  `a ** b ** c` 和取负运算符 `-a`。

- 在 Mojo 中增加了对 `&expr` 的支持，允许在函数中标注按引用传递的参数。
  这是必需的，因为结构体方法的 `self` 类型隐式为指针。

- 实现了对参数化函数声明的支持，例如：

  ```mojo
  struct SIMD[dt: DType, width: index]:
      fn struct_method(self: &SIMD[dt, width]):
          pass

  def fancy_add[dt: DType, width: index](
      lhs: SIMD[dt, width], rhs: SIMD[dt, width]) -> index:
    return width
  ```

## 2022-10-17 那一周

- 添加了使用 `var` 的显式变量声明，用于在函数和结构体内部声明变量，
  并支持类型引用。添加了 `index` 作为临时内建类型。

  ```mojo
  def foo(lhs: index, rhs: index) -> index:
      var result: index = lhs + rhs
      return result
  ```

- 实现了解析结构体声明以及函数中类型声明引用的支持！在 `def` 中，
  可以省略类型以表示对象类型。

  ```mojo
  struct Foo:
      var member: index

  def bar(x: Foo, obj) -> index:
      return x.member
  ```

- 实现了解析器对 `if` 语句和 `while` 循环的支持！

  ```mojo
  def if_stmt(c: index, a: index, b: index) -> index:
      var result: index = 0
      if c:
          result = a
      else:
          result = b
      return result

  def while_stmt(init: index):
      while init > 1:
          init = init - 1
  ```

- 显著改善了错误输出与处理，使解析器能够在解析文件时输出多个错误。

## 2022-10-10 那一周

- 增加了对整数、浮点数和字符串字面量的解析支持。

- 实现了解析器对函数输入参数和结果的支持。现在
  可以编写参数化函数，例如：

  ```mojo
  def foo[param: Int](arg: Int) -> Int:
      result = param + arg
      return result
  ```

## 2022-10-03 那一周

- 添加了一些基础解析器脚手架和初始解析器产生式，包括
  简单表达式和赋值解析产生式。
- 实现了基础作用域处理和函数 IR 生成，并支持
  前向声明。简单函数如

  ```mojo
  def foo(x: Int):
  ```

  现在可以解析了！但所有参数类型都被硬编码为 MLIR 的 `index` 类型。

- 添加了对内建类型上简单算术表达式的 IR 生成，例如
  `x + y`。
