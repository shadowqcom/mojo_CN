## 2023-02-27 那一周

- 📢 `@interface`、`@implements` 和 `@evaluator` 三个装饰器已
  被移除，由 `@parameter if` 和 `@adaptive` 特性取代。

- 📢 参数推断现在可以推断可变列表的类型。

- 📢 函数结果中现已支持内存主类型。在调用方分配结果槽，
  被调用方将函数结果写入该槽。这对
  不能整齐放入寄存器的大型类型更高效！并且内存主类型的初始化器
  现在就地初始化值，而不是发出拷贝！

- 已实现对内存主类型 `let` 声明的支持。它们
  是内存主类型的常量、只读值，但
  分配在函数栈上。

- 重载转换解析与参数推断已改进：

  1. 推断现在在先前无法工作的某些场景中可与 `let` 声明一起
     工作。
  2. 参数绑定现在可以将类型推断进参数表达式。这
     有助于解析参数表达式中的高阶函数。

- 📚 在 X86 硬件上优化 floor、ceil 和 ldexp。

- 📚 实现 log 数学函数。

## 2023-02-20 那一周

- 📢 引入了新的 `@__memory_primary` 结构体装饰器。内存
  主类型必须始终具有地址。例如，在函数中声明时它们始终
  被栈分配，其值通过地址而非拷贝传入
  函数调用。这与寄存器主类型形成对比，后者可能
  没有地址，且在函数调用中按值传递。寄存器主
  结构体内不允许存在内存主字段，因为结构体元素是
  在线存储的。

- 📢 新增 `_CompilerBuiltin` 模块。该模块定义
  被解析器引用的语言核心类型与函数，因此会被
  所有其他模块自动导入。例如，诸如布尔
  True/False 等字面值的新类型将包含在 `_CompilerBuiltin` 中。

- 📢 可以在被标记为 `@adaptive` 的函数引用上访问特殊
  的 `__adaptive_set` 属性。该属性返回该函数的自适应重载集。
  返回类型为 `!kgen.param_list`。此特性
  有助于在标准库中实现通用的 `evaluate` 函数。

- 📢 在 `_CompilerBuiltin` 中新增内建字面量类型 `BoolLiteral`。
  它表示字面布尔值 `True` 和 `False`。这是第一个
  作为标准库类型发出的 Mojo 字面量！

- 📚 添加 prefetch 内联函数以启用硬件预取缓存行。

- 📚 添加 `InlinedFixedVector`，针对小向量优化，
  并在栈和堆上存储值。

## 2023-02-13 那一周

- 对结构体成员的非限定查找会应用上下文参数。这意味着
  例如你可以引用静态方法而无需绑定
  结构体参数。

  ```mojo
  struct Foo[x: Int]:
      @staticmethod
      bar(): pass

      foo(self):
          bar()         # implicitly binds to Foo[x].bar()
          Foo[2].bar()  # explicitly bind to another parameter
  ```

- 📢 新的 `Self` 类型指代包含所有参数绑定到
  其当前值的封闭类型。这在处理复杂参数化
  类型时很有用，例如：

  ```mojo
  struct MyArray[size: Int, element_type: type]:
     fn __new__() -> Self:
         return Self {...}
  ```

  这比反复写 `MyArray[size, element_type]`
  要好得多。

- 📢 Mojo 现在支持 `@adaptive` 装饰器。该装饰器将取代
  接口，表示一个允许解析到多个有效候选的
  重载函数。此时，调用会被发出为 fork，
  导致多个函数候选可供搜索。

  ```mojo
  @adaptive
  fn sort(arr: ArraySlice[Int]):
      bubble_sort(arr)

  @adaptive
  fn sort(arr: ArraySlice[Int]):
      merge_sort(arr)

  fn concat_and_sort(lhs: ArraySlice[Int], rhs: ArraySlice[Int]):
      let arr = lhs + rhs
      sort(arr) # this forks compilation, creating two instances
                # of the surrounding function
  ```

- 📢 Mojo 现在要求类型实现 `__clone__` 特殊成员以
  拷贝它们。这允许安全地定义像 Atomic 这样的不可拷贝类型。
  注意，Mojo 尚未实现析构函数，并且（由于
  不存在不可变引用）它在拷贝 let 值时实际上并不调用
  `__clone__` 成员。因此，这迫使你作为 Mojo
  用户编写大量样板代码却得不到多少价值。

  未来，我们将通过装饰器减少样板代码，并
  实际开始使用它。但构建完成尚需时日。

- 📢 添加了特殊的 `__mlir_region` 语句，为在 Mojo 中
  定义 MLIR 操作 region 提供更强
  的不变量。其语法类似于函数声明，只是
  没有结果也没有输入约定。

- 📚 实现 log 数学函数。

- 📚 改进 DType 结构体以启用编译期相等检查。

- 📚 添加 Complex 结构体类。

## 2023-02-06 那一周

- 📢 `if` 语句现在支持 `@parameter` 装饰器，这要求
  其条件为参数表达式，但只将条件的 'True'
  分支输出到二进制中，提供 "static if" 功能。
  这应能消除许多仅用于提供不同实现约束的
  `@interface` 用法。

- 📢 `fn main():` 现在会自动导出，并可直接由
  命令行 `mojo` 工具运行。这是临时方案，以启用脚本式
  用例，直至我们构建出更多语言特性。

- 🪦 `@nodebug_inline` 特性已被移除，请改用
  `@alwaysinline("nodebug")`，用于必须内联且我们不希望
  步入的方法。

- 📢 Python 链式比较，例如 `a < b < c`，现已在 Mojo 中支持。

- 📢 函数现在可以用默认参数值定义，例如
  `def f(x: Int, y: Int = 5):`。当调用者
  未提供该参数值时使用默认参数值：例如 `f(3)` 使用
  默认参数值 `y = 5`。

- 未使用的协程结果现在会被清晰地诊断为"missing await"警告。

- 📚 为 SIMD 类型引入向量化归约运算。
