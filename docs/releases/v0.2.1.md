Mojo 的首个带版本号的发布版本！🔥

所有更早的发布版本都被视为 0.1 版本。

## 🔥 传奇

- Mojo SDK 的首个发布版本！

  你现在可以在本地使用 Mojo 进行开发了。Mojo SDK 目前支持
  Ubuntu Linux 系统，对 Windows 和 macOS 的支持即将推出。
  你仍然可以在 Windows 或 Mac 计算机上通过容器或
  远程 Linux 系统进行开发。

  Mojo SDK 包含 Mojo 标准库和 [Mojo 命令行
  接口](/docs/cli/)（CLI），它允许你运行、编译和打包
  Mojo 代码。它还提供了一个 REPL 编程环境。

  [获取 Mojo SDK！](https://developer.modular.com/download)

- [VS Code 的 Mojo 扩展](https://marketplace.visualstudio.com/items?itemName=modular-mojotools.vscode-mojo)的
  首个发布版本。

  它在 Visual Studio Code 中提供了 Mojo 语言的核心功能，例如
  代码补全、代码快速修复、文档工具提示等。即使在
  远程系统上开发，使用 VS Code 配合此扩展也能提供
  接近原生的 IDE 体验。

## ⭐️ 新增

- [`benchmark`](/docs/std/benchmark/benchmark/) 模块中新增了一个
  `clobber_memory` 函数。
  该 clobber memory 函数告诉系统在指定程序点刷新所有内存操作。
  这使你能够在编译器不重排内存操作的情况下进行基准测试。

- [`benchmark`](/docs/std/benchmark/benchmark/) 模块中新增了一个
  `keep` 函数。`keep`
  函数试图告诉编译器在变量未被使用时不要将其优化掉。
  这使你能够避免编译器的死代码消除机制，且仅产生很小的副作用。

- [`simd`](/docs/std/builtin/simd/) 模块中新增了 `shift_right` 和 `shift_left`
  函数。它们分别将
  SIMD 向量中的元素右移/左移，并在需要时用零填充元素。

- [`reduction`](/docs/std/algorithm/reduction/) 模块中新增了一个
  `cumsum` 函数，用于计算
  输入元素的累加和（也称为扫描）。

- Mojo Jupyter 内核现在支持代码补全。

## 🦋 变更

- 扩展了 `rotate_bits_left`、`rotate_left`、`rotate_bits_right` 和
  `rotate_right`，使其可在 Int 值上操作。参数顺序也已
  调整以支持类型推断。现在可以编写
  `rotate_right[shift_val](simd_val)` 并从实参中推断 `dtype` 和 `simd_width`。
  此修复对应
  [Issue #528](https://github.com/modular/modular/issues/528)。

## 🛠️ 修复

- 修复了当 `with` 语句未带冒号时导致解析器崩溃的 bug。
  此修复对应 [Issue #529](https://github.com/modular/modular/issues/529)。

- 当模块顶层存在其他错误时，错误的导入不再导致崩溃。此修复对应 [Issue
  #531](https://github.com/modular/modular/issues/531)。
