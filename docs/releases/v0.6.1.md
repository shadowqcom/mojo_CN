## ⭐️ 新增

- Mojo REPL 现在对 `%cd` 魔术命令提供有限支持。

  此命令会自动维护一个你在 REPL 会话期间访问的目录栈。用法：

  - `%cd 'dir'`：切换到目录 `dir`，并将其压入目录栈。
  - `%cd -`：弹出目录栈并切换到上次访问的目录。

- 用 `@value` 装饰的 struct 现在会自动遵循
  [`Movable`](/docs/std/builtin/value/Movable/)
  和 [`Copyable`](/docs/std/builtin/value/Copyable/) 内建 trait。

- [`String`](/docs/std/collections/string/string/String/) 现在新增了
  [`toupper()`](/docs/std/collections/string/string/String/#upper) 和
  [`tolower()`](/docs/std/collections/string/string/String/#lower) 方法，
  分别类似于 Python 的 `str.toupper()` 和 `str.tolower()`。

- 添加了 [`hash()`](/docs/std/hashlib/hash/hash/) 内建函数和
  [`Hashable`](/docs/std/hashlib/hash/Hashable/) trait，用于实现了
  `__hash__()` 方法的类型。未来的版本将为标准库类型添加
  `Hashable` 支持。在此期间，`hash` 模块包含一个适用于任意字节串的
  `hash()` 函数版本。要为 [`SIMD`](/docs/std/builtin/simd/SIMD/) 类型生成哈希，
  你需使用内部的 `_hash_simd()` 函数：

  ```mojo
  from builtin.hash import _hash_simd

  fn gen_simd_hash():
      let vector = SIMD[DType.int64, 4](1, 2, 3, 4)
      let hash = _hash_simd(vector)
  ```

- 若干标准库类型现在遵循
  [`CollectionElement`](/docs/std/builtin/value/CollectionElement/) trait。这些
  类型包括 [`Bool`](/docs/std/builtin/bool/Bool/)、
  [`StringLiteral`](/docs/std/builtin/string_literal/StringLiteral/)、
  [`DynamicVector`](/docs/std/collections/list/List/)、`Tensor`、`TensorShape`
  和 `TensorSpec`。

## 🦋 变更

- `utils.vector` 已移至新的 `collections` 包，以便为新集合腾出
  空间。这意味着如果你之前的代码执行了
  `from utils.vector import DynamicVector`，由于此次迁移，
  现在需要改为 `from collections.vector import DynamicVector`。

- 特殊析构方法 `__del__()` 已更改，强制其不能抛出错误。目前
  尚未正确支持抛出异常的析构函数。

## 🛠️ 修复

- [#1421](https://github.com/modular/modular/issues/1421) - 修复了在
  REPL 中使用 Tuple 时的崩溃。

- [#222](https://github.com/modular/modular/issues/222) - 为明显的
  自递归函数生成错误。

- [#1408](https://github.com/modular/modular/issues/1408) - 修复了当候选
  可以返回泛型类型时的重载解析。

- [#1413](https://github.com/modular/modular/issues/1413) 和
  [#1395](https://github.com/modular/modular/issues/1395) - 重新声明内建声明时
  不再崩溃。

- [#1307](https://github.com/modular/modular/issues/1307) - 修复了仅
  默认参数值不同的函数签名的兼容性。

- [#1380](https://github.com/modular/modular/issues/1380) - 修复了空
  `String` 的打印。
