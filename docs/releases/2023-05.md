## 2023-05-31

### ⭐️ 新增

- Mojo Playground 现包含以下 Python 包（响应
  [popular demand](https://github.com/modular/modular/discussions/173)）：
  `torch`、`tensorflow`、`polars`、`opencv-python`、`keras`、`Pillow`、`plotly`、
  `seaborn`、`sympy`、`transformers`。

- 已对未使用转移（`^`）运算符而作为
  owned 值传递的非平凡可拷贝值应用新优化。考虑如下
  代码：

  ```mojo
  var someValue: T = ...
  ...
  takeValueAsOwned(someValue)
  ...
  ```

  当 `takeValueAsOwned()` 以
  [`owned`](/docs/manual/values/ownership/#transfer-arguments-var-and-)
  值接受其参数（这在初始化器中很常见，例如）时，它被允许对该值做任何想做的事，并在使用完后销毁它。为支持此行为，
  Mojo 编译器被迫制作 `someValue` 值的临时拷贝，并
  传递该值而非 `someValue`，因为调用
  之后可能还有对 `someValue` 的其他使用。

  Mojo 编译器现在已足够聪明，能检测
  后续没有对 `someValue` 的使用，并像你手动指定转移运算符
  `takeValueAsOwned(someValue^)` 那样消除拷贝。这
  为非平凡类型提供了"开箱即用"的体验，而无需
  手动管理转移。

  如果你想完全控制并为你的类型暴露完整所有权，
  只需让它不可拷贝。仅移动类型需要显式转移
  运算符，这样你可以在代码中看到所有权转移发生的所有位置。

- 类似地，当源值的最后一次使用沿控制流路径时，Mojo 编译器
  现在会将 `__copyinit__` 方法的调用转换为对
  `__moveinit__` 的调用。这允许既可拷贝又可移动的类型获得
  透明的移动优化。例如，以下代码
  即使不使用转移运算符也被编译为移动而非拷贝：

  ```mojo
    var someValue = somethingCopyableAndMovable()
    use(someValue)
    ...
    let otherValue = someValue      # Last use of someValue
    use(otherValue)
    ...
    var yetAnother = otherValue     # Last use of otherValue
    mutate(yetAnother)
  ```

  这对像 `PythonObject`
  （以及更复杂的值语义类型）这类在流式
  编程风格中常用的情况是显著的性能优化。这些类型不希望其
  拷贝构造函数执行多余的引用计数操作。

  如果你想显式控制拷贝，建议使用
  非 dunder 的 `.copy()` 方法而非 `__copyinit__`，并记住
  对想要完全显式行为者而言，不可拷贝类型必须始终使用转移运算符。

## 2023-05-24

### ⭐️ 新增

- `try` 语句现在支持 `finally` 子句。此外，`try`
  语句不再需要 `except` 子句，从而允许 `try-finally` 块。
  `finally` 子句包含当代码以任何方式离开 `try` 语句的其他
  子句时始终执行的代码。

### 🦋 变更

- `with` 语句的发出已改为使用新的 `finally` 逻辑，因此

  ```mojo
  with ContextMgr():
      return
  ```

  会在返回之前正确执行 `ContextMgr.__exit__`。

## 2023-05-16

### ⭐️ 新增

- 为 `PythonObject` 添加了缺失的 dunder 方法，从而能在导入的 Python 值上
  使用常见的算术和逻辑运算符。

- `PythonObject` 现在可从 Mojo 中打印，而无需导入 Python 的 print 函数。

### 🛠️ 修复

- [Issue #98](https://github.com/modular/modular/issues/98):
  循环中生命周期跟踪的不正确错误。

## 2023-05-11

### ⭐️ 新增

- `NDBuffer` 和 `Buffer` 现在可以通过 `Pointer` 和
  `DTypePointer` 构造。

- `String` 现在支持用整数或切片进行索引。

- 向 `Math` 模块添加了阶乘函数。

### 🦋 变更

- 使用 `&` 符号的 "byref" 语法已改为使用 `inout`
  关键字，以更接近参数中的 `borrowed` 和 `owned` 语法。
  请查看 [Issue #7](https://github.com/modular/modular/issues/7) 获取
  更多信息。

- 优化了 notebook 中的矩阵乘法实现。最初
  我们为可扩展性而非性能优化。我们
  找到了两全其美的方法，现在优化后 Matmul 实现的性能快了 3 倍。

- 将 [`^` 后置
运算符](/docs/manual/values/ownership#transfer-arguments-var-and-)
从 "consume" 改名为 "transfer"。

### 🛠️ 修复

- 修复了 `Testing.assertEqual` 缺失的重载，使其
  可在 `Integer` 和 `String` 值上工作。

- [Issue #6](https://github.com/modular/modular/issues/6):
  当定义简单泛型时 Playground 停止求值单元格。

- [Issue #18](https://github.com/modular/modular/issues/18):
  移除了 Python 互操作中的内存泄漏。
