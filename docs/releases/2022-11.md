## 2022-11-28 那一周

- 📢 我们支持将 `True` 和 `False` 关键字作为表达式使用。

- 📢 新增 `alias` 声明，可用于定义局部参数值。随着其逐步完善，
  它最终将涵盖类型别名等内容。

- 📢 我们现在可以使用 `kgen` 工具端到端执行 Mojo 文件了！
  使用 `@export` 导出的函数可以被运行。

- 📢 我们已经有了 try-except-else 与 `raise` 语句以及隐式错误传播！
  其错误语义是 `def` 默认可以抛出，但 `fn` 必须用 `@raises` 装饰器
  显式声明可抛出。初步搭起了基本的 `Error` 类型。

- 用于按引用传递参数的 `&` 符号现在放在标识符之后。
  后置形式在表达式侧对引用和移动运算符更友好，因为它可以链式调用
  且在心理上更符合联想：`thing.method().result^`。我们尚未实现该特性，
  但将参数声明语法与之对齐，使得将来实现时不至于看起来奇怪。
  实际写法如下：

  ```mojo
  def mutate_argument(a&: index):
      a = 25
  ```

## 2022-11-21 那一周

- 📢 神奇的 `index` 类型已移除。`__mlir_type.index` 万岁。

- 实现了参数替换到参数化 `__mlir_type` 声明中。这使我们
  能够使用新的 "placeholder" 属性定义暴露参数的参数化不透明 MLIR 类型。
  由此可以将 KGEN 类型参数系统的能力直接引入 Mojo。

- 📢 现在可以在 Mojo 中定义并使用完全参数化的自定义类型，这整合了
  最近的大量工作。例如，我们可以将 SIMD 类型直接作为 KGEN 类型的
  包装器来编写：

  ```mojo
  struct SIMD[dt: __mlir_type.`!kgen.dtype`, nelts: __mlir_type.index]:
      var value:
        __mlir_type.`!pop.simd<#lit<placeholder index>,
                               #lit<placeholder !kgen.dtype>>`[nelts, dt]

      fn __add__(self, rhs: SIMD[dt, nelts]) -> SIMD[dt, nelts]:
          return __mlir_op.`pop.add`(self.value, rhs.value)
  ```

## 2022-11-14 那一周

- 📢 实现了神奇的 `__mlir_type` 声明，可用于访问任意
  MLIR 类型。例如 `__mlir_type.f64`。

- 📢 新增了 `fn` 声明。它类似于 `def` 声明，但在若干方面更严格：
  参数必须带类型标注、函数体内不允许隐式变量声明，
  且其参数为右值而非左值。

- 实现了 Swift 风格的反引号标识符，这在代码迁移中名称可能与
  新关键字冲突时很有用。

- 📢 新增了 `__include` 指令，用于在源码层面进行文本包含。
  在我们拥有 `import` 模型之前这是临时的。

- 实现了算术运算符（如 `+` 和 `*`）的 IR 生成，基于
  `__add__` 和 `__mul__` 方法。

- 📢 新增了对 `break` 和 `continue` 语句的支持，以及循环和
  条件语句内的提前返回！

- 📢 实现了复合赋值运算符，如 `+=` 和 `@=`。

- 📢 Mojo 现在可以通过新的 `__mlir_op` 神奇声明生成任意
  MLIR 操作（不含 region），我们可以借此开始搭建
  语言的内建类型：

  ```mojo
  struct Int:
      var value: __mlir_type.index

      fn __add__(self, rhs: Int) -> Int:
          return __mlir_op.`index.add`(self.value, rhs.value)
  ```

  可以通过下标 `[]` 语法为声明附加属性，并可以在无法推断时
  通过特殊的 `_type` 属性指定显式结果类型。属性可以通过
  `__mlir_attr` 神奇声明访问：

  ```mojo
  __mlir_op.`index.cmp`[
      _type: __mlir_type.i1,
      pred: __mlir_attr.`#index<cmp_predicate slt>`
  ](lhs, rhs)
  ```

- 改进了带范围的诊断输出！现在错误会高亮整段代码，
  而不只是第一个字符。

## 2022-11-07 那一周

- 实现了 `@interface` 和 `@implements` 装饰器，用于
  访问 KGEN 生成器接口。被标记为 `@interface` 的函数
  没有函数体，但可由多个其他函数实现。

  ```mojo
  @interface
  def add(lhs: index, rhs: index):

  @implements(add)
  def normal_add(lhs: index, rhs: index) -> index:
      return lhs + rhs

  @implements(add)
  def slow_add(lhs: index, rhs: index) -> index:
      wait(1000)
      return normal_add(lhs, rhs)
  ```

- 📢 已支持静态结构体方法和初始化器语法。用 `Foo()` 初始化
  结构体会调用一个隐式静态的 `__new__` 方法。在结构体内
  应使用该方法而非 `__init__`。

  ```mojo
  struct Foo:
      var value: index

      def __new__() -> Foo:
          var result: Foo
          result.value = Foo.return_a_number() # static method!
          return result

      @staticmethod
      def return_a_number() -> index:
          return 42
  ```

- 📢 完整的按引用传递参数支持。现在可以正确地定义
  原地运算符如 `__iadd__` 以及像 `swap(x, y)` 这样的函数。

- 📢 实现了对右值字段提取的支持，例如当 `x` 不是左值
  （`var` 声明或按引用的函数参数）时的 `x.value`。
