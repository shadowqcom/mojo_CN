Mojo SDK 的首个补丁发布版本来了！v0.3.1 版本主要包含
与安装相关的修复。如果你在安装此前的 SDK 版本时遇到问题，
本版本可能正适合你。

## 🛠️ 修复

- [#538](https://github.com/modular/modular/issues/538) - 安装过程在
  测试阶段卡住。此问题出现在 CPU 核心数较少的机器上，
  例如免费的 AWS EC2 实例和 GitHub Codespaces。
- [#590](https://github.com/modular/modular/issues/590) - 安装失败并
  提示 "failed to run python"。
- [#672](https://github.com/modular/modular/issues/672) - 语言服务器在
  代码补全时卡住。与 #538 相关，此问题出现在 CPU 核心数较少的
  机器上。
- [#913](https://github.com/modular/modular/issues/913) - 在 REPL 和
  Jupyter notebook 中，行内注释此前被错误地解析。
