## 2023-08-24

- 修复了 `fn` 内 `with expr as x` 语句的行为像在 `def` 中那样、
  以函数作用域而非词法作用域绑定 `x` 的问题。

### ⭐️ 新增

- 对标准库进行重大重构，以启用打包和更好的
  导入体验：
  - 包以二进制构建以提升启动速度。
  - 包名和模块名现在为小写，以与 Python 风格对齐。
  - 模块已迁移以更好地反映底层
    函数的用途（例如 `Pointer` 现在位于 `memory` 包内的 `unsafe` 模块中）。
  - 以下模块现在作为内建包含：
    `SIMD`、`DType`、`IO`、`Object` 和 `String`。
    这意味着不再需要显式导入这些模块。
    相反，这些模块会为用户隐式导入。模块内的私有
    方法仍可通过
    `builtin.module_name._private_method` 导入语法访问。
  - 新增 `math` 包以容纳 `bit`、`math`、`numerics`
    和 `polynomial` 模块。`math.math` 模块的内容
    被重新导出到 `math` 包。

- Mojo 现在支持在参数表达式中使用仅内存类型，以及作为
  函数或类型参数：

  ```mojo
  @value
  struct IntPair:
      var first: Int
      var second: Int

  fn add_them[value: IntPair]() -> Int:
      return value.first + value.second

  fn main():
      print(add_them[IntPair(1, 2)]()) # prints '3'
  ```

- 此外，Mojo 支持在编译期求值使用堆分配内存的代码，并将带堆分配内存的编译期值
  物化为动态值：

  ```mojo
  fn fillVector(lowerBound: Int, upperBound: Int, step: Int) -> DynamicVector[Int]:
      var result = DynamicVector[Int]()
      for i in range(lowerBound, upperBound, step):
          result.push_back(i)
      return result

  fn main():
      alias values = fillVector(5, 23, 7)
      for i in range(0, values.__len__()):
          print(values[i]) # prints '5', '12', and then '19'
  ```

### 🦋 变更

- `def main():`（不带显式 `None` 类型）现在可用于定义
  Mojo 程序的入口。

- `assert_param` 函数已重命名为 `constrained`，现在是
  内建函数。

- `print` 函数现在可用于 `Complex` 值。

### 🛠️ 修复

- 修复了 `DType.uint16` 和 `DType.int16` 的打印格式问题。
- [Issue #499](https://github.com/modular/modular/issues/499) - SIMD 模块新增了
  `rotate_right` 和 `rotate_left` 两个函数。
- [Issue #429](https://github.com/modular/modular/issues/429) - 你现在可以
  从元素类型为 `DType.bool` 的 `SIMD` 类型构造 `Bool`。
- [Issue #350](https://github.com/modular/modular/issues/350) - 令人困惑的 Matrix
  实现
- [Issue #349](https://github.com/modular/modular/issues/349) - 缺失 load_tr
  in struct Matrix
- [Issue #501](https://github.com/modular/modular/issues/501) - Python 表达式中缺失语法
  错误消息。

## 2023-08-09

### 🦋 变更

- `ref` 和 `mutref` 标识符现在被视为关键字，这意味着
  它们不能用作变量、属性或函数名。这些关键字
  由 "lifetimes" 特性使用，该特性仍在开发中。在
  开发工作定型、公共 Mojo 构建中启用支持以及我们
  积累使用经验后，可以考虑重命名它们（以及其他
  相关关键字）。

- `def` 函数中的参数处理已变更：之前它们具有
  涉及被调用方中可变拷贝的特殊行为。现在，我们有
  一条简单规则：`def` 参数默认采用 `owned` 约定
  （`fn` 参数仍默认采用 `borrowed` 约定）。

  这主要是编译器和参数模型的内部清理与简化，但
  确实启用了一个小众用例：现在你可以通过将值的所有权转移
  到 `def` 调用，将不可拷贝类型传递给 `def` 参数。此前
  这不可能，因为拷贝发生在被调用方一侧，而非调用方一侧。这
  还允许在希望选择启用该行为的 `def` 中显式
  使用 `borrowed` 关键字。

## 2023-08-03

### ⭐️ 新增

- 新增 `Tensor` 类型。该张量类型管理自己的数据（不同于 `NDBuffer` 和 `Buffer`，它们只是视图）。因此，该张量类型自行进行分配和释放。以下是使用张量类型表示 RGB 图像并转换为灰度的简单示例：

  ```mojo
  from tensor import Tensor, TensorShape
  from utils.index import Index
  from random import rand

  let height = 256
  let width = 256
  let channels = 3

  # Create the tensor of dimensions height, width, channels and fill with
  # random value.
  let image = rand[DType.float32](height, width, channels)

  # Declare the grayscale image.
  var gray_scale_image = Tensor[DType.float32](height, width)

  # Perform the RGB to grayscale transform.
  for y in range(height):
      for x in range(width):
          let r = image[y, x, 0]
          let g = image[y, x, 1]
          let b = image[y, x, 2]
          gray_scale_image[Index(y, x)] = 0.299 * r + 0.587 * g + 0.114 * b
  ```

### 🛠️ 修复

- [Issue #53](https://github.com/modular/modular/issues/53) - `Int` 现在使用 `/` 运算符实现真除法。与 Python 类似，这返回
  64 位浮点数。相应的就地运算符
  `/=` 与 `//=` 具有相同语义。
